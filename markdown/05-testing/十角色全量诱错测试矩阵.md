# 十角色全量诱错测试矩阵

> v1.0.0 | 每里程碑 closeout 前必须至少执行一次全角色诱错

---

## 使用说明

本矩阵覆盖 10 个用户角色对系统进行全方位诱错测试的完整场景。每个场景包含诱错操作、预期行为和失败处置。

测试分为两个级别:
- **S0 (阻断)**: 每里程碑必须全量通过
- **P1 (高优)**: 发布前必须通过
- **P2 (常规)**: 持续回归

## 测试执行

### 手动测试

每里程碑 closeout 前，按角色顺序执行 S0 级测试。记录通过/失败到 `storage/audit/role-test-{date}.json`。

### 自动化覆盖

以下场景已有自动化测试覆盖，不需要手动执行:

| 场景 | 测试文件 |
|------|---------|
| 编译失败诊断 | `compileGraph.diagnostics.test.js` |
| 运行时错误格式 | `graphStore.runtimeErrors.test.js` |
| capability 边界 | `supportMatrix.test.js` |
| 凭证组件安全性 | `CredentialInput.jsx` (组件级) |
| DAG 环检测 | `CoreStrategyIr::validate_dag()` (单元测试) |
| graph_id 校验 | `runtime_validation.rs` (单元测试) |
| 存储配额 | `storage_lifecycle.rs` (单元测试) |
| 策略图编辑 | `StrategyWorkspacePage.codeMode.test.jsx` |
| 事件流面板 | `EventStreamPanel.*.test.jsx` |
| 回测工件 | `EventStreamPanel.backtestArtifacts.test.jsx` |

# 自由维度诱错审计 — v4.7.0 第 1 轮

## 结论

未发现阻断本地 closeout 的 S0。v4.6 OKX testnet 真下单与 v4.7 深度性能阈值依赖外部环境，已登记为延后项。

## 五维诱错

| 维度 | 检查点 | 结果 |
|---|---|---|
| A: 订单状态机 | OCO 单腿成交取消另一腿；trailing stop 触发价移动；GTD 过期；amend 保留 order id | 通过定向 Rust 测试 |
| B: 回放确定性 | tick replay 按 timestamp/sequence/symbol/venue 排序，重复运行 artifact 轨迹一致 | 通过定向 Rust 测试 |
| C: LiveActual 安全 | 无 Risk Plane 拒绝启动；runtime_simulated 能力在 ProviderActual 模式被拒绝 | 通过定向 Rust 测试 |
| D: v4 AI 提案 | v4 目标必须绑定 backtest source；trajectory 分析输出稳定摘要 | 通过定向 Rust 测试 |
| E: 沙箱回放 | candidate fill rate 低于 baseline 时标记 CandidateUnderperforms | 通过定向 Rust 测试 |

## 残余风险

- OKX testnet 真实订单提交/撤单未在本机执行。
- 500 bar 性能阈值未在固定硬件基准环境采样。

### 2. 压缩活跃规划文档

- 将已完成的工作移出活跃收尾说明。
- 将活跃收尾说明限制为仅未完成的工作。
- 将阶段完成的切片压缩为简短的状态要点，并指向其正式合约文档，而非重复大型完成清单。

### 3. 保持措辞与冻结边界一致

- 保持区分当前实现事实与未来方向。

### 4. 在关闭检查清单中保留 UTF-8 和渲染输出检查

- 在合并检查清单中保留 UTF-8 和渲染输出检查。

### 5. 阶段收尾验证

## 范围内不包括

以下不是当前主干方向的项目，不应重新进入近期队列：

- `async/await`
- `while`
- 泛化 `for`
- 完整 `match`
- 作为支持的语言特性的递归
- 宏
- OOP / 对象 / 方法 / 映射 / 数组作为通用语言特性
- 任意的用户定义指标 DSL
- 任意的用户定义权重 DSL 或比较器 DSL
- 跨 K 线的自由持久状态
- 将高级组合策略直接推入 QuantScript 主要语法
- 将动态运行时重新选择呈现为今天已支持的 universe 模型

## 使用规则

- 一旦某个任务已作为完成写入正式文档，不要在此处重复保留它。
- 这些说明应仅保留仍需执行的未完成工作。
- 一旦某个项目完成，首先将真实数据移入正式文档，然后在此处移除或压缩它。

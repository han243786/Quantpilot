## L0 — 致命缺陷（0.5 天）

### L0-1 compile 失败后旧结果未清除

**当前行为**：

```
@compile              → 编译成功，self.compile_result = Some(ok)
@modify { fast: 999 } → 存储修改
@compile              → 编译失败！但 self.compile_result 仍是旧的 Some(ok)
@backtest             → 使用旧的编译结果运行！(BUG)
```

**文件**：`src/test_runner.rs:compile_strategy()`

**改法**：函数开头清除旧结果：

```rust
fn compile_strategy(&mut self, ctx: &TestRunnerContext) -> bool {
    self.compile_result = None; // ← 新增：先清除，失败不留残留
    match lower_script_to_runtime_config(&ctx.module) {
        // ...
    }
}
```

**验收**：
```
curl 测试：
  @modify { param: "bad_param", value: 999 }
  @compile                              → compilable == false  
  @backtest                             → step failed: "no compile result"
```

```rust
if rest.starts_with("counts.") {
```

```rust
if rest.starts_with("protocol_name") {

        // 支持 == "value" 字符串比较
        if let Some(quoted) = rest.split('"').nth(1) {

}
```

### L2-2 `@modify` 扩展字段支持

**当前**：仅 `intent.params` 可修改。

**目标**：也支持 `data_sources` 和 `risks` 的常用参数。

**文件**：`src/test_runner.rs:compile_strategy()`

**改法**：

```rust
for (param_name, new_value) in &self.pending_modifications {
    // Data sources
    for ds in &mut runtime_config.data_sources {
        if param_name == "window_size" { ds.days = Some(*new_value as u32); }
        if param_name == "interval" { ds.interval = Some(format!("{}d", *new_value as u32)); }
    }
    // Risk controls
    for risk in &mut runtime_config.risks {
        if param_name == "max_total_leverage" { risk.max_total_leverage = *new_value; }
        if param_name == "max_exchange_leverage" { risk.max_exchange_leverage = *new_value; }
    }
    // Intents (existing)
    for intent in &mut runtime_config.intents {
        if param_name.contains("fast") { intent.params.insert("fast_period".into(), *new_value); }
        if param_name.contains("slow") { intent.params.insert("slow_period".into(), *new_value); }
    }
}
```

**验收**：
```
@modify { node: "data", param: "window_size", value: 100 }
@compile
@backtest
→ steps=100 (窗口缩小)
```

### L2-3 `@save_run` 实际持久化到磁盘

**文件**：`src/test_runner.rs:execute_step()` + `src/runtime_persistence.rs`

**改法**：

```rust
TestActionDef::SaveRun => {
    // 优先保存最后一次回测
    if let Some(last_bt) = self.backtest_history.last() {
        let report = serde_json::to_string_pretty(last_bt)?;
        let path = format!("storage/test-backtests/backtest_{}.json", 
            std::time::SystemTime::now().duration_since(...).as_millis());
        std::fs::write(&path, report).map_err(|e| format!("save failed: {e}"))?;
        messages.push(format!("save_run: persisted to {}", path));
    } else if self.last_run_equity.is_some() {
        // 保存最后一次 run
        let data = json!({ "equity": self.last_run_equity, "events": self.last_run_events_count });
        let path = format!("storage/test-runs/run_{}.json", ...);
        std::fs::write(&path, data.to_string()).map_err(...)?;
        messages.push(format!("save_run: persisted to {}", path));
    } else {
        return Err("save_run: no prior run or backtest to save".to_string());
    }
}
```

**验收**：
```
@backtest { source: "deterministic_mock" }
@save_run
→ "save_run: persisted to storage/test-backtests/backtest_xxx.json"
→ 文件确实存在且内容可读
```

# Legacy RFC-022 Venue Capability Protocol

场地能力协议定义系统如何描述一个交易场地或数据场地能够提供什么能力。它既包括市场数据能力，也包括交易能力、精度限制、频率限制、认证要求和支持的订单特性。协议的目标是让系统在做路由、回退和功能判断时，不必依赖硬编码事实。

场地能力应表达支持的产品线、支持的请求类型、参数限制、精度约束、限频信息和已知差异。对于同一品牌下不同产品线能力不一致的情况，也应明确拆分描述。场地能力可以来自人工配置，也可以来自接口探测，但一旦进入系统就应当具有统一结构。

本协议使系统可以更可靠地做跨场地扩展。无论是新增交易所，还是在同一交易所中接入现货、永续和交割合约，都可以通过能力描述来驱动后续流程。

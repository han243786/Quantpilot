# Legacy RFC-003 Instrument Protocol

标的协议定义系统如何表示交易对象。它覆盖现货、合约、指数、标记价格、资金费率参考对象以及未来可能接入的更多市场实体。协议的目标是把交易所各自不同的命名方式收敛成系统内部可比较、可筛选、可分组的统一标的语义。

标的协议要求至少表达提供方、产品线、交易所标识符和系统内部的规范化标识。对于衍生品，还应能表达合约类型、到期信息、保证金币种、报价单位和基础资产等关键特征。系统内部应允许同时保留原始符号和规范化符号，以便请求路由使用原始值，上层逻辑使用统一值。

标的协议的价值在于隔离交易所命名差异。只要标的语义稳定，策略、特征工程、组合管理和风险计算就可以在不感知具体交易所命名规则的前提下复用同一套逻辑。

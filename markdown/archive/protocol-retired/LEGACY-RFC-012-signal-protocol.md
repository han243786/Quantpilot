# Legacy RFC-012 Signal Protocol

信号协议定义系统如何表示一个可用于决策的判断结果。信号通常来自指标计算、统计模型、规则系统或代理分析，它本身不是最终动作，但会影响意图生成。协议的目标是让不同来源的信号可以并存、比较、聚合和追溯。

信号应至少表达来源、对象、方向、强度、时间范围和生成依据。对于概率型或评分型结果，还应明确量纲和解释方式。信号协议不强求所有信号都同构，但要求关键信息足够稳定，使上层能够对信号做筛选、排序和合成。

本协议让系统中的分析结果不再停留在临时变量里，而是变成可以缓存、回测、审计和复用的对象。意图协议通常会以一个或多个信号作为输入依据。

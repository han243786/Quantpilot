# Legacy RFC-013 Feature Protocol

特征协议定义系统如何表示用于建模、打分和规则判断的中间特征。特征可以来自行情聚合、统计计算、行为记录、订单流结构或外部数据融合。协议的意义在于让特征成为被明确定义的系统对象，而不是散落在不同策略代码中的临时字段。

特征应表达名称、作用对象、时间窗口、计算方式摘要、值类型和单位。对需要回放和重算的特征，还应保留版本信息和依赖引用。这样当特征逻辑更新时，历史结果仍然可以解释，不会因为名字相同却计算方法不同而混淆。

本协议为策略研究、模型训练和线上推断提供共同语义。信号往往由特征产生，意图又往往由信号产生，因此特征协议是策略体系可复现性的基础之一。

# Legacy RFC-004 Value Protocol

数值协议定义系统如何表达价格、数量、成交额、比率、杠杆、手续费和其他可计算值。协议关心的不只是一个数字，还包括单位、精度、方向和上下文语义。对于量化系统来说，一个没有单位和语义的数值几乎没有可复用价值。

数值协议要求重要字段在进入统一模型时就明确类型和单位。价格应与计价资产关联，数量应与基础资产或合约张数关联，比率应明确是否为百分数表达还是小数表达。对于精度要求较高的数据，内部应优先保留十进制安全表示，避免在早期处理中损失信息。

数值协议为后续风险、执行、结算和回测提供共同基础。只要值类型和单位一致，不同数据源和不同模块的计算结果才有可比较性，也才能避免隐蔽的单位错误传导到上层决策。

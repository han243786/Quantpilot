# Retired Protocol RFCs

This directory contains RFCs that were removed from the active QRPC protocol set.

They are preserved only for historical context. They are not normative, must not be
used as the current implementation baseline, and should not drive new development or
review decisions.

Archived filenames use the `LEGACY-RFC-*` prefix to avoid colliding with the active
continuous RFC numbering in `markdown/protocol`.

The active numbering space is now only `RFC-001` through `RFC-020`.

## Retired RFC List

- `RFC-001` Identity Protocol
- `RFC-002` Time Protocol
- `RFC-003` Instrument Protocol
- `RFC-004` Value Protocol
- `RFC-006` Source Adapter Protocol
- `RFC-009` Data Quality Protocol
- `RFC-012` Signal Protocol
- `RFC-013` Feature Protocol
- `RFC-022` Venue Capability Protocol

Use the active set in
[markdown/protocol](D:/rust-js-pr/QuantPilot/quantpilot/markdown/protocol/README.md)
for all current protocol work.

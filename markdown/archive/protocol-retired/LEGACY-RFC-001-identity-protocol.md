# Legacy RFC-001 Identity Protocol

身份协议定义系统中对象如何被稳定标识。它关注的不是展示名称，而是跨模块、跨环境、跨时间都尽量不变的身份引用。任何需要被缓存、追踪、关联、比较或审计的对象，都应当有明确身份，包括数据源、账户、策略、代理、组合、订单、执行报告和审计事件。

身份协议要求区分主身份和展示信息。主身份用于系统内部关联，展示信息用于面向用户的说明。主身份应尽量短小、唯一、可序列化并可由调用方可靠保存。身份的创建规则必须可解释，不能依赖临时上下文，也不能把会频繁变化的名称直接当作主键。

身份协议的价值在于把系统中的引用关系固定下来。只要身份稳定，数据就可以回放，策略结果就可以复现，审计链路也可以串联。后续所有协议中出现的对象引用，都默认继承本协议的约束。

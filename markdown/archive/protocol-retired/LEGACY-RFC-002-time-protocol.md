# Legacy RFC-002 Time Protocol

时间协议定义系统如何表达事件时间、处理时间和有效时间。量化系统中的很多问题并不是值本身错误，而是时间语义不清楚，因此本协议要求所有重要数据都明确说明时间来源和时间含义。市场数据至少要区分交易所产生时间与系统接收时间，执行相关数据还要区分请求时间、发送时间和成交时间。

时间协议要求时间字段优先使用统一的可比较格式，并且在跨模块传递时避免模糊语言。内部推荐以毫秒级时间戳作为机器主字段，同时允许保留便于阅读的文本形式。任何窗口、延迟、超时、回放和新鲜度判断，都应基于显式时间字段，而不是隐含在代码上下文中。

时间协议的意义在于保证排序、去重、对齐和时序分析有共同基础。数据规范模块、风控模块、执行模块和回测模块都需要依赖同一套时间语义，否则同一条记录在不同链路中的解释就会发生漂移。

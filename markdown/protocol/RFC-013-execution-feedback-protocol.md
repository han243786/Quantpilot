# RFC-013 Execution Feedback Protocol

执行反馈协议定义执行层和场地反馈如何被系统重新吸收。它可被视为 `RuntimeEvent` 的专用子集，用于表达订单与成交状态变化，但不改变 QRPC 主链。

## 协议目标

- 统一表达订单反馈和成交反馈
- 为订单状态机、持仓状态和事件追踪提供共同输入
- 保留必要场地原文，但不让上层依赖场地私有格式

## 反馈范围

执行反馈通常覆盖：

- 订单已提交
- 订单被拒绝
- 订单部分成交
- 订单全部成交
- 订单取消
- 订单过期
- 场地异常或连接错误

这些反馈最终应被统一收敛到运行态对象和运行事件中，而不是停留在交易所原始回包结构里。

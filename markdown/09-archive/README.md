## 清理规则

活跃目录中的文档满足以下条件时，可以归档到这里：

1. 不在当前 README、总览索引、模块树或递归状态中承担入口职责。
2. 已被新治理文档、协议文档或实现契约替代。
3. 最近递归流程没有继续写入或引用。
4. 移动后不会破坏当前门禁、模块树或全量树。

历史里程碑、审计报告和 closeout 记录即使长期不活跃，也不直接删除；它们属于证据链，除非确认是重复生成物或已被更高层归档文件完整覆盖。

# 私有基线风险登记册

本文档仅记录所有者接受的私有基线风险。
它不授权公开发布、公开仓库可见性、出站许可证替换或公开发布就绪措辞。

## 当前所有者决策

审查日期：`2026-04-28`

所有者仅接受剩余的前端依赖审计风险用于私有基线使用。之前的 PostCSS 中等发现已通过仅锁文件的补丁更新到 `postcss@8.5.12` 移除；剩余的审计发现是 Vite/esbuild 链。
这与 README 和首次发布就绪记录使用的发布姿态相同：私有基线可在接受的 gate 通过后进行，但公开发布不得声明为就绪。

此接受意味着：

- 当 `cmd /c tools\run-closeout-gates.bat` 通过时，私有基线可进行
- 仓库必须保持私有
- 公开发布仍然受阻
- 公开发布就绪措辞仍然被禁止
- Vite/Vitest 迁移在未来的任何公开发布之前仍然必需

这些项目不是新功能范围，应在以后作为 P2 清理、测试卫生或仅审查打磨进行修复。它们不改变当前的 paper-runtime beta 边界。

| 风险 | 证据 | 当前影响 | 所需的跟进 |

## 已解决的 P2 清理项

记录于 `2026-04-26` 并更新于 `2026-04-28`：

- 工作区页面 `act(...)` 警告已通过将协作审计刷新保留在测试拥有的 store fixture 下移除。`cd frontend; cmd /c npm run test -- StrategyWorkspacePage.codeMode.test.jsx` 现在通过而无需之前的警告。
- 可选的响应式视觉审查路由漂移已修复。审查规范现在针对当前的策略中心、策略工作区、回测详情和回测比较路由，其 API fixture 覆盖当前的图列表、图版本、图审计和实验历史读取。`VISUAL_REVIEW=1 cmd /c npx playwright test tests/e2e/visual-responsive-review.spec.js` 现在通过。
- 重复的策略中心 `可运行策略` 状态措辞已通过保留指标卡片标签并将操作状态卡片重命名为 `运行就绪` 来去重。
- `postcss <8.5.10` 中等审计发现已通过 `npm audit fix` 移除，将前端锁文件更新为 `postcss@8.5.12`，无需更改应用程序源代码或添加新的依赖范围。
- 可选的响应式视觉审查已通过截图前冻结动画和模拟减少运动来稳定，以获取手动截图证据。回测比较不再捕获过时的暗化过渡状态。
- 回测详情 `EventStreamPanel` 现在显式标记详情模式并在详情页面中使用自然流布局，避免了由编辑器面板网格行引起的移动端图表/源重叠。
- 事件流 JSX kicker 标签现在使用可读的源文本而非可见的 Unicode 转义字面量。

本地机器可读的审计输出可能存在于 `storage/audit/npm-audit-2026-04-24.json`。
该文件有意被忽略，因为本地审计输出是证据，而非版本化的产品真实数据。

## S0 — 阻断级 (✅ 已修复)

### S0-1 [C] `average_true_range` 越界 panic 🔧 FIXED

**文件:** `qrpc_runtime/src/core_ir_evaluator.rs:1760`
**触发:** `keltner_channel` 在 `bars.len() == period` 时调用 `average_true_range`。`true_range(bars)` 返回 `bars.len() - 1` 个元素，造成 `tr[..period]` panic。
**GP:** §5.3 (禁止 stub evaluator) / §4.1 capability contract
**修复:**

```rust
// keltner_channel 守卫: bars.len() < period → bars.len() <= period
// 或在 average_true_range 内部加 period > tr.len() 守卫
```

## P1 — 高优先级 (下个里程碑修复)

### P1-1 [B] `config_generation_history` Vec 无界增长 (内存泄漏)

**文件:** `src/runtime/mutation.rs:1374-1380`
**触发:** 每次参数变异激活 push 一个 `ConfigGenerationEntry`，无上限。
**修复:** 加 `truncate(100)` 或改用 `VecDeque` with 固定容量。

### P1-2 [B] `live_execution.rs` 异步上下文中 `std::thread::sleep`

**文件:** `qrpc_runtime/src/live_execution.rs:185,271,278,394`
**触发:** `okx_request()` 和 `rate_limit()` 使用同步 sleep，阻塞 tokio 线程。
**修复:** 通过 `spawn_blocking` 调用执行模块，或改用 `tokio::time::sleep`。

### P1-3 [B] `std::sync::Mutex` / `tokio::sync::Mutex` 混用无文档

**文件:** `qrpc_runtime/src/lib.rs:112` (std), `src/runtime/mutation.rs:1374` (tokio)
**触发:** 跨层混用，重构时可能意外在 `.await` 点持有 std Mutex。
**修复:** 添加显式注释说明设计意图。

### P1-4 [C] NaN 穿透 `.clamp()` 守卫

**文件:** `qrpc_runtime/src/core_ir_evaluator.rs:153,191,1595,1602`; `slippage.rs:191`
**触发:** `NaN.clamp(0.0, 1.0)` 仍返回 NaN，指标输出全链条污染。
**修复:** 每个 `.clamp()` 前加 `if !raw.is_finite() { 0.0 } else { raw.clamp(...) }`。

### P1-5 [C] 均线趋势除零 (ma_slow == 0.0)

**文件:** `qrpc_runtime/src/core_ir_evaluator.rs:150-153,187-191`
**触发:** Mock 数据或异常行情产生零价均线 → `ma_fast / 0.0 = Infinity`。
**修复:** 加 `!ma_slow.is_finite() || ma_slow == 0.0` 守卫。

### P1-6 [D] 全代码库零 `fsync` 调用

**文件:** 所有持久化路径
**触发:** 系统崩溃时，即使 tmp+rename 已完成，数据页可能未刷盘，文件变为空或截断。
**修复:** `write(tmp, data)` 后加 `tmp.sync_all()?`；rename 后 sync 父目录。

### P1-7 [D] 图保存非多文件原子

**文件:** `src/graph_api.rs:356-380`
**触发:** 5 次顺序原子写入 — 中间崩溃导致不一致状态 (json 已更新但 qs 未更新，或反之)。
**修复:** 写入临时子目录 → 单次 `rename()` 目录 (参照 `backtest_artifacts.rs` 模式)。

### P1-8 [E] 速率限制器暴露内部配置

**文件:** `src/rate_limiter.rs:100-107`
**触发:** 错误响应 detail 包含 `limiter.max_rps`，向攻击者透露限速配置。
**修复:** 移除具体数值，改用相对描述。

### P1-9 [E] `compile_api.rs` 使用 `{:#}` 泄漏完整错误链

**文件:** `src/compile_api.rs:14-20`
**触发:** `{:#}` 格式任何 `anyhow::Error`，暴露内部路径/字段名。
**修复:** DEV 模式用 `{:#}`，生产模式用 `{}`。

### P1-10 [E] `ErrorBoundary.jsx` DEV 模式泄漏 componentStack

**文件:** `frontend/src/components/ErrorBoundary.jsx:14-17`
**触发:** DEV 模式 `console.error` 完整组件栈，截图分享时泄漏内部结构。
**修复:** 仅 DEV 输出 `error.message`，完整栈写入专用诊断日志。

### P1-11 [E] 凭证 API 无用户级访问控制

**文件:** `src/credential_api.rs:17-111`
**触发:** 多用户模式下用户 A 可查看/修改用户 B 的交易所凭证。
**GP:** §A3 认证隔离
**修复:** credential_vault 接入 `scoped_key()` 机制。

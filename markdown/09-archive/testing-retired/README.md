# Testing Retired Archive

> Scope: inactive testing and audit reports moved out of the active testing surface.
> Batch: document deadwood cleanup, 2026-06-13.

This archive keeps historical testing evidence that is no longer part of the active testing workflow.

Move criteria used for this batch:

1. The document was under `markdown/05-testing/`.
2. The document had no direct Markdown references outside generated/global indexes.
3. The document represented historical audit, inducement-test, or closeout evidence rather than an active checklist, latest report, guide, or automation plan.
4. The document did not own current test commands, current acceptance gates, or active governance policy.

Active testing documents remain in `markdown/05-testing/` when they are still referenced, latest-facing, or used as operational guides.

- 如果“首个节点可见”和“全部节点挂载”差距很小，说明主要成本不在节点逐步补挂，而在 React Flow 容器初始化本身。

- 如果“首个节点卡片挂载”已经接近“首个节点可见”，说明节点卡片本身不是第一瓶颈。
- 如果“全量富节点卡片可见”明显晚于“首个节点卡片挂载”，说明 staged 模式确实把丰富节点内容延后了。

# Review Docs

Review docs are retained as reference material only.
They capture inspection snapshots and review findings from earlier passes.
They are not the active implementation source of truth, not a release gate, and
not a task queue.

When review wording conflicts with active product or release state, the active
docs win:

- [Current Status And Release State](../overview/overview-current-status-and-roadmap.md)
- [First Release Readiness](../implementation/planning/implementation-first-release-readiness.md)
- [Support Matrix](../implementation/governance/implementation-support-matrix.md)
- [Test Layer Expectations](../implementation/runtime/implementation-test-layer-expectations.md)

Do not re-open old review findings as active work unless a current gate failure,
capability-boundary drift, or reproducible regression is found.

## P1 — 必须完成

### P1-1: `zh-CN.js` 双重 Unicode 转义

**问题**: `frontend/src/i18n/locales/zh-CN.js` 前 9-25 行包含 `\\u...` 字面量键和值, 会把部分 UI 文本渲染为转义串。

**方案**:
1. 将转义键和值恢复为真实中文。
2. 增加 locale integrity 测试, 扫描值中不允许出现 `\\u[0-9a-fA-F]{4}`。
3. 同步 `en-US.js` 对应 key。

**验收**: i18n 测试通过; UI 不再出现 `\u4ee3` 等字面量。

### P1-2: 执行端无 i18n

**问题**: `frontend-executor/src` 全部用户可见文本硬编码中文, 没有 I18nProvider/useI18n。

**方案**:
1. 新增 executor i18n provider 和 `zh-CN` / `en-US` locale。
2. `ExecutorTopBar`, `OrderPanel`, `AssetPanel`, `KlineChart`, `StrategyParamsPanel`, `V4EvidencePanel`, `ExecutorApp` 全部用 `t()`。
3. locale 缺失时 fail in test。

**验收**: executor build 通过; en-US 下执行端核心界面无中文残留。

### P1-3: 主前端硬编码中文清理

**问题**: `StrategyWorkspacePage.jsx`, `TopToolbar.jsx`, 多个 StrategyHub 子组件仍有未包裹中文。

**方案**:
1. 收敛到 `t()`。
2. 补齐 en-US locale。
3. 扩展 user-facing text gate 路径或白名单。

**验收**: `tools/check-user-facing-text.ps1` 通过并覆盖新增路径。

### P1-4: QuantScript 编辑器 MVP 化

**问题**: 当前为 textarea, 无持久化、无 humanized error、粘贴超限用 `alert()`。

**方案**:
1. 用 localStorage 保存草稿和最后运行报告。
2. 错误走 `humanizeErrorText` / error code 映射。
3. 粘贴超限改用 Toast。
4. 最少实现行号、基础语法 token 高亮或分流到 Monaco/CodeMirror 评估。

**验收**: 离开再返回草稿不丢失; 后端错误不再展示原始 HTTP dump。

### P1-5: CSS 语法和设计系统漂移

**问题**: `styles.css` 存在缺逗号选择器; `.ad-btn` 与 `.ghost-btn/.primary-btn/.danger-btn` 并存; Toast 使用硬编码颜色。

**方案**:
1. 修复 `button,input,select` 和 `.toolbar-group,.toolbar-center` 等选择器。
2. 建立按钮类迁移策略, 保留兼容 alias。
3. Toast 使用 CSS variable token。
4. 加 CSS lint 或最小语法扫描脚本。

**验收**: CSS parser/lint 通过; Toast 颜色来自设计 token。

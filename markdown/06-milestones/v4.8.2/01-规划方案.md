# v4.8.2 规划方案 — 产品/UX/i18n 收敛

> 版本类型: PATCH | 基准: v4.8.1 API 契约与部署治理规划
> 来源: Claude 产品/UX/功能完整度审计 + Codex 代码侧核查
> 目标: 先修用户可见质量和 i18n 断点, 不扩大交易能力边界

---

## 目标

v4.8.2 聚焦产品入口、国际化、编辑体验和前端一致性。该版本不新增交易能力, 只修复会直接影响用户理解、语言切换、代码编辑和可访问性的体验问题。

1. 修复 `zh-CN.js` 双重 Unicode 转义, 防止关键标签渲染为字面量 `\u...`。
2. 给 `frontend-executor` 接入 i18n 基础设施, 至少覆盖当前所有用户可见文本。
3. 将主前端新增/遗留硬编码中文纳入 `t()` 和 locale 文件。
4. 将 QuantScript 编辑器从 MVP textarea 提升到可用编辑器: 持久化、错误 humanize、粘贴提示、快捷键。
5. 修复 CSS 选择器语法和按钮/Toast 设计系统漂移。
6. 补齐首次访问教程自动触发、404 页面、侧边栏键盘展开、命令面板动作命令和中文用户指南。

## 非目标

- 不开放真实资金执行端。
- 不新增交易 provider、资产类别或 V1 QS 语法。
- 不重写整个前端设计系统。
- 不在本版本升级 React/Vite 等大版本依赖。
- 不把策略中心搜索/筛选/排序列为缺口, 因为代码侧已确认存在。

## 兼容性与迁移

- 默认语言仍为 `zh-CN`; `en-US` 仅在切换后生效。
- 执行端 i18n 可先复用主前端 locale 结构, 但不得直接依赖主前端 bundle。
- QS 编辑器升级允许分阶段: 先持久化和错误映射, 再引入高亮/补全。
- 亮色主题作为 P3 评估项, 不阻塞本版本 closeout。

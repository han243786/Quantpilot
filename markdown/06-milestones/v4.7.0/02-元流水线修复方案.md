## P0-1: 修复 track-gate-metrics.ps1

**文件**: `tools/track-gate-metrics.ps1`

**根因**: 第 51 行 `Write-Host "  ${Name}: $($sw.ElapsedMilliseconds)ms $($if($success){'PASS'}else{'FAIL'})"` 中 `$($if(...))` 嵌套子表达式在 PowerShell 5.1 下有兼容性故障。

**修复**:

```powershell
# 旧 (第 51 行):
Write-Host "  ${Name}: $($sw.ElapsedMilliseconds)ms $($if($success){'PASS'}else{'FAIL'})" -ForegroundColor $(if($success){'Green'}else{'Red'})

# 新:
$label = if ($success) { 'PASS' } else { 'FAIL' }
$color = if ($success) { 'Green' } else { 'Red' }
Write-Host "  ${Name}: $($sw.ElapsedMilliseconds)ms $label" -ForegroundColor $color
```

**额外改动**:
- 输出格式从伪 JSON append 改为 NDJSON (`gate-metrics.ndjson`)，每行一条 JSON 记录
- 默认输出路径: `target/meta-pipeline-audit/gate-metrics.ndjson`
- 新增 `-DryRun` 参数: 只校验脚本语法不实际执行门禁

**验收**:
```powershell
# 可执行
powershell tools/track-gate-metrics.ps1 -OutputDir target/meta-pipeline-audit

# DryRun 模式
powershell tools/track-gate-metrics.ps1 -DryRun  # → exit 0, 不执行任何门禁

# 输出为合法 NDJSON
cat target/meta-pipeline-audit/gate-metrics.ndjson | jq '.'  # 每行可解析
```

## P1-1: Draft / Release 两种 closeout 模式

**文件**: `tools/run-closeout-gates.bat`

**方案**: 增加 `--mode` 参数:

| 模式 | 范围 | clean worktree | 全量树 | QS smoke | 用途 |
|------|------|:--:|:--:|:--:|------|
| `draft` | 1-21 项 | 警告不阻断 | 警告不阻断 | 警告不阻断 | 开发中快速定位 |
| `release` | 1-24 项 | 阻断 | 阻断 | 阻断 | 最终提交前 |

默认 `release`。原则: 最终 release 仍必须 24/24，不降低标准。

**实现**:
```bat
set CLOSEOUT_MODE=release
if "%1"=="--draft" set CLOSEOUT_MODE=draft

REM 在 clean worktree / full feature tree / QS smoke 步骤:
if "%CLOSEOUT_MODE%"=="release" (
    REM 失败 → goto :fail
) else (
    REM 失败 → echo [WARN] draft mode, continuing...
)
```

**验收**:
- `run-closeout-gates.bat --draft` → clean worktree 失败不阻断
- `run-closeout-gates.bat --release` → clean worktree 失败阻断 (原行为保持不变)

## P2-1: 结构化失败分类

**文件**: `tools/track-gate-metrics.ps1` (P0-1 修复中一并实现)

**分类体系** (超级规范化 §7.2 元流水线指标):

| 分类 | 含义 | 示例 |
|------|------|------|
| `true_positive` | 门禁正确拦截了真正的违规 | capability drift, BOM 文件, 版本不一致 |
| `false_positive` | 门禁报告违规但人工确认为误报 | 检查脚本正则过于宽泛 |
| `expected_dirty_worktree` | 提交前工作区有未提交文件 | 新增文件尚未 git add |
| `tooling_bug` | 门禁脚本自身故障 | track-gate-metrics.ps1 语法错误 |
| `environmental` | 环境问题导致的失败 | 磁盘满、网络超时、权限不足 |

**统计**: 每轮 closeout 后汇总:
- 误报率 = `false_positive / (true_positive + false_positive)`
- 工具故障率 = `tooling_bug / 总执行次数`
- 环境故障率 = `environmental / 总执行次数`

**约束**: 超级规范化 §7.4 (策略检查工具质量跟踪) 要求统计误报率和漏报率。本分类体系直接支撑该指标。

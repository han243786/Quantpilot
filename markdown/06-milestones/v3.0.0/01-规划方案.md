# v3.0.0 规划方案 — 实时执行端

> 版本类型: MAJOR | 基准: v2.5.0 | 目标: 兑现实盘交易承诺, 构建专业级实时执行系统

---

## 目标

- 构建与测试系统完全隔离的**实时执行端** (独立进程, 独立端口)
- 直连交易所 WebSocket 实现实时价格推送和 K 线绘制
- 策略从测试端一键迁移到执行端 (锁定拓扑, 热调参数)
- 专业级 UI: lightweight-charts K 线, 策略图涌动效果, 挂单/成交实时更新
- 多策略并发执行 (多标签页)
- 最高级别 API 加密规范 (进程间临时密钥 + AES-256-GCM + HMAC)
- 支持实盘和模拟盘双模式

## 非目标

- 不改变测试端 (v2.5.0 已有功能)
- 不在执行端提供策略编辑功能 (拓扑永久锁定)
- 不在 v3.0.0 实现 AI 自动调参 (API 已就绪, AI 调参留给 v3.1.0)
- 不支持策略图拓扑变更 (仅热调参)

## 架构概览

```
┌─ 测试端 (127.0.0.1:3000) ───┐    ┌─ 执行端 (127.0.0.1:3001) ───┐
│ Axum + Tauri                  │    │ Axum + Tauri (独立窗口)       │
│                               │    │                               │
│ 策略编辑/编译/回测            │    │ 策略执行/监控/热调参          │
│ QuantScript 编译器            │    │ WebSocket 直连交易所          │
│ 插件系统                      │    │ lightweight-charts K线        │
│ 凭证保险库                    │    │ 策略图涌动渲染               │
│                               │    │ 多策略并发标签页             │
│                               │    │                               │
│   ┌──策略迁移 API─────────────┼────┼─→ 接收策略包                │
│   │  (加密通道)               │    │   (Core IR + Graph + Params) │
│   └───────────────────────────┼────┼───────────────────────────── │
│                               │    │                               │
│   ┌──热调参 API───────────────┼────┼─→ 安全窗口+自动回滚         │
│   │  (加密通道)               │    │                               │
│   └───────────────────────────┘    └───────────────────────────────┘
```

## 核心决策 (已确认)

| # | 决策 | 选择 |
|---|------|------|
| 1 | 架构关系 | 独立进程 (测试 :3000 / 执行 :3001) |
| 2 | API 安全 | 进程间加密通道: 启动时临时密钥 + AES-256-GCM + HMAC-SHA256 |
| 3 | 凭证管理 | 执行端单独输入, 最高安全规范, 不与测试端共享 |
| 4 | 策略迁移 | Core IR + 图JSON + 参数快照 + SHA-256 完整性签名 |
| 5 | 主界面布局 | 左侧侧边栏(挂单/成交/资产) + 右侧上下分屏(策略图/K线) |
| 6 | 实时数据 | WebSocket 直连交易所 (Binance/OKX) |
| 7 | K线渲染 | lightweight-charts (TradingView) |
| 8 | 多策略并发 | 多标签页 (每标签=独立策略实例) |
| 9 | 热调参 API | 安全窗口检查 + pending 写入 + 下一周期生效 + 30s观察窗口 + 自动回滚 |
| 10 | 策略图渲染 | 仅显示 + 涌动效果 (拓扑锁定, 不可编辑) |
| 11 | 运行模式 | 实盘 + 模拟盘双模式 |

## 实现阶段

### Phase 1: 执行端后端骨架

| 任务 | 文件 | 说明 |
|------|------|------|
| 1.1 | `src-executor/main.rs` | 独立 binary: 执行端 Axum server, 端口 3001 |
| 1.2 | `src-executor/executor_state.rs` | 执行端状态管理: 活跃策略注册表, WS连接池, 环形缓冲区 |
| 1.3 | `src-executor/ws_client.rs` | WebSocket 客户端: 直连 Binance/OKX, 自动重连, 心跳 |
| 1.4 | `src-executor/kline_buffer.rs` | K线环形缓冲区: 每标的最近1000条, OHLC聚合, 一字线生成 |
| 1.5 | `src-executor/migration_api.rs` | 策略迁移端点: 接收/验证/加载策略包 |
| 1.6 | `src-executor/params_api.rs` | 热调参端点: GET/POST params + rollback, 安全窗口验证 |
| 1.7 | `src-executor/session_crypto.rs` | 进程间加密: 临时密钥生成, AES-256-GCM 加密/解密, HMAC 签名 |

## 验收

| # | 验收项 | 标准 |
|---|--------|------|
| 1 | 独立进程启动 | `cargo run --bin executor` 在 :3001 启动 |
| 2 | WebSocket 连接 | 直连 Binance WS, 实时接收 ticker/kline |
| 3 | K线渲染 | lightweight-charts 显示实时K线, 含一字线/插针/蜡烛 |
| 4 | 策略迁移 | 测试端编译策略→部署→执行端加载并显示锁定策略图 |
| 5 | 涌动效果 | 策略图节点显示实时价格, 触发时产生脉冲动画 |
| 6 | 热调参 | POST params→安全窗口→生效→观察→异常自动回滚 |
| 7 | 多策略并发 | 3个标签页各自独立运行不同策略 |
| 8 | 加密通道 | 进程间 API 请求 AES-256-GCM 加密 + HMAC 验证 |
| 9 | 实盘交易 | OKX 真实下单/撤单/成交反馈 |
| 10 | 模拟盘 | paper 模式正常运行 (复用现有 FillEngine) |
| 11 | 紧急停止 | 一键停止所有策略 + 撤销所有挂单 |

## 风险

| 风险 | 缓解 |
|------|------|
| lightweight-charts 许可证 (Apache 2.0, 免费) | 确认商业使用无限制 |
| WebSocket 断连 | 自动重连 + 指数退避 + 断连期间保留最后价格 |
| 多策略资源竞争 | 每策略独立 RuntimeCoordinator + 资源监控面板 |
| 实盘资金风险 | 每日限额 + 紧急停止 + 独立凭证隔离 |
| 开发周期长 | 按 Phase 1→5 分阶段交付, Phase 1-2 即可验证核心链路 |

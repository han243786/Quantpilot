## Leaf Split Decision Gate

`http_transport` should continue to baseline/extraction because:

- live HTTP transport is still parent residual code after historical cache and mock generation extraction;
- it has a distinct owner from in-memory cache and circuit-breaker orchestration;
- it includes reusable transport primitives already needed by historical cache through the parent facade;
- extracting it reduces `data_module.rs` residual complexity while preserving `BuiltinDataModule` as the parent facade.

Further split inside `http_transport` is not approved yet. After extraction, the child must run terminal leaf control before deciding whether ping probing, OKX live fetch, JSON transport, runtime blocking, and Windows fallback should remain together.

## Summary

This baseline freezes the execution feedback contract family before extraction from `qrpc_core/src/rfc_execution_contracts.rs`.

The next implementation step may move only `FeedbackKind` and `ExecutionFeedback` into a private child module under the RFC execution parent. Public names must remain available through the RFC execution parent facade and the qrpc-core crate root facade.

## Frozen Surface

The selected child owns:

- `FeedbackKind`;
- `ExecutionFeedback`.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Feedback kind taxonomy | `FeedbackKind` keeps `OrderSubmitted`, `OrderRejected`, `OrderPartiallyFilled`, `OrderFilled`, `OrderCancelled`, `OrderExpired`, and `VenueError`. |
| Execution feedback DTO | `ExecutionFeedback` keeps `feedback_id`, `order_id`, `kind`, `fill_qty`, `fill_price`, `remaining_qty`, `reject_reason`, `venue_message`, `occurred_at_ms`, and `ingested_at_ms`. |
| Optional fill/reject fields | `fill_qty`, `fill_price`, `remaining_qty`, `reject_reason`, and `venue_message` remain optional and unchanged. |
| Timestamps | `occurred_at_ms` and `ingested_at_ms` remain `u64` millisecond timestamps. |
| Order relation | `order_id` remains a string ID reference. This child must not import or own order transition behavior. |
| Derives and serde | Current `Debug`, `Clone`, `Copy` where present, `Serialize`, `Deserialize`, `PartialEq`, and `Eq` where present remain unchanged. |
| Public facade | Existing public names remain available through `qrpc_core::*`. |

## Planned Extraction Shape

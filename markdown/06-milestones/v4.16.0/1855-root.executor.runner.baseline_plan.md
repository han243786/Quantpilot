## Goal

Freeze the executor runner boundary before recursive runner route extraction.

`root.executor.runner` owns the execution-side strategy lifecycle and external
market/provider interaction surface. The immediate refactor target is to drain
runner-related route handlers out of `src-executor/main.rs` while preserving the
parent route registration surface.

## Physical Surface

| Path | Initial owner note |
| --- | --- |
| `src-executor/live_runner.rs` | runner pool, live runner, v4 runner behavior |
| `src-executor/migration_api.rs` | migration package validation and strategy load |
| `src-executor/kline_buffer.rs` | kline buffer support |
| `src-executor/ws_client.rs` | market websocket client and parsing |
| `src-executor/okx_rest.rs` | OKX REST order/balance adapter |
| `src-executor/main.rs` | still holds runner route handlers and process wiring |

## Runner Child Queue

| Order | Candidate child | Initial scope |

| 1 | `provider_order_routes` | OKX demo order submit/query/cancel route handlers and provider credential loading |
| 2 | `strategy_lifecycle_routes` | strategy list/detail/deploy/start/stop handlers |
| 3 | `market_stream_routes` | kline route and SSE event stream |
| 4 | `v4_deploy_support` | v4 deploy request parsing, graph resolution, static bundle helpers |
| 5 | `runner_support_files` | existing live runner, migration, kline, websocket, and OKX REST files |

## Equivalent Behavior

Runner extraction must preserve:

- executor route paths and response shapes;
- strategy package verification and migration behavior;
- runner registration/start/stop behavior;
- V4 deployment and preflight behavior;
- OKX demo provider order payload validation and audit redaction;
- market data and SSE behavior;
- no direct backend/runtime state mutation.

## Exclusions

- Do not reopen `executor.state` or move `state_routes`.
- Do not move process startup or top-level router construction except to point
  at extracted route handlers.
- Do not include frontend-executor UI.
- Do not introduce release-transition shortcuts.

## Public Surface To Preserve

| Surface | Requirement |
| --- | --- |
| `AgentEvaluationRequest` | Cycle name, intent signals, Core IR, portfolio state, rebalance timestamp map, timestamp, and trace id stay unchanged. |
| `AgentEvaluationOutput` | Agent decisions, runtime events, and evaluated rebalance agent ids stay unchanged. |
| `AgentModuleProvider` | Provider trait remains `Send + Sync`; default key remains `builtin.agent.default`; `evaluate_agents` signature stays unchanged. |
| `BuiltinAgentModule` | Built-in provider remains stateless and continues to route policy families by agent kind and cycle name. |

## White-Box Responsibilities

`root.contracts.runtime_support.agent_module` owns:

- dispatching enabled Core IR agent policies by cycle and `AgentPolicyKind`;
- building weighted signal decisions for slow-cycle long/short behavior;
- building portfolio rebalance decisions and target-weight plans;
- enforcing rebalance cadence through `last_rebalance_at_ms`;
- building cross-venue arbitrage decisions from quote observe signals or spread signals;
- calculating signal score, position ratio, current allocation, portfolio equity, and total cost buffer helpers used by agent decisions;
- emitting `AgentDecisionProduced` runtime events;
- preserving local tests for weighted signal, rebalance, arbitrage, symbol/exchange inheritance, allocation methods, and cadence behavior.

## Split Decision

The read-only leaf tool returned conservative `STOP` because it cannot infer same-parent wave ownership by itself:

```text

Terminal leaf control: size_bucket=oversized_over_800, governance_mode=stop_split
```

This baseline overrides that conservative recommendation with stronger ownership evidence:

- `AgentPolicyKind::WeightedSignals`, `PortfolioRebalance`, and `CrossVenueArbitrage` are distinct behavior families;
- the current file is oversized and branch-heavy;
- each policy family has separate tests and failure modes;
- same-parent child extraction can preserve public API by keeping `BuiltinAgentModule` as the dispatch facade;
- shared helpers can remain parent-owned until the child extractions prove a cleaner owner.

Decision:

`continue_split: true`

## Allowed Movement Rules

Future extraction may add child modules under `qrpc_runtime/src/agent_module/` while preserving parent-mediated access.

Allowed only after a child-specific baseline:

- move weighted-signal decision flow into a child;
- move portfolio-rebalance flow into a child;
- move cross-venue arbitrage flow into a child;
- move shared scoring/portfolio helpers only if at least two extracted children need parent-mediated reuse;
- move local tests into a direct test-harness child only after production flow children are stable, or if Rust visibility makes production extraction noisy.

The parent must keep:

- public request/output/provider/builtin types;
- provider key;
- top-level `evaluate_agents` dispatch and event assembly unless a later baseline proves a safe facade alternative;
- crate-root re-export compatibility.

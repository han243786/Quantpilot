## Summary

`root.contracts.core_ir.v4_contracts.plugin_governance_contract` freezes the equivalence baseline for extracting the
v4 plugin governance and manifest validation contract from `qrpc_core_ir/src/v4.rs`.

Frozen public surface:

- `PluginGovernanceContract`
- `PluginManifestSpec`
- `PluginKind`
- `PluginManifestField`
- `PluginSideEffect`
- `PluginRuntimePermission`
- `PluginNetworkPermission`
- `impl Default for PluginGovernanceContract`
- `PluginGovernanceContract::validate_static_contract`
- `PluginGovernanceContract::validate_plugin_manifest`

Frozen internal child helpers:

- `default_plugin_governance_version`
- `default_plugin_kinds`
- `default_plugin_required_fields`

Frozen behavior:

- default allowed plugin kind list and order remain Pure/Runtime/Venue
- default required manifest field list and order remain unchanged
- default governance flags remain true
- static governance validation keeps current schema version, allowed kind, required field, QS capability declaration,
  real order venue/risk-plane, and pure determinism error strings
- manifest validation keeps current ID/name/version/test fixture, kind, input/output schema, pure plugin, runtime plugin,
  venue plugin, capability matrix, and first-wave venue capability validation behavior
- venue manifest validation keeps the existing best-effort mode support check loop behavior

Allowed extraction:

- add `mod plugin_governance_contract;` to `qrpc_core_ir/src/v4.rs`
- re-export the child through `pub use plugin_governance_contract::*;`
- create `qrpc_core_ir/src/v4/plugin_governance_contract.rs`
- move plugin governance DTOs/enums/defaults and validation methods
- import QS type-system, runtime mode, and venue capability matrix public surfaces through the v4 surface

Forbidden movement:

- QS type-system implementation, runtime mode implementation, venue capability matrix implementation, static bundles,
  compile-time capability reports, compatibility bridge, reproducibility, complexity budget, developer learning pipeline,
  bridge builders, tests, machine contract, machine graph contract, QS profile, and version manifest

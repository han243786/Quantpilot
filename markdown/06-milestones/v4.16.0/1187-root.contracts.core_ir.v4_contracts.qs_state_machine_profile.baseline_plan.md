## Summary

`root.contracts.core_ir.v4_contracts.qs_state_machine_profile` freezes the equivalence baseline for extracting
the QS state-machine profile contract family from `qrpc_core_ir/src/v4.rs`.

Frozen public surface:

- `QsStateMachineProfile`
- `QsStatePolicy`
- `QsActionBlockPolicy`
- `QsMemoryPolicy`
- `QsEventPolicy`
- `QsPriorityPolicy`
- `QsRiskPlanePolicy`
- `default_v4_qs_state_machine_profile`
- `QsStateMachineProfile::validate_static_contract`

Frozen default behavior:

- profile schema defaults to `V4_QS_STATE_MACHINE_PROFILE_VERSION`
- allowed templates default to Observation, Decision, and Execution
- state policy defaults preserve state groups, nested machines, warning requirement, max states, and max groups
- action policy defaults preserve event emission, memory writes, diagnostics, no network/file/direct-order/cross-memory/unbounded-loop/dynamic-eval, and `Some(1_024)` loop limit
- memory, event, priority, and risk-plane policy defaults remain unchanged

Frozen validation behavior:

- schema version, duplicate template, and missing Observation/Decision/Execution template errors remain unchanged
- state, action, memory, event, priority, and risk-plane validation error strings and branch order remain unchanged
- `Ok(())` vs `Err(errors)` result behavior remains unchanged

Allowed extraction:

- add `mod qs_state_machine_profile;` to `qrpc_core_ir/src/v4.rs`
- re-export the child with `pub use qs_state_machine_profile::*;`
- create `qrpc_core_ir/src/v4/qs_state_machine_profile.rs`
- move only the seven QS profile policy structs, their `Default` impls, `default_v4_qs_state_machine_profile`,
  `default_qs_state_machine_profile_version`, `default_qs_machine_templates`, and `QsStateMachineProfile::validate_static_contract`
- import shared `MachineTemplateKind`, `V4_QS_STATE_MACHINE_PROFILE_VERSION`, `default_true`, `BTreeMap`, `BTreeSet`,
  `Value`, and serde traits as needed

Forbidden movement:

- `V4StaticContractBundle` and its defaults/validation
- runtime mode, QS type system, plugin governance, version manifest, reproducibility, complexity budget, capability,
  bridge, and venue contracts
- machine contract and machine graph contract modules
- v4 tests

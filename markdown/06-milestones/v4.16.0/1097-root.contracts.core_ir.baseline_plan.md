## Hard Boundaries

This baseline must not:

- edit Rust source code;
- change v1 or v4 struct/enum fields, serde attributes, constants, helper behavior, validation diagnostics, validation ordering, public exports, or tests;
- change qrpc-core, compiler, runtime, QuantScript, backend, executor, frontend, physical `plugins/*`, or release transition;
- move compiler/runtime bridge ownership into core_ir;
- introduce direct sibling shortcuts.

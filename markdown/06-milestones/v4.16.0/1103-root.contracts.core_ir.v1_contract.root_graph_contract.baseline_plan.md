This baseline freezes the v1 root graph contract before extraction from `qrpc_core_ir/src/v1.rs`.

The next implementation step may move only the v1 root graph declarations into `qrpc_core_ir/src/v1/root_graph_contract.rs`. Public names must remain available through the v1 parent and crate-root facades.

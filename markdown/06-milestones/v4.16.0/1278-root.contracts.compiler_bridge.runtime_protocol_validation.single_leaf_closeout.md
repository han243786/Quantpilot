## Summary

`root.contracts.compiler_bridge.runtime_protocol_validation` stops splitting.

The child now has one parent-mediated `pub(super)` entrypoint and a cohesive private validation pipeline for `RuntimeProtocolCoreConfig`. Splitting them further would create small helper-only modules and increase communication cost without an independent public or state-machine owner.

## Visibility Watchpoint

`V4PaperSimulatedRuntime` stores `V4SimulatedExecutionRuntimeState` in the public type-surface child. If the implementation include is moved under `v4_runtime/simulated_execution_engine.rs`, the state type must remain parent-visible without making it a public API.

Allowed adaptation:

- make `V4SimulatedExecutionRuntimeState` visible only inside `crate::v4_runtime`;
- import it through the parent boundary;
- keep all behavior methods private to the simulated execution child unless an existing parent method requires `pub(super)`.

Forbidden adaptation:

- exposing simulator internals as public API;
- linking sibling modules directly;
- activating release-transition optimization.

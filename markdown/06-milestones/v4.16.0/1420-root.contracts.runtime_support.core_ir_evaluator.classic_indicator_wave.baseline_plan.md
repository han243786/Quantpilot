## White-Box Contract

The child may call parent-owned private helpers through `super::*`.

The child must expose only parent-visible evaluator entrypoints, expected as `pub(super)` functions, so public API remains unchanged.

## Split Decision

`continue_split: true`

Reason:

- these six functions are direct builtin registry targets and form a stable same-parent wave;
- extracting them reduces the parent file without changing public evaluator dispatch;
- continuing to split each classic indicator into separate files would create unnecessary governance and import churn.

## Equivalence Requirements

The extraction must preserve:

- registry keys and evaluator order;
- output fields, derived metrics, reason strings, TTLs, and error behavior;
- helper ownership and parent-mediated access;
- local tests for classic indicators and dependent intent-module smoke test behavior.

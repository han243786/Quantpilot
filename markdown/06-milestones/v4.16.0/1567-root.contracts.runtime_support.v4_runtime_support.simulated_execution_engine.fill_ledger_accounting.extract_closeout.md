## Decision

Extract `fill_ledger_accounting` as a dedicated simulated execution child.

The extraction moved trigger-fill execution and ledger mutation helpers out of the parent include while preserving fill event payloads, fee projection, order status updates, OCO sibling cancellation, cash/position accounting, and asset point side effects.

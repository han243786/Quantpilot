## White Box Boundary

| Item | Owner | Input | Output | Side effects |

## Equivalence Baseline

The next extraction must preserve:

- `Position`: `exchange`, `symbol`, `net_qty`, `frozen_qty`, `avg_entry_price`, `mark_price`, `unrealized_pnl`, and `realized_pnl`.
- `ExchangeExposure`: `exchange`, `gross_notional`, `net_notional`, and `leverage`.
- `PortfolioState`: `cash_balance`, `available_cash_balance`, `frozen_cash_balance`, `open_orders`, `positions`, `exchange_exposures`, `total_gross_notional`, `total_net_notional`, `total_leverage`, and `updated_at_ms`.
- `PortfolioState` serde shape, including `#[serde(deny_unknown_fields)]`.
- `PortfolioState::new`: available cash equals initial cash, frozen cash is `0.0`, all vectors start empty, notional/leverage totals start `0.0`, and `updated_at_ms` equals the input timestamp.
- `PortfolioState::debug_assert_invariants`: debug-only cash-balance consistency assertion, non-negative leverage assertion, and non-negative cash assertion.
- Existing parent and crate-root facade exports.

## Extraction Plan

BE-001SJ-02 may:

- create `qrpc_core/src/runtime_io_contract/portfolio_state.rs`;
- add `mod portfolio_state;` and `pub use portfolio_state::*;` to the runtime IO parent;
- move only `Position`, `ExchangeExposure`, `PortfolioState`, and its impl block;
- import `Exchange` and `Symbol` from the qrpc-core crate facade;
- import `OpenOrder` through the runtime IO parent facade.

BE-001SJ-02 must not:

- move `RuntimeEvent`, `RuntimeCycleOutput`, `SessionOutput`, or backtest output DTOs;
- reopen closed market data IO, decision flow, or execution IO children;
- change `PortfolioState::new` defaults or debug assertion conditions/messages;
- add sibling horizontal links;
- change downstream runtime/backend/compiler behavior;
- introduce release-transition optimization.

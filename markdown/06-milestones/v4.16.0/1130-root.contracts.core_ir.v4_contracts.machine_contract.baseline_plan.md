## Frozen Validation Surface

`V4MachineContract::validate_static_contract` must move intact and preserve these checks:

- schema version equals `V4_MACHINE_CONTRACT_VERSION`;
- `machine_id` is non-empty;
- at least one state exists;
- state IDs are non-empty and unique;
- exactly one initial state exists;
- state group IDs are non-empty and unique;
- state groups reference known states;
- states reference known groups;
- transition IDs are non-empty and unique;
- transition `from_state` and `to_state` reference known states;
- transition event type is non-empty;
- memory field names are non-empty and unique;
- memory field `type_name` is non-empty;
- non-nullable memory fields must have `default_value`;
- transition `action.memory_writes` reference declared memory fields;
- child machines have non-empty IDs;
- child machine IDs must not equal parent machine ID;
- child machine IDs are unique under one parent;
- child machine template matches parent template;
- child machines may not contain another child machine;
- child machine validation errors remain recursively prefixed with parent state/machine context;
- pinned machines with `ReturnLastThenRecover` cache policy must use `ManualRecover`.

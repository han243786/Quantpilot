## White-Box Contract

The child may call parent-owned private lookup helpers through `super::*`.

The child must expose only `pub(super)` evaluator entrypoints required by the parent registry. Public API remains unchanged.

## Split Decision

`continue_split: true`

Reason:

- Spread and Custom share typed `SeriesExpr` materialization, value projection, aggregation, and alignment machinery;
- splitting Spread and Custom before moving shared expression machinery would create sibling coupling and helper churn;
- the wave is expected to be large but cohesive, and later terminal-leaf scoring can decide whether it is worth splitting further.

## Equivalence Requirements

The extraction must preserve:

- Spread and Custom registry keys and dispatch behavior;
- legacy Spread quote pairing and time-skew validation;
- typed Spread resample/window/alignment behavior;
- Custom predicate, strength, scope, signal side, and reference price behavior;
- local tests covering spread/custom expression behavior.

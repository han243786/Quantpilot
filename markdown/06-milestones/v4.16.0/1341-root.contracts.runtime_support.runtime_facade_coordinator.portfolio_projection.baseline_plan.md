## White-Box Node

Inputs:

- source id
- trace id
- runtime timestamp
- normalized market data
- current portfolio state
- open orders
- positions

Outputs:

- `RuntimeEventType::PortfolioUpdated` event payload
- quote lookup map by exchange and symbol
- refreshed mark prices
- refreshed unrealized PnL
- exchange exposure projection
- total gross and net notional
- total leverage and per-exchange leverage
- updated portfolio timestamp

Internal behavior to preserve:

- `portfolio_equity_estimate` stays `cash_balance + total_net_notional`
- stale mark prices remain unchanged when no fresh quote exists
- non-positive mark prices fall back to `avg_entry_price.max(0.01)`
- exposure projection groups gross and net notional by exchange
- leverage uses the same proportional equity floor
- portfolio update event keeps the same event id, event type, trace id, source id, timestamp, and payload fields

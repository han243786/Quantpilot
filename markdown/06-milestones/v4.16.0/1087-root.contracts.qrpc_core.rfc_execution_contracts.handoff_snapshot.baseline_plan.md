## Summary

This baseline freezes the handoff snapshot contract family before extraction from `qrpc_core/src/rfc_execution_contracts.rs`.

The next implementation step may move only `HandoffSnapshot` and `HandoffSnapshot::validate_completeness` into a private child module under the RFC execution parent. Public names must remain available through the RFC execution parent facade and the qrpc-core crate root facade.

## Frozen Surface

The selected child owns:

- `HandoffSnapshot`;
- `HandoffSnapshot::validate_completeness`.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Handoff snapshot DTO | `HandoffSnapshot` keeps `snapshot_id`, `source_strategy_id`, `positions`, `open_orders`, `cash_balance`, `available_cash_balance`, `frozen_cash_balance`, `current_cycle`, and `snapshot_at_ms`. |
| Positions | `positions` remains `BTreeMap<Symbol, f64>`. |
| Open orders | `open_orders` remains `Vec<Order>` and must continue using the parent-mediated RFC execution order contract. |
| Balances and cycle | Balance fields remain `f64`; `current_cycle` and `snapshot_at_ms` remain `u64`. |
| Empty snapshot ID validation | Empty `snapshot_id` continues pushing the current message string unchanged. |
| Empty strategy ID validation | Empty `source_strategy_id` continues pushing the current message string unchanged. |
| Open order ID validation | Each open order with empty `order_id` continues pushing the current formatted message using `order.instrument` unchanged. |
| Validation order | `snapshot_id`, `source_strategy_id`, then `open_orders` iteration order remains unchanged. |
| Result contract | Returns `Ok(())` when no errors are collected; otherwise returns `Err(errors)`. |
| Derives and serde | Current `Debug`, `Clone`, `Serialize`, `Deserialize`, and `PartialEq` remain unchanged. |
| Public facade | Existing public names remain available through `qrpc_core::*`. |

## Planned Extraction Shape

BE-001TA-02 may:

- create `qrpc_core/src/rfc_execution_contracts/handoff_snapshot.rs`;
- add `mod handoff_snapshot;` and `pub use handoff_snapshot::*;` to `qrpc_core/src/rfc_execution_contracts.rs`;
- move only the frozen surface listed above;
- import serde, `BTreeMap`, `crate::Symbol`, and parent-mediated `super::Order`;
- leave the RFC execution parent as a pure facade over child modules.

## Split Rule Pre-Check

| Rule | Baseline result |
| --- | --- |
| Physical owner | Worth extracting. Handoff snapshot schema plus validation is an independent compatibility contract. |
| Public surface | Continue only at this layer. Public item names remain preserved through parent facades. |

## Decision

`actual_extraction: false`

The helper pocket stays parent-owned for this pass.

## Rationale

The extracted evaluator children use these helpers through parent-mediated `super::*` access.

Moving the helper pocket into a physical child now would either:

- introduce sibling helper imports from closed evaluator children;
- force parent wrapper churn around many private helpers;
- widen helper visibility without reducing public API complexity;
- split formula helpers away from local tests before the dedicated test-harness step.

Parent ownership is the cleaner boundary under the current hard rule that child modules communicate through their parent.

## Preserved Boundaries

| Boundary | Requirement |
| --- | --- |
| Parent mediation | Closed evaluator children keep using helpers through the parent module. |
| Public API | No helper is promoted to crate-public API. |
| Sibling shortcut | No child imports a sibling helper module. |
| Test boundary | Tests remain queued separately under `test_harness`. |
| Release transition | No performance bypass or horizontal connection is proposed. |

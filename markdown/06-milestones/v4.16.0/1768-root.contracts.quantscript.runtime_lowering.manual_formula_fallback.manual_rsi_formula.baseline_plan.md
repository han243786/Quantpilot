## Objective

Freeze the RSI manual formula fallback boundary before extraction.

The next movement may extract only the current RSI fallback recognizer from
`quantscript/src/lowering/fallback.rs` into a child module. Public caller
behavior must remain equivalent:

- `resolve_manual_formula_binding` must still try RSI first;
- `manual_rsi_from_expr` must still return `IndicatorBinding::Rsi` with the
  same source, period, and `RsiMethod` mapping;
- `match_manual_rsi_formula` must still return the same
  `SourcePeriodSmoothingMatch` or no-match result;
- alias recursion, RS shell parsing, balanced gain/loss smoothing checks, and
  no-match behavior must not change.

The extraction must not move or rewrite:

  RSI branch through the child;

  boundary lookback, and fallback test logic;
- `EmaSpreadMatch`, `MacdLineSignalMatch`, and their helper flow;
- shared binding source decoders, semantic helpers, data source lookup helpers,
  and expression number helpers.

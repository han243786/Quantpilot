## Public Surface Decision

Reason:

- it is a public function, not a private helper;
- moving it would require either public re-export policy or a wrapper;
- this wave can remove the private reservation/accounting pocket without touching public API;
- keeping it parent-owned avoids churn while preserving the current crate surface exactly.

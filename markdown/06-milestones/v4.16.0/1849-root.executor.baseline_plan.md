## Goal

Freeze the Rust executor boundary before recursive child handling.

`root.executor` covers the standalone execution process under `src-executor`.
This baseline does not include frontend executor UI files.

| Path | Initial owner note |

## Child Queue

| Order | Child | Initial scope |
| --- | --- | --- |
| 1 | `executor.state` | state, audit, guard, credential support |
| 2 | `executor.runner` | runner pool, migration API, market feed, OKX REST, kline buffer |

## Parent Rules

- Executor state must only be mutated through executor-owned APIs.
- Backend/runtime must not directly mutate executor internals.
- Runner communication must stay behind migration/API boundaries.
- Release-transition shortcuts remain forbidden unless the developer explicitly
  starts a release-transition phase.

## Initial Equivalence Guard

The next child handling should preserve:

- executor HTTP route shapes;
- execution-mode behavior;
- state load/recovery behavior;
- audit append behavior;
- runner registration and market feed wiring;
- OKX demo order path semantics.

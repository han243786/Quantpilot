## Decision

Extract `validation_capability_helpers` as a dedicated simulated execution child.

The extraction moved admission validation, capability derivation, conditional-order classification, trigger evaluation, fill price math, and limit marketability helpers out of the parent include while preserving error text, validation order, capability sets, fill price math, and parent-mediated sibling access.

- sibling children continue to import helpers through the simulated execution parent with `use super::*`;
- no sibling child imports `validation_capability_helpers` directly;
- helper visibility is limited to `crate::v4_runtime`, matching the existing parent `pub(super)` re-export boundary required by Rust;
- direct-submit orchestration remains in the parent include and only calls the helper surface through the parent module.

No release-transition optimization, hot-path sibling horizontal connection, route/schema change, persistence owner change, runtime mode change, or test rewrite was introduced.

## Summary

This baseline freezes the order contract family before extraction from `qrpc_core/src/rfc_execution_contracts.rs`.

The next implementation step may move only `OrderStatus`, `OrderStatus::can_transition_to`, and `Order` into a private child module under the RFC execution parent. Public names must remain available through the RFC execution parent facade and the qrpc-core crate root facade.

## Frozen Surface

The selected child owns:

- `OrderStatus`;
- `OrderStatus::can_transition_to`;
- `Order`.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Order status taxonomy | `OrderStatus` keeps `Created`, `Submitted`, `Accepted`, `PartiallyFilled`, `Filled`, `Cancelled`, `Rejected`, and `Expired`. |
| Terminal-state guard | `Filled`, `Cancelled`, `Rejected`, and `Expired` continue returning `false` for every next state. |
| Created transitions | `Created -> Submitted`, `Created -> Cancelled`, and `Created -> Rejected` remain allowed. |
| Submitted transitions | `Submitted -> Accepted` and `Submitted -> Rejected` remain allowed. |
| Accepted transitions | `Accepted -> PartiallyFilled`, `Accepted -> Cancelled`, `Accepted -> Rejected`, and `Accepted -> Expired` remain allowed. |
| PartiallyFilled transitions | `PartiallyFilled -> PartiallyFilled`, `Filled`, `Cancelled`, `Rejected`, and `Expired` remain allowed. |
| All other transitions | All transitions not listed above remain rejected. |
| Order DTO | `Order` keeps `order_id`, `client_order_id`, `exchange`, `instrument`, `side`, `order_type`, `price`, `quantity`, `executed_qty`, `time_in_force`, `status`, `source_intent_id`, `source_agent_id`, `venue_order_id`, `created_at_ms`, and `updated_at_ms`. |
| Derives and serde | Current `Debug`, `Clone`, `Copy` where present, `Serialize`, `Deserialize`, `PartialEq`, and `Eq` where present remain unchanged. |
| Public facade | Existing public names remain available through `qrpc_core::*`. |

## Planned Extraction Shape

BE-001SW-02 may:

- create `qrpc_core/src/rfc_execution_contracts/order_contract.rs`;
- add `mod order_contract;` and `pub use order_contract::*;` to `qrpc_core/src/rfc_execution_contracts.rs`;
- move only the frozen surface listed above;
- import serde plus public `Exchange`, `OrderSide`, `OrderType`, `Symbol`, and `TimeInForce`;
- leave feedback and handoff contracts in the parent file.

- move feedback or handoff contracts;
- reopen closed qrpc-core children, `data_request`, or `allocation`;

- create direct sibling shortcuts.

### What changes in `qrpc_compiler/src/lib.rs`

1. Add `pub mod strategy_ir_lowering;` after existing `mod` declarations
2. Replace inlined `lower_strategy_ir_to_core_ir` body with delegation: `strategy_ir_lowering::lower_strategy_ir_to_core_ir(strategy_ir)`
3. Make shared helpers `pub(crate)` so child can access via `use super::`
4. Keep all imports, public facades, shared helpers, and tests unchanged

### Parent-child communication

```text
qrpc_compiler::lib (parent facade)
  ├── pub fn lower_strategy_ir_to_core_ir(...) → delegates to child
  ├── pub(crate) shared helpers (parse, build, decode)
  ├── mod runtime_protocol_validation (child, closed)
  ├── mod runtime_protocol_lowering (child, closed parent facade)
  └── mod strategy_ir_lowering (new child)
        ├── lower_strategy_ir_to_core_ir
        └── private helpers (indicator, logic, spread, custom)
```

No sibling horizontal link. Both runtime and strategy children access shared helpers via `use super::`.

### Public API preserved

External callers (`src/graph_api.rs`, `src/compile_api.rs`) continue to call `qrpc_compiler::lower_strategy_ir_to_core_ir(&strategy_ir)` — no import path change.

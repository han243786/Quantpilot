- missing venue matrix required capability uses `V4CAP200`
- undeclared required capability uses `V4CAP201`
- mode/source rejection uses `V4CAP202`
- invalid plugin manifest uses `V4CAP300`
- missing required plugin uses `V4CAP301`

Frozen report validation:

- accepted verdict is required
- graph, venue, and runtime mode must resolve
- execution submission must not be attached
- error diagnostics are surfaced as `code target: message`
- each required execution capability must have a required supported execution entry
- each required plugin must have a required accepted plugin entry

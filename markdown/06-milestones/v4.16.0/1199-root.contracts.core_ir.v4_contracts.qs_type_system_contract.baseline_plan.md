## Summary

`root.contracts.core_ir.v4_contracts.qs_type_system_contract` freezes the equivalence baseline for extracting the
QS type system contract family from `qrpc_core_ir/src/v4.rs`.

Frozen public surface:

- `QsTypeSystemContract`
- `QsScalarTypeKind`
- `QsCompositeTypeKind`
- `QsCompositeTypeSpec`
- `QsTypeRef`
- `V4_FIRST_WAVE_QS_SCALAR_TYPES`
- `V4_FIRST_WAVE_QS_COMPOSITE_TYPES`
- `v4_first_wave_scalar_types`
- `v4_first_wave_composite_types`
- `default_v4_qs_type_system_contract`
- `QsTypeSystemContract::validate_static_contract`
- `QsTypeSystemContract::validate_type_ref`

Frozen internal child helpers:

- `QsTypeSystemContract::validate_type_ref_inner`
- `QsTypeSystemContract::validate_composite_ref`
- `default_qs_type_system_version`
- `default_qs_scalar_types`
- `default_qs_composite_type_specs`
- `default_qs_type_max_nesting_depth`

Frozen behavior:

- the 23 first-wave QS scalar type list and order remain unchanged
- the 5 first-wave QS composite type list and order remain unchanged
- default composite type specs remain Optional/List/Map/Fresh/Stale with existing max_items and replay_safe values
- default max nesting depth remains `V4_QS_TYPE_MAX_NESTING_DEPTH`
- static validation keeps the current schema version, zero nesting depth, duplicate scalar, missing first-wave scalar,
  duplicate composite, composite max_items, replay_safe, and missing first-wave composite error strings
- type-ref validation keeps the current nesting depth, undeclared scalar, undeclared map key, missing composite,
  required max_items, and upper-bound error strings

Allowed extraction:

- add `mod qs_type_system_contract;` to `qrpc_core_ir/src/v4.rs`
- re-export the child through `pub use qs_type_system_contract::*;`
- create `qrpc_core_ir/src/v4/qs_type_system_contract.rs`
- move QS type DTOs, enums, constants, public constructors, and public validation methods
- move the private QS type-ref/composite validation helpers with `QsTypeSystemContract`
- move QS serde default helpers required by the moved DTOs
- import schema identity constants from the v4 surface

Forbidden movement:

- schema identity constants, version manifest orchestration, plugin governance, reproducibility, complexity budget,
  developer learning pipeline, static contract bundle, compile-time capability report, compatibility bridge, bridge
  builders, tests, machine contract, machine graph contract, QS state machine profile, runtime mode contract, and venue
  capability matrix

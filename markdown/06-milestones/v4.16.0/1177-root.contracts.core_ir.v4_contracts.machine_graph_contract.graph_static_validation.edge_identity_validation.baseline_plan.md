## Summary

`root.contracts.core_ir.v4_contracts.machine_graph_contract.graph_static_validation.edge_identity_validation`
freezes the equivalence baseline for extracting the graph edge identity and endpoint checks from
`qrpc_core_ir/src/v4/machine_graph_contract/static_validation.rs`.

Frozen behavior:

- blank `edge_id` must still emit `edge_id is required`
- duplicate nonblank `edge_id` must still emit `duplicate edge `{edge_id}``
- blank `event_type` must still emit `edge `{edge_id}` must declare an event_type`
- unknown source endpoint must still emit `edge `{edge_id}` references unknown source_machine_id `{source_machine_id}``
- unknown target endpoint must still emit `edge `{edge_id}` references unknown target_machine_id `{target_machine_id}``
- self-loop edges must still emit `edge `{edge_id}` must not connect a machine to itself`
- validation branch order remains edge ID, event type, source endpoint, target endpoint, self-loop for each edge

Allowed extraction:

- add `mod edge_identity_validation;` to the parent static validation module
- create `qrpc_core_ir/src/v4/machine_graph_contract/static_validation/edge_identity_validation.rs`
- move only the edge inventory loop and local duplicate-ID set into the child
- expose a private child helper that receives the parent-produced machine map and returns `Vec<String>`
- preserve parent orchestration order by extending edge identity errors before DAG/event/risk validation

Forbidden movement:

- schema version, graph ID, and empty machine-list checks
- `machine_identity_validation`, `graph_acyclic_validation`, `event_usage_validation`, and `risk_plane_validation`
- `machine_event_party_allowed`
- graph schema DTOs, traversal helpers, bridge builders, and tests

Expected child helper shape:

```rust
pub(super) fn validate_edge_identity(
    &self,
    machines_by_id: &BTreeMap<&str, &V4MachineContract>,
) -> Vec<String>
```

The helper may import `BTreeMap`, `BTreeSet`, `V4MachineContract`, and `V4MachineGraphContract`
inside the child file.

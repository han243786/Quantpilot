## Summary

`root.contracts.qrpc_core.strategy_ir.root_validation.data_execution_validation` has been extracted from `root_validation.rs` into a private child module.

The root validation parent preserves the original validation order:

1. identity/readiness validation;
2. signal and logic validation;
3. risk validation;
4. data requirement and execution validation;
5. unknown path/reason validation.

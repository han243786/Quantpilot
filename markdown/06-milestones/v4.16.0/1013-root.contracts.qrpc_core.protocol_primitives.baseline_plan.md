## Summary

This baseline freezes the next qrpc-core child before extraction.

The next implementation step may move only the primitive constants, primitive enums, small primitive impls, and primitive defaults from `qrpc_core/src/lib.rs` into a private child module under the qrpc-core crate root.

The already closed error, event envelope, plugin contract, and Strategy IR children remain authoritative. This baseline narrows the next safe movement without changing Rust source code.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Version strings | All version constants keep exact string values. |
| Symbol parsing | `Symbol::parse` still trims and uppercases input, maps `BTCUSDT` to `BtcUsdt`, and preserves other symbols as uppercase `Other`. |
| Symbol serialization | `Symbol` still serializes through `as_str`. |
| Symbol deserialization | Empty or whitespace-only strings still fail with the same custom diagnostic; non-empty strings still parse through `Symbol::parse`. |
| Primitive enum serde | Existing derives and `serde(rename_all = "snake_case")` attributes remain unchanged. |
| Defaults | `RiskDecisionMode::default` remains `Normal`; `SourceHealth::default` remains `Healthy`. |
| OrderSide display | `OrderSide` display still uses JSON serialization with debug fallback. |
| Public facade | Existing root exports remain available through `qrpc_core::*`. |

## Planned Extraction Shape

BE-001RO-02 may:

- create `qrpc_core/src/protocol_primitives.rs`;
- add `mod protocol_primitives;` to `qrpc_core/src/lib.rs`;

- move only the frozen primitive surface listed above;
- keep `DataQualitySnapshot`, `DataSourceConfig`, runtime protocol config, artifact specs, runtime IO DTOs, RFC execution contracts, and tests in `lib.rs`.

## Same-Parent Parallel Wave Judgment

This child remains a single-child extraction for BE-001RO-02.

`same_parent_parallel_children` is not activated because later qrpc-core children depend on these primitive surfaces. Serial extraction keeps the crate root facade stable before heavier schema-bearing modules move.

## Hard Boundaries

BE-001RO-02 must not:

- change version strings, enum variants, serde attributes, symbol parsing behavior, display behavior, default values, public exports, tests, digest behavior, or schema field shapes;
- move `DataQualitySnapshot`, `DataSourceConfig`, runtime protocol config structs, artifact specs, runtime IO DTOs, RFC execution contracts, or tests;
- change closed error/proto/plugin/strategy IR contracts;
- change `qrpc_core_ir`, `qrpc_compiler`, `qrpc_runtime`, `quantscript`, backend, executor, frontend, physical `plugins/*`, or release transition;
- create direct sibling shortcuts to later qrpc-core residuals.

## Split Rule Pre-Check

| Rule | Baseline result |
| --- | --- |
| Physical owner | Worth extracting. The selected slice is a coherent primitive surface currently embedded in a large crate-root file. |
| Public surface | Continue only at this layer. The child preserves public item names through the crate facade. |
| Mixed responsibility | Stop after extraction unless primitive groups create separate stable pressure. For now they form one foundational protocol primitive family. |
| State ownership | Stop after extraction. The child owns no runtime state. |
| Side effects | Stop after extraction. No IO, persistence, locks, runtime state, or external side effects are involved. |
| Parent-mediated dependency | Required. Later qrpc-core children consume primitives through the crate-root facade. |
| Future reopen rule | Allowed only for concrete version, primitive enum, symbol parsing, serde/display/default, or public facade proposals. |

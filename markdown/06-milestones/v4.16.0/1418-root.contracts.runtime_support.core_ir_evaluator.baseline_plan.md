## White-Box Responsibilities

`root.contracts.runtime_support.core_ir_evaluator` owns:

- Core IR indicator evaluation API and builtin registry dispatch;
- classic indicator evaluators: MA family, RSI, MACD, Momentum, ZScore, and QuoteObserve;
- advanced indicator evaluators: ATR, Bollinger Bands, OBV, CMF, ADX, Stochastic, CCI, Parabolic SAR, Keltner Channel, and Donchian Channel;
- Spread and Custom evaluator entrypoints;
- typed spread expression evaluation, series materialization, resampling, alignment, and window aggregation;
- custom predicate/value expression evaluation, custom scope, strength, signal side, and reference price derivation;
- kline/quote lookup, parameter defaulting, threshold scaling, moving average, EMA/SMA, and indicator math helpers;
- local evaluator fixtures and tests.

- move MA/RSI/MACD/Momentum/ZScore/QuoteObserve evaluator functions into `classic_indicator_wave`;
- move ATR/Bollinger/OBV/CMF/ADX/Stochastic/CCI/Parabolic SAR/Keltner/Donchian evaluator functions into `advanced_indicator_wave`;

## Remaining Parent Surface

- public audit and runtime-handoff entrypoints;
- public report DTOs and verdict enum;
- private parent wrappers used by child modules;
- the tiny `parse_machine_template` enum mapping;
- local static-audit tests.

## Why No More Child Split

- `parse_machine_template` is a micro enum mapping, not a standalone owner.
- Moving it would reopen an already closed child or create a governance-heavy
  micro leaf with little system benefit.
- DTOs and tests are intentionally parent-owned because they define the public
  surface and local equivalence harness.
- Parent-child communication remains explicit through the parent wrappers.

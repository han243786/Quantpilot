## Scope

Freeze deprecated config-style QuantScript compatibility before extracting it out of the crate root.

This child owns the legacy QS config path kept only for compatibility while formal QuantScript remains the supported product path.

## Physical Boundary

Current owner file:

- `quantscript/src/lib.rs`

Candidate child file:

- `quantscript/src/legacy_config_compat.rs`

## Public API To Preserve

Deprecated compatibility entrypoints:

- `parse_quant_script`
- `parse_quant_script_source`
- `parse_quant_script_config`
- `compile_quant_script`
- `compile_quant_script_file`

Compatibility conversion:

- `compile_program_to_config`

Public DTOs:

- `QuantScriptProgram`
- `RuntimeSection`
- `DataSection`
- `IntentSection`
- `AgentSection`
- `RiskSection`
- `QuantScriptSource`

Private implementation helpers to move with the child:

- `Token`
- `Value`
- `Parser`
- `tokenize`
- legacy field decode helpers
- legacy parse helpers for exchange, symbol, market type, data kind, intent kind
- `looks_like_config`
- `looks_like_script`
- legacy config tests and `SAMPLE_SCRIPT`

## Equivalence Requirements

Future movement must preserve:

- deprecated attributes and public API names;
- legacy config parse defaults for runtime fees, slippage, leverage, and enabled flags;
- legacy data/intent/agent/risk conversion into `RuntimeProtocolCoreConfig`;
- `compile_quant_script_file` file-read error context;
- source-kind detection behavior for config-style and formal QS source;
- legacy tests currently living in `quantscript/src/lib.rs`;
- crate-root `quantscript::*` public imports.

## Forbidden In This Child

Do not change:

- formal QS parser, AST, type, or HIR modules already closed under `syntax_ast_surface`;
- formal parse/analyze/lower APIs such as `parse_formal_quant_script_config`, `parse_formal_quant_script_typed_hir`, `analyze_formal_quant_script`, or `extract_formal_instrument_pool_spec`;
- typed resolution, analysis, evaluator, lowering, v4 static audit, test-plan extraction, docs/samples, backend, runtime, executor, frontend, or release-transition behavior.

## Expected Movement Shape

BE-002FZ-02 may:

- add `mod legacy_config_compat;` to `quantscript/src/lib.rs`;
- move only the legacy config DTOs, deprecated entrypoints, parser helpers, and legacy tests into `quantscript/src/legacy_config_compat.rs`;
- re-export the public DTOs and deprecated functions from the crate root;
- keep formal QS APIs in the crate root as parent facade functions.

## Movement Summary

`quantscript/src/v4_static_audit/static_document_parser.rs` now owns the
top-level v4 static-audit document parser boundary.

Moved implementation:

- `ParsedV4QsStaticDocument`;
- `parse_v4_static_document` implementation body;
- top-level `v4_strategy` header validation;
- venue, mode, required capability, required type, and required plugin parsing;
- machine block, edge, and risk-plane delegation;
- graph metadata assembly for `default_venue_id` and `market_event_source`;
- graph construction and compile-time capability request construction.

The parent `quantscript/src/v4_static_audit.rs` now declares
`mod static_document_parser;`, keeps a private parent wrapper named
`parse_v4_static_document`, and exposes a private `derive_event_catalog` bridge
so the document parser still reaches event catalog derivation through the parent
boundary.

## Preserved Boundaries

- Public API unchanged.
- `audit_entrypoint` still calls the parent `parse_v4_static_document` wrapper.
- Machine, state, memory, transition, edge, and risk-plane parser bodies remain
  parent-owned.
- Capability/type parser helpers remain in the closed `capability_type_parser`
  child and are reached through parent wrappers.
- Parser utilities remain in the closed `parser_utilities_diagnostics` child and
  are imported through the parent module.
- Event catalog derivation remains in the closed `event_catalog_derivation`
  child and is reached through the parent bridge.
- Public report DTOs and local static-audit tests remain parent-owned.
- No release-transition link was introduced.

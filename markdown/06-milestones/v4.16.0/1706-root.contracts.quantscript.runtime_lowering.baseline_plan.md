## Baseline Decision

`root.contracts.quantscript.runtime_lowering` is frozen as an existing parent subtree.

The next recursive step must be a parent residual judgment inside this subtree, not a direct all-in extraction. The subtree already lives under `quantscript/src/lowering/`, and its internal files expose several durable child owners.

| Surface | Visibility | Owner |

| `LoweringContext` | `pub` re-export | `quantscript/src/lowering/context.rs` through `mod.rs` |

| `extract_instrument_pool_spec` | `pub(crate)` re-export | `quantscript/src/lowering/universe.rs` through `mod.rs` |

Public behavior must remain equivalent:

- script lowering still normalizes universe constructs before strategy selection;
- diagnostics still accumulate parse/lowering binding diagnostics in the same outward error shape;
- inferred data sources, indicator bindings, intents, risk profile, execution profile, and runtime config output stay semantically unchanged;
- `lower_script_to_runtime_config` must remain a default-context wrapper over `lower_script_to_runtime_config_with_context`.

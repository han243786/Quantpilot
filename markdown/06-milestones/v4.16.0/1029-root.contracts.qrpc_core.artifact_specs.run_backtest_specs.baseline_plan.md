## Summary

This baseline freezes the qrpc-core run/backtest artifact spec surface before extraction.

The next implementation step may move only run/backtest modes, dataset and execution assumption projections, market data snapshot specs, `RunSpec`, and `BacktestSpec` from `qrpc_core/src/artifact_specs.rs` into a private child module under the artifact specs parent.

## Selected Surface

The selected child owns:

- `RunModeSpec`;
- `BacktestReplaySource`;
- `DatasetSpec` and `DatasetSpec::from`;
- `ExecutionAssumptionSpec`;
- `ExecutionAssumptionValueSource`;
- `ExecutionAssumptionSourceSummary`;
- `ExecutionAssumptionSpec::from`;
- `MarketDataSnapshotSpec` and `MarketDataSnapshotSpec::from_runtime_protocol`;
- `RunSpec`;
- `RunSpecRuntimeProtocolInput`;
- `RunSpec::from_runtime_protocol`;
- `BacktestSpec` and `BacktestSpec::new`.

`StrategyArtifactSourceKind` is intentionally excluded from this child. It belongs with the artifact bundle contract because it describes strategy artifact source taxonomy.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Run mode enum | `RunModeSpec` keeps `Paper` and `Backtest` with snake_case serde. |
| Replay source enum | `BacktestReplaySource` keeps `HistoricalReplay` and `DeterministicMock` with snake_case serde. |
| Dataset projection | `DatasetSpec::from(&DataSourceConfig)` keeps dataset/data id cloning, primitive clones, interval/day mapping, and enabled propagation. |
| Execution assumption source enum | `ExecutionAssumptionValueSource` keeps backend/profile/request variants with snake_case serde. |
| Execution assumptions | `ExecutionAssumptionSpec::from(&RuntimeProtocolCoreConfig)` keeps cash/cost fields, `TimeInForce::Gtc`, partial fills true, and no latency assumption. |
| Snapshot projection | `MarketDataSnapshotSpec::from_runtime_protocol` keeps snapshot id/source/time inputs and maps runtime data sources into datasets. |
| Run spec projection | `RunSpec::from_runtime_protocol` keeps `RUN_SPEC_V1_VERSION`, input assignment, dataset projection, execution assumption projection, no source summary, and core IR digest. |
| Backtest constructor | `BacktestSpec::new` keeps `BACKTEST_SPEC_V1_VERSION`, id/source/time/run spec/snapshot assignment. |
| Public facade | Existing crate-root public names remain available through `qrpc_core::*`. |

## Summary

`root.contracts.compiler_bridge.runtime_protocol_lowering` is frozen before physical Rust movement.

This child owns runtime protocol config to Core IR lowering behavior and the direct runtime lowering public entrypoint. The next movement may create a compiler bridge child module for runtime lowering while preserving the parent public facade.

Decision:

`baseline_frozen: true`

Next movement:

`BE-001XG-01` may move only the runtime protocol lowering implementation and its runtime-only helper pocket. It must not move Strategy IR lowering, canonical hash assembly, tests, or shared spread/custom helpers without their own baselines.

## Public Surface Frozen

| Public function | Current owner meaning | BE-001XG-01 rule |

| `lower_runtime_protocol_to_core_ir` | Public runtime protocol lowering entrypoint with default runtime-protocol metadata. | Keep signature and observable output unchanged; parent may delegate to child. |
| `lower_runtime_protocol_to_core_ir_with_metadata` | Public runtime protocol lowering entrypoint with caller-provided Core IR metadata. | Keep signature and observable output unchanged; parent may delegate to child. |
| `compile_runtime_protocol_config` | Public compile facade with default metadata, validation, lowering, and hash assembly. | Keep in parent facade for this child; it may call the moved lowering function. |

| `lower_strategy_ir_to_core_ir` | Strategy IR lowering public entrypoint. | Hard excluded from this child. |

## Equivalence Baseline

BE-001XG-01 must preserve:

- default metadata for `lower_runtime_protocol_to_core_ir`;
- caller metadata override behavior for `lower_runtime_protocol_to_core_ir_with_metadata`;
- execution rule ids, venue kind, sizing kind, slippage/fee/cost params, and time-in-force defaults;
- data binding source hints, including `exchange`, `symbol`, `timeframe`, `ping_enabled`, and `request_interval_ms`;
- enabled intent filtering and indicator/signal order;
- enabled agent/risk filtering and policy field defaults;
- structured comparison output for MA, RSI, Momentum, ZScore, and QuoteObserve spread branches;
- fallback raw-text condition behavior for non-structured runtime intents;
- DAG validation timing and error surface.

## Hard Exclusions

This baseline must not:

- change any public signature;
- move or alter Strategy IR lowering;
- move or alter canonical config hash generation;
- move or alter `CompiledRuntimeProtocol` assembly semantics;
- move tests out of `qrpc_compiler/src/lib.rs`;
- change runtime protocol validation behavior or validation ordering;
- start release transition or introduce sibling links.

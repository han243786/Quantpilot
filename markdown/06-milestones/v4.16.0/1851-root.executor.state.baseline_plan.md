## Goal

Freeze the executor state boundary before Rust movement.

The next movement may extract only executor state API handlers from
`src-executor/main.rs` into a state route child while preserving route shapes
and state behavior.

## Frozen Boundary

| Field | Value |
| --- | --- |
| Planned new file | `src-executor/state_routes.rs` |
| Parent file | `src-executor/main.rs` |
| Existing state files | `executor_state.rs`, `audit_log.rs`, `api_guard.rs`, `credential_vault_v2.rs` |
| Approved handlers | `health_check`, `get_mode`, `set_mode`, `get_params`, `update_params` |
| Approved helper movement | `SetModeRequest`, `validate_hot_param_value`, route-local audit append helper if needed |
| Parent retained | route registration, process startup, runner wiring, strategy lifecycle, OKX demo routes |

## Equivalent Behavior

The extracted state route child must preserve:

- `/api/executor/health` response shape;
- `/api/executor/mode` GET/POST behavior;
- deferred/invalid mode error payload behavior;
- `/api/executor/params/:strategy_id` GET/POST behavior;
- pending params rollback snapshot behavior;
- hot parameter validation behavior;
- audit append behavior for state route mutations.

## Exclusions

- Do not move strategy deploy/start/stop/list/detail handlers.
- Do not move SSE event stream handlers.
- Do not move OKX demo provider handlers or credential loading.
- Do not move runner, migration, websocket, kline, or OKX REST modules.
- Do not alter execution mode semantics.
- Do not introduce release-transition cross-module links.

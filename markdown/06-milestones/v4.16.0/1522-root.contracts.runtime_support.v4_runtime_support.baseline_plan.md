## Scope

`root.contracts.runtime_support.v4_runtime_support` freezes the current v4 runtime support boundary before movement.

Physical scope:

- `qrpc_runtime/src/v4_runtime.rs`
- `qrpc_runtime/src/v4_runtime_types.rs`
- `qrpc_runtime/src/v4_simulated_execution.rs`
- `qrpc_runtime/src/v4_runtime_tests.rs`

Current physical structure uses `include!("v4_runtime_types.rs")` at the top of `v4_runtime.rs` and `include!("v4_simulated_execution.rs")` near the end of `v4_runtime.rs`. The baseline must preserve that behavior until a later extraction explicitly replaces it with parent-mediated module declarations.

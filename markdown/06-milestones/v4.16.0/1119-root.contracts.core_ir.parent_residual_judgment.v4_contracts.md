`v4_contracts` is selected because it is the only remaining production child before qrpc-core-ir crate facade closeout:

- `qrpc_core_ir/src/lib.rs` is already a small facade over `v1` and `v4`;

- `qrpc_core_ir/src/v4.rs` remains parent-sized and mixed-responsibility;
- v4 owns state-machine contract DTOs, static validators, runtime mode/type contracts, plugin/reproducibility/complexity contracts, compile-time capability reports, Core IR compatibility bridge, venue matrix helpers, and local tests.

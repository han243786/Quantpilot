## Selection Rationale

`runtime_protocol_config` is selected because it is the next contiguous schema-bearing region after protocol primitives:

- it owns `DataQualitySnapshot`;
- it owns `RuntimeEventType`;
- it owns `DataSourceConfig`;
- it owns universe asset metadata/snapshot config DTOs;
- it owns `IntentConfig`, `AgentConfig`, and `RiskConfig`;
- it owns global risk/profile default constants and paper execution defaults;
- it owns `RuntimeProtocolCoreConfig` and `RuntimeProtocolCoreConfig::default`;
- it owns `CompiledRuntimeProtocol`;
- it can move before artifact specs because artifact spec builders consume runtime protocol config as an input.

## Same-Parent Parallel Judgment

`same_parent_parallel_children` remains inactive for this selection.

`artifact_specs` depends on `RuntimeProtocolCoreConfig`, `DataSourceConfig`, and related config DTOs. A serial runtime config extraction keeps the qrpc-core parent facade stable before artifact specs move.

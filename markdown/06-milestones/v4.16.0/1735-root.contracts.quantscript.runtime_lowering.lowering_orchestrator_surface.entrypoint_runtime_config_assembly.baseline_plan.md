## Baseline Decision

`entrypoint_runtime_config_assembly` is frozen as a production child for extraction.

The next movement may create a private child module under `quantscript/src/lowering/orchestrator/` and move only the runtime config assembly implementation currently inside `lower_script_to_runtime_config_with_context`.

## Frozen Input / Output

| Field | Boundary |
| --- | --- |
| Input | `ScriptModule` plus `LoweringContext` |
| Output | Existing `RuntimeProtocolCoreConfig` or existing lowering diagnostics |
| Parent caller | `lower_script_to_runtime_config_with_context` public facade |
| Error surface | Existing `QPQSLOW000`, `QPQSLOW006`, `QPQSLOW007`, semantic analysis diagnostics, and `anyhow` context remain equivalent |
| Gate | `cargo test -p quantscript` plus `cargo check -p quantpilot` |

## Symbols Approved For Movement

Move only:

- the private assembly body behind `lower_script_to_runtime_config_with_context`
- private error constants used only by that assembly
- imports needed only by that child

The child may expose a parent-visible function such as `assemble_runtime_config_with_context`.

## Symbols Explicitly Not Approved For Movement

- public `lower_script_to_runtime_config`
- public `lower_script_to_runtime_config_with_context`
- public re-export declarations in `quantscript/src/lowering/mod.rs`
- `profile_detection_surface` implementation
- `integration_test_harness` and its child test modules
- universe, intent, binding, fallback, source recovery, semantic bridge, helper env, context, shared helpers, and diagnostics modules

## Parent Mediation Rule

After extraction:

- `orchestrator.rs` declares the private child module;
- public entrypoints remain in `orchestrator.rs`;
- public entrypoints delegate to the child through the parent-child boundary;
- return type, diagnostics, defaults, and runtime config shape remain equivalent.

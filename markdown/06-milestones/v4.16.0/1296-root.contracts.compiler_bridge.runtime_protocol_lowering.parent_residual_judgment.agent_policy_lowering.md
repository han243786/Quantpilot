## Selection Rationale

`agent_policy_lowering` is selected next because it is the largest remaining cohesive behavior pocket in `qrpc_compiler/src/runtime_protocol_lowering.rs`:

- it owns `lower_runtime_agent_to_policy`;
- it owns `lower_runtime_rebalance_schedule_to_core_ir`;
- it converts `AgentConfig` plus referenced `IntentConfig` data into one `AgentPolicy`;
- it determines agent kind, input signal ids, rebalance symbols, rebalance schedule, allocation/rank/normalize metadata, decision threshold, max quantity ratio, spread trigger, and enabled state;
- it is separate from risk policy lowering and top-level runtime orchestration;
- moving it behind one parent-mediated call can reduce the parent file without changing public APIs or Core IR output.

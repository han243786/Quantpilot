## Scope

Freeze the current QuantScript language-contract boundary before any extraction or deeper child handling.

`root.contracts.quantscript` owns:

- formal QuantScript parsing and AST/HIR public DTOs;
- typed resolution, callable classification, semantic keys, and type inference;
- unsupported construct analysis, diagnostics, warmup/lookahead checks, and authoring diagnostics;
- normalization/evaluation helpers used before lowering;
- runtime protocol lowering and instrument pool extraction;
- v4 static audit and v4 runtime handoff report generation;
- legacy config-style QuantScript compatibility entrypoints;
- test-plan extraction;
- local QS authoring guides, samples, and boundary samples.

- formal parser and AST: `parse_quant_script_module`, `parse_expr`, `ScriptModule`, `Item`, `FunctionDecl`, `Stmt`, `Expr`, `CallArg`, `TestBlock`, `StepBlock`;

- runtime lowering: `lower_script_to_runtime_config`, `lower_script_to_runtime_config_with_context`, `extract_formal_instrument_pool_spec`, `LoweringContext`, `InstrumentPool*`;

## Baseline Equivalence

Future movement must keep equivalent:

- parser acceptance/rejection behavior and error text where tested or user-facing;
- AST, HIR, diagnostic, static audit, handoff, runtime config, and test-plan serialized/observable shapes;
- formal QS lowering output consumed by backend compile routes, test runner, runtime v4 handoff, and backtest request resolution;
- legacy config-style compatibility, including deprecated public entrypoints;
- sample file semantics and authoring docs references;
- parent-mediated communication through the QuantScript crate facade and existing lowering parent.

## Forbidden In This Baseline

Do not:

- move Rust code before a child baseline/actual-extraction step;
- change QRPC Core, Core IR, compiler, runtime support, backend, executor, frontend, plugins, or E2E behavior;
- rewrite public DTO names or serialized field semantics;
- introduce child-to-child shortcuts outside the QuantScript parent;
- start release-transition optimization.

## Summary

This baseline freezes the allocation contract family before extraction from `qrpc_core/src/rfc_execution_contracts.rs`.

The next implementation step may move only `AllocationMethod`, `Allocation`, and `Allocation::apply_to_targets` into a private child module under the RFC execution parent. Public names must remain available through the RFC execution parent facade and the qrpc-core crate root facade.

## Frozen Surface

The selected child owns:

- `AllocationMethod`;
- `Allocation`;
- `Allocation::apply_to_targets`.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Allocation taxonomy | `AllocationMethod` keeps `EqualWeight`, `FixedWeight`, `RankWeight`, `ScoreWeight`, and `RiskParity`. |
| Allocation DTO | `Allocation` keeps `allocation_id`, `method`, `weights`, `total_budget`, `min_weight`, `max_weight`, `constraint_source`, and `created_at_ms`. |
| Explicit weight lookup | `apply_to_targets` keeps `self.weights.get(&tw.symbol).copied()` as the first weight source. |
| Fallback weight | Missing explicit weight continues to fall back to `tw.target_weight`. |
| Budget projection | Amount remains `self.total_budget * weight`. |
| Min/max clamp | `(Some(min), Some(max))` clamps between `min * total_budget` and `max * total_budget`; single-bound cases clamp only that side. |
| No-bound behavior | `(None, None)` keeps the raw amount. |
| Insert behavior | Results continue inserting `tw.symbol.clone()` into a `BTreeMap<Symbol, f64>`, preserving sorted map semantics and last-write behavior for duplicate symbols. |
| Derives and serde | Current `Debug`, `Clone`, `Serialize`, `Deserialize`, and `PartialEq` derives remain unchanged. |
| Public facade | Existing public names remain available through `qrpc_core::*`. |

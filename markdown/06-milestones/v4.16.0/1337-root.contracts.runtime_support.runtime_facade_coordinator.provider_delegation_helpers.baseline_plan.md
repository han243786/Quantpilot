## White-Box Node

Inputs:

- cycle name and trace id
- runtime timestamp
- normalized market data
- intent kinds
- intent signals
- agent decisions
- risk decisions
- execution plans
- mutable runtime event buffer
- coordinator state, merge engine, and provider trait objects

Outputs:

- normalized data
- intent signals
- agent decisions
- optional merge record
- risk decisions
- execution plans
- fill reports
- merge record projection
- appended runtime events
- last-action and last-rebalance state updates

Internal behavior to preserve:

- data provider event forwarding
- intent provider event forwarding
- agent provider event forwarding and rebalance timestamp updates
- pass-through merge behavior for zero or one decision
- merge engine fallback warning on merge errors
- risk provider fallback to empty decisions on risk errors
- approved-agent last-action timestamp updates
- execution planner event forwarding
- execution submitter and market-update fill forwarding

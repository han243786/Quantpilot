## Scope

`root.contracts.runtime_support.v4_runtime_support.event_replay_orchestration` freezes the v4 runtime event/replay orchestration surface before movement.

Current physical owner:

- `qrpc_runtime/src/v4_runtime.rs`

- introduce `qrpc_runtime/src/v4_runtime/event_replay_orchestration.rs`;

## Leaf Split Decision Gate

This child should be evaluated after extraction.

Expected decision:

`stop_split_after_extraction: likely`

Reason:

- The candidate is expected to stay in the terminal target size range after movement.
- Splitting bar replay from tick replay would duplicate artifact projection and decision-record collection.
- Splitting market input submission from idle draining would separate public external input from the queue drain that makes it observable.
- Any deeper split should be rejected unless the extracted child exceeds the terminal range or exposes a stronger independent owner.

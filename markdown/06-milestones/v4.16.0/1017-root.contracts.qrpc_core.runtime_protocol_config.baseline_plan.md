## Summary

This baseline freezes the next qrpc-core child before extraction.

The next implementation step may move only runtime protocol config DTOs, universe metadata config DTOs, risk/execution default constants, `RuntimeProtocolCoreConfig::default`, and `CompiledRuntimeProtocol` from `qrpc_core/src/lib.rs` into a private child module under the qrpc-core crate root.

The already closed qrpc-core primitive child remains authoritative. Artifact specs, runtime IO contracts, RFC execution contracts, and tests remain parent-owned for later recursive steps.

## Split Rule Pre-Check

| Rule | Baseline result |
| --- | --- |
| Physical owner | Worth extracting. The selected slice is a coherent runtime config surface currently embedded in a large crate-root file. |
| Public surface | Continue only at this layer. Public item names remain preserved through the crate facade. |
| Mixed responsibility | Stop after extraction unless universe/config/default subfamilies create separate pressure after evidence. |
| State ownership | Stop after extraction. The child owns config DTOs and defaults, not runtime state. |

| Future reopen rule | Allowed only for concrete runtime config field, serde/default, compiled protocol, universe config, or public facade proposals. |

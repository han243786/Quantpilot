## Physical Scope

This child freezes the runtime session and cycle orchestration methods currently located in `qrpc_runtime/src/runtime_facade_coordinator.rs`.

Owned methods:

- `RuntimeCoordinator::run_session`
- `RuntimeCoordinator::run_slow_cycle`
- `RuntimeCoordinator::run_fast_cycle`
- `RuntimeCoordinator::run_cycle`

Owned behavior:

- apply pending module configs at the session boundary
- call slow cycle and fast cycle in sequence
- update risk-monitor stop state after a completed session
- assemble `SessionOutput`
- choose slow-cycle intent kinds
- choose fast-cycle intent kinds
- build deterministic per-cycle trace IDs
- sequence provider helper calls inside a cycle
- retain merge decision records with the existing retention cap
- assemble `RuntimeCycleOutput`

## Exclusions

This child does not own:

- `RuntimeCoordinator` struct definition
- constructor/provider wiring
- execution submission or market data entry point public methods
- state/config accessors
- `swap_module_config`
- `apply_pending_module_configs` implementation
- `generation_history` or current generation accessors
- data, intent, agent, risk, and execution provider helper implementations
- open-order processing helper implementation
- portfolio refresh and projection helpers
- coordinator tests

## Parent/Child Communication Rules

The child must stay below `runtime_facade_coordinator`.

Allowed dependencies:

- `super::RuntimeCoordinator`
- `super::portfolio_equity_estimate`
- parent-owned private helper methods on `RuntimeCoordinator`
- `anyhow::Result`
- `qrpc_core::{IntentKind, RuntimeCycleOutput, SessionOutput}`

No sibling-to-sibling shortcut and no release-transition optimization is allowed.

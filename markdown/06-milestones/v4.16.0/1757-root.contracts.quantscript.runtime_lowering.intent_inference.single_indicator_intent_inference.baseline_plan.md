## Baseline Decision

Freeze `single_indicator_intent_inference` for actual extraction.

The next Rust movement may create a child module under `quantscript/src/lowering/intents/` and move only the single-indicator intent builder. Parent-owned condition dispatch, spread inference, MA ratio inference, legacy emit fallback, relation/id helpers, and data-source canonicalization helpers must remain in `intents.rs`.

| Field | Rule |

## Baseline

Freeze `capability_type_parser` before Rust movement.

The approved future movement is limited to pure parser helpers that convert
static-audit string tokens into runtime mode, execution capability, and QS type
contracts. The parent may directly call the child or keep thin wrappers; the
actual choice must preserve all returned values and error strings.

## Equivalent Behavior To Preserve

| Function | Baseline |
| --- | --- |
| `parse_runtime_mode` | Maps `paper_actual`, `paper_simulated`, `live_actual`, and `live_simulated` to `RuntimeTradingMode`; unknown values return the existing unknown-mode string |
| `parse_execution_capability` | Maps all current order/capability aliases to `ExecutionCapabilityKind`; unknown values return the existing unknown-capability string |
| `parse_qs_type_ref` | Recursively parses `optional`, `fresh`, `stale`, `list`, `map`, and scalar types |
| `strip_wrapper` | Preserves `<...>` wrapper stripping and trimming behavior |
| `parse_items_type_args` | Preserves `list<T,max=N>` arity and max parsing |
| `parse_max_arg` | Preserves `max=N` parsing and positive integer error behavior |
| `split_top_level_args` | Preserves nested generic comma splitting |
| `parse_qs_scalar_type` | Maps every current QS scalar literal to `QsScalarTypeKind`; unknown values return the existing unknown-type string |

## Risk Controls

- Do not change `IntentKind`, `IntentConfig`, parameter names, comparison code numbers, or structured comparison keys.
- Do not change spread operand numeric encodings, resample/align semantics, or data-source ordering.
- Do not move binding/source decoding, fallback resolution, semantic alias resolution, helper env, context, shared arg helpers, or diagnostic formatting in this baseline.
- Do not batch this parent with sibling runtime lowering owners.
- Do not introduce sibling horizontal links; all child calls must go through the parent module boundary.

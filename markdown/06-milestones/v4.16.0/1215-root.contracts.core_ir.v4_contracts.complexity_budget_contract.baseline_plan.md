## Summary

`root.contracts.core_ir.v4_contracts.complexity_budget_contract` freezes the equivalence baseline for extracting the v4
complexity budget and metrics contract from `qrpc_core_ir/src/v4.rs`.

Frozen public surface:

- `ComplexityBudgetContract`
- `ComplexityMetrics`
- `impl Default for ComplexityBudgetContract`
- `ComplexityBudgetContract::validate_static_contract`
- `ComplexityBudgetContract::validate_metrics`
- `ComplexityMetrics::from_machine_graph`

Frozen internal child helpers:

- `default_complexity_budget_contract_version`
- `default_max_nested_machine_depth`
- `default_max_event_processing_path_count`

Frozen behavior:

- default budget values remain unchanged
- every zero-valued budget field still fails with `{name} must be greater than 0`
- every metric overage still fails with `{name} {value} exceeds budget {limit}`
- graph metrics keep counting all nested machine states, transitions, and memory fields through machine-family traversal
- nested depth remains the maximum machine depth or 0 when no root machines exist
- event rate estimate remains event catalog event count multiplied by 1,000
- estimated order paths remain the count of execution-template machines
- event processing path count remains `transition_count * max(nested_machine_depth, 1)` with saturating multiplication
- stale dependency count remains 0 in graph-derived metrics

Allowed extraction:

- add `mod complexity_budget_contract;` to `qrpc_core_ir/src/v4.rs`
- re-export the child through `pub use complexity_budget_contract::*;`
- create `qrpc_core_ir/src/v4/complexity_budget_contract.rs`
- move complexity budget DTOs/defaults/validation and complexity metric calculation
- import machine graph contract, machine template kind, and graph traversal helpers through the v4 surface

Forbidden movement:

- compile-time capability report DTOs, compatibility bridge reports, static bundles, developer learning pipeline,
  reproducibility, plugin governance, tests, machine contract schema, machine graph schema, QS contracts, runtime mode,
  venue capability matrix, and version manifest

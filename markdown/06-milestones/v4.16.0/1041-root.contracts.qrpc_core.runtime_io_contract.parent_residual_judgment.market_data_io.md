`market_data_io` is selected first because it is the first contiguous DTO family in `qrpc_core/src/runtime_io_contract.rs`:

- it owns `RawKline`;
- it owns `RawQuote`;
- it owns `NormalizedKline`;
- it owns `KlineSeriesSnapshot`;
- it owns `QuoteSnapshot`;
- it owns `NormalizedMarketData`;
- it is pure schema with no helper methods, no mutable state, no IO, no locks, and no persistence;
- later decision, execution, portfolio, runtime output, and backtest DTOs can keep consuming it through the runtime IO parent facade.

## Summary

This baseline freezes the qrpc-core runtime input/output contract surface before extraction.

The next implementation step may move only runtime input/output DTOs from `RawKline` through `BacktestOutput` from `qrpc_core/src/lib.rs` into a private child module under the qrpc-core crate root.

The already closed qrpc-core children remain authoritative. RFC execution contracts beginning at `MarketScope`, crate-root tests, and downstream runtime/compiler/backend behavior remain parent-owned for later recursive steps.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Raw market input | `RawKline` and `RawQuote` keep field names, numeric types, and serde shape. |
| Normalized market data | Exchange/symbol/market type, interval/time, price/volume, quote, source status, and data quality fields remain unchanged. |
| Decision DTOs | Intent, proposed action, portfolio target, agent decision, and risk decision fields remain unchanged, including optional/default fields. |
| Execution DTOs | Sim orders, execution plans, fill reports, open orders, fill result events, and execution statuses remain unchanged. |
| Portfolio state | `PortfolioState` keeps `deny_unknown_fields`, all balances/exposures/orders/positions fields, and update timestamp. |
| Portfolio helpers | `PortfolioState::new` keeps initial cash, available cash, empty vectors, zero exposure/leverage, and timestamp assignment. `debug_assert_invariants` keeps debug-only cash/leverage/balance assertions. |
| Runtime events/output | Runtime event envelope, cycle output, session output, runtime event lists, and data fetch counts remain unchanged. |
| Backtest output/report | Equity points, risk adjusted metrics, trade analysis, drawdown analysis, benchmark comparison, summary, period returns, final portfolio, optional v4 artifact, and debug values remain unchanged. |
| Public facade | Existing crate-root public names remain available through `qrpc_core::*`. |

## Planned Extraction Shape

BE-001SB-02 may:

- create `qrpc_core/src/runtime_io_contract.rs`;
- add `mod runtime_io_contract;` to `qrpc_core/src/lib.rs`;
- add `pub use runtime_io_contract::*;` to preserve crate-root public surfaces;
- move only the frozen runtime IO surface listed above;
- keep RFC execution contracts beginning at `MarketScope` in `qrpc_core/src/lib.rs`;
- keep crate-root tests in `qrpc_core/src/lib.rs`;
- keep closed qrpc-core child modules unchanged.

## Same-Parent Parallel Wave Judgment

This child remains a single-child extraction for BE-001SB-02.

`same_parent_parallel_children` is not activated because the selected child has many public DTO surfaces plus helper methods. Serial extraction keeps qrpc-core public exports, serde compatibility, and runtime/backtest DTO boundaries stable before any deeper child split decision.

## Hard Boundaries

BE-001SB-02 must not:

- change raw/normalized market data fields, decision DTO fields, execution DTO fields, portfolio fields, runtime output fields, backtest report fields, serde attributes, helper method behavior, public exports, or tests;
- move RFC execution contracts beginning at `MarketScope`, crate-root tests, or closed qrpc-core children;
- change closed error/proto/plugin/strategy IR/protocol primitive/runtime config/artifact specs contracts;
- change `qrpc_core_ir`, `qrpc_compiler`, `qrpc_runtime`, `quantscript`, backend, executor, frontend, physical `plugins/*`, or release transition;
- create direct sibling shortcuts to closed qrpc-core children.

## Split Rule Pre-Check

| Rule | Baseline result |
| --- | --- |
| Physical owner | Worth extracting. The selected slice is a contiguous runtime IO surface currently embedded in a large crate-root file. |
| Public surface | Continue only at this layer. Public item names remain preserved through the crate facade. |
| Mixed responsibility | Continue after extraction. The child likely contains multiple DTO subfamilies, but first needs a stable physical owner. |
| State ownership | Heavy caution. `PortfolioState` is a DTO/projection owner here, not runtime mutable service state; helper methods must remain behavior-equivalent. |
| Side effects | Stop at extraction. No IO, persistence, locks, async lifecycle, or external calls are involved. |
| Parent-mediated dependency | Required. RFC contracts and downstream runtime/backend callers must consume names through the crate-root facade. |
| Future reopen rule | Required after extraction to decide whether market data, decision flow, execution IO, portfolio state, and backtest output deserve child-level splitting. |

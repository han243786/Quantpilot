## Baseline Decision

Freeze `rebalance_directive_detection` for actual extraction.

The next Rust movement may create a child module under `quantscript/src/lowering/universe/` and move only the rebalance directive detection surface from `quantscript/src/lowering/universe.rs`. The parent `universe.rs` must remain the mediator for other universe lowering children.

## Approved Movement Scope

Move only:

- `detect_portfolio_rebalance_directive`
- `detect_portfolio_rebalance_directive_with_mode`
- `extract_instrument_pool_spec`
- `collect_portfolio_rebalance_directive_from_stmts`
- `portfolio_rebalance_directive_from_expr`
- `parse_rebalance_schedule`
- `parse_rebalance_allocation_expr`
- `evaluate_number_list_expr`
- `RebalanceAllocationParse`
- rebalance allocation / schedule / strategy error constants used by this child

The moved child may call parent-owned universe expression evaluation through a `pub(super)` boundary.

## Parent-Owned Exclusions

Do not move in this step:

- `UniverseValue`
- `expand_universe_constructs`
- statement expansion, symbol substitution, and local binding renaming helpers
- `evaluate_universe_expr`
- `evaluate_universe_arg`
- `decode_symbols_literal`
- universe metadata lookup, metric projection, and sorting helpers
- module-local tests and sample snapshot fixture
- `quantscript/src/lowering/mod.rs` re-export declarations

## Boundary Contract

| Field | Rule |
| --- | --- |
| Parent input | `ScriptModule`, `LoweringContext`, and best-effort pool extraction mode |
| Child output | `Option<PortfolioRebalanceDirective>` or `InstrumentPoolSpec` through the existing facade |
| Child visibility | `pub(super)` for implementation helpers unless existing parent-visible facade requires more |
| Parent calls into child | Through thin wrapper functions in `universe.rs` |
| Child calls back to parent | Only for `evaluate_universe_expr` and shared `UniverseValue` if needed |

## Summary

`root.contracts.core_ir.v4_contracts.machine_graph_contract.traversal_helpers` freezes the equivalence baseline for
extracting graph traversal helpers from `qrpc_core_ir/src/v4/machine_graph_contract.rs`.

Frozen behavior:

- `collect_machine_family` must push the current machine before recursively visiting child machines
- `collect_machine_family` must preserve traversal order by iterating state order
- `machine_nested_depth` must return `1` for a machine with no child machines
- `machine_nested_depth` must return `1 + max(child_depth)` for nested child machines
- existing callers in `v4.rs`, machine identity validation, and event reference resolution must keep using the
  same parent module import path

Allowed extraction:

- add `mod traversal_helpers;` to `qrpc_core_ir/src/v4/machine_graph_contract.rs`
- create `qrpc_core_ir/src/v4/machine_graph_contract/traversal_helpers.rs`
- move only `collect_machine_family` and `machine_nested_depth`
- re-export both helpers from the parent module with `pub(super) use traversal_helpers::{...};`

Forbidden movement:

- graph schema DTOs
- event catalog DTOs and validation
- graph static validation children
- v4 default helper functions
- bridge builders, tests, and complexity-budget logic

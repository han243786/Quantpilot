## Leaf Split Decision Gate

This child should be terminal after extraction.

Reason:

- The behavior is a compact preprocessing owner: normalize symbols, clone/prefix machines, expand graph edges, event parties, metadata, and risk-plane ids.
- Splitting normalization from graph expansion would create a micro leaf and increase parent import churn.
- The child has two public functions and private helpers; this is a strong terminal owner.

Decision:

`stop_split_after_extraction: true`

## Risk Notes

This is a medium-risk leaf because it includes filesystem persistence, quota checks, atomic rename/fsync, historical HTTP fetch, and stale fallback. If actual extraction exposes coupling with live transport or parser ownership, the extraction must keep those calls through parent-owned imports rather than introducing sibling horizontal links.

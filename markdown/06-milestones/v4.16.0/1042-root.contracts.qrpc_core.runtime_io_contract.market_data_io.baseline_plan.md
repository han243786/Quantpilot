## Summary

This baseline freezes the runtime IO market data DTO family before extraction.

The next implementation step may move only raw and normalized market data DTOs from the top of `qrpc_core/src/runtime_io_contract.rs` into a private child module under the runtime IO parent.

Decision flow, execution IO, portfolio state, runtime output, backtest output, RFC execution contracts, and crate-root tests remain parent-owned for later recursive steps.

## Frozen Surface

The selected child owns the current market data IO surface in `qrpc_core/src/runtime_io_contract.rs`:

- `RawKline`;
- `RawQuote`;
- `NormalizedKline`;
- `KlineSeriesSnapshot`;
- `QuoteSnapshot`;
- `NormalizedMarketData`.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Raw kline input | `RawKline` keeps `open_time`, OHLCV fields, and `close_time` with the same `u64`/`f64` types. |
| Raw quote input | `RawQuote` keeps bid/ask prices, sizes, and timestamp with the same numeric types. |
| Normalized kline | `NormalizedKline` keeps exchange, symbol, market type, interval, open/close timestamps, OHLC, and volume fields unchanged. |
| Kline series snapshot | `KlineSeriesSnapshot` keeps data identity, instrument identity, interval, bars, window, timestamp, latency, source status, and defaulted data quality fields unchanged. |
| Quote snapshot | `QuoteSnapshot` keeps data identity, instrument identity, quote prices/sizes, mid price, timestamp, latency, source status, and defaulted data quality fields unchanged. |
| Normalized data enum | `NormalizedMarketData` keeps `KlineSeries(KlineSeriesSnapshot)` and `Quote(QuoteSnapshot)` variants unchanged. |
| Public facade | Existing `qrpc_core::*` and runtime IO parent public names remain available through parent re-exports. |

## Planned Extraction Shape

BE-001SD-02 may:

- create `qrpc_core/src/runtime_io_contract/market_data_io.rs`;
- add `mod market_data_io;` to `qrpc_core/src/runtime_io_contract.rs`;
- add `pub use market_data_io::*;` to preserve the runtime IO parent facade;
- move only the frozen market data IO surface listed above;
- keep decision flow, execution IO, portfolio state, runtime output, and backtest output DTOs in `qrpc_core/src/runtime_io_contract.rs`;
- keep qrpc-core crate-root exports unchanged.

## Same-Parent Parallel Wave Judgment

This child remains a single-child extraction for BE-001SD-02.

`same_parent_parallel_children` is not activated because `RuntimeCycleOutput` still references `NormalizedMarketData`, and serial parent-facade updates keep dependency direction explicit.

## Hard Boundaries

BE-001SD-02 must not:

- change raw/normalized market data field names, types, serde derives, enum variants, default behavior, public exports, or tests;
- move decision flow, execution IO, portfolio state, runtime output, backtest output, RFC execution contracts, or crate-root tests;
- change closed qrpc-core children, downstream runtime/backend/compiler behavior, or release transition;
- create direct sibling shortcuts to other runtime IO child candidates.

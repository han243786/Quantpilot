| action memory writes | Reject writes to undeclared memory fields. |

| child machine self-reference | Reject child machine ID matching parent machine ID. |
| child machine uniqueness | Reject duplicate child machine IDs under one parent. |

| child machine depth | Reject child machines that themselves contain child machines. |

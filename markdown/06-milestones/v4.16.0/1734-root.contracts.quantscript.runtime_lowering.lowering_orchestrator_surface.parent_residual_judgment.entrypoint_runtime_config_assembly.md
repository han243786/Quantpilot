## Decision

Select `entrypoint_runtime_config_assembly` as the next child under `lowering_orchestrator_surface`.

`profile_detection_surface` and `integration_test_harness` are closed. The remaining production code in `quantscript/src/lowering/orchestrator.rs` still directly owns runtime config assembly behind the public `lower_script_to_runtime_config` and `lower_script_to_runtime_config_with_context` entrypoints. That assembly is cohesive enough to become a child owner while the parent keeps the public facade.

## Symbols Approved For Movement

Move only the private runtime config assembly implementation currently inside `lower_script_to_runtime_config_with_context`, including:

- normalization / universe expansion / typed HIR / analysis orchestration
- strategy function lookup and missing strategy error
- data source inference and de-duplication
- binding collection and diagnostic merge
- data source canonicalization and intent inference
- `AgentConfig` assembly
- `RiskConfig` assembly
- final `RuntimeProtocolCoreConfig` assembly
- private error constants needed only by the assembly

The public entrypoint functions must remain in `orchestrator.rs` and delegate through the parent-child boundary.

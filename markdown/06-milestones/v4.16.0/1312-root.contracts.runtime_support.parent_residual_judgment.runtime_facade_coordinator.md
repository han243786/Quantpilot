## Split Decision

`continue_split: true`.

Reasons:

- `qrpc_runtime/src/lib.rs` is still a large parent facade and coordinator implementation.
- It mixes crate-root exports, provider wiring, coordinator state, session orchestration, runtime events, and local tests.
- Extracting a coordinator child can reduce parent weight while keeping the crate-root public API stable.
- Other runtime children should continue communicating through this parent facade and provider traits.

No release-transition optimization is proposed.

## Decision

Select `intent_collection_orchestration` as the first internal child under `intent_inference`.

The parent `intents.rs` has been frozen as a precision leaf. The first split should isolate the orchestration shell around `infer_intents`: statement traversal, active condition propagation, conditional emit handling, dispatch into specialized intent constructors, and final merge behavior. This creates a stable parent-child boundary before moving specialized owners such as single-indicator inference, spread inference, MA ratio inference, and legacy emit fallback.

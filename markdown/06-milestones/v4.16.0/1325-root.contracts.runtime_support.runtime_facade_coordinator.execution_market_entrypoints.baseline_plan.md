## Physical Scope

This child freezes the public execution and market-data entrypoint methods currently located in `qrpc_runtime/src/runtime_facade_coordinator.rs`.

Owned methods:

- `RuntimeCoordinator::submit_execution_plan`
- `RuntimeCoordinator::on_market_data`

Owned behavior:

- lock `execution_module` with existing poisoned-lock recovery
- call `ExecutionModuleProvider::submit_plan`
- call `ExecutionModuleProvider::on_market_update`
- pass mutable portfolio state into execution module calls
- call parent-owned `refresh_portfolio_state` after execution or market update
- return `qrpc_core::FillResult`

## Exclusions

This child does not own:

- `RuntimeCoordinator` struct definition
- constructor/provider wiring
- session/cycle orchestration
- state/config accessors
- config generation
- provider delegation helper implementations
- `refresh_portfolio_state`
- `portfolio_update_event`
- coordinator tests

## Parent/Child Communication Rules

The child must stay below `runtime_facade_coordinator`.

Allowed dependencies:

- `super::RuntimeCoordinator`
- parent-owned `RuntimeCoordinator::refresh_portfolio_state`
- `anyhow::Result`
- `qrpc_core::{ExecutionPlan, NormalizedMarketData}`

No sibling-to-sibling shortcut and no release-transition optimization is allowed.

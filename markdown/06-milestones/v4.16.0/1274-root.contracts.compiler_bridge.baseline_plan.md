## Summary

`root.contracts.compiler_bridge` is frozen before Rust movement.

The current physical owner is the single-file crate `qrpc_compiler/src/lib.rs`. It bridges QRPC runtime/strategy contracts into Core IR and compiled runtime artifacts. This baseline records its public API, internal ownership families, first split candidate, and hard exclusions so the next recursive step can split without semantic drift.

Decision:

`baseline_frozen: true`

First selected candidate:

`root.contracts.compiler_bridge.runtime_protocol_validation`

## First Split Plan

Next step `BE-001XA-01` may select only `runtime_protocol_validation`.

If selected, the later extraction may move only runtime protocol validation helpers and their direct validation-only support into a private child module under `qrpc_compiler/src/`. It must keep all public functions re-exported or called through the parent facade and must not change validation messages, validation ordering, lowering output, canonical hash behavior, Strategy IR lowering, tests, or crate dependencies.

## Hard Exclusions

This baseline must not:

- move runtime protocol lowering helpers;
- move Strategy IR lowering helpers;
- move spread/custom expression construction;
- change public function signatures;
- change `CompiledRuntimeProtocol` hash generation;
- change Core IR output shape or validation ordering;
- change QRPC/Core IR data contracts;
- introduce release-transition sibling links;
- move test fixtures unless the explicit test-retirement path is active.

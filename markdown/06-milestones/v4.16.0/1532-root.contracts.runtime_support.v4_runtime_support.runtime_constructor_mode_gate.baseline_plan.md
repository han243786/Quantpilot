## Scope

`root.contracts.runtime_support.v4_runtime_support.runtime_constructor_mode_gate` freezes the v4 runtime constructor and mode-gating surface before movement.

Current physical owner:

- `qrpc_runtime/src/v4_runtime.rs`

Planned child direction:

- introduce a parent-mediated constructor/mode-gate child under the v4 runtime support parent;
- move only the constructor and execution-capability policy attachment methods;
- preserve `V4PaperSimulatedRuntime` public constructor behavior through the same inherent impl surface.

## Owned Surface

The child owns:

- `V4PaperSimulatedRuntime::new`
- `V4PaperSimulatedRuntime::new_for_mode`
- `V4PaperSimulatedRuntime::new_for_mode_inner`
- `V4PaperSimulatedRuntime::new_with_execution_capabilities`
- `V4PaperSimulatedRuntime::new_for_mode_with_execution_capabilities`
- `V4PaperSimulatedRuntime::new_for_backtest`
- `V4PaperSimulatedRuntime::with_execution_capabilities`

Owned behavior:

- accepted runtime modes remain `PaperSimulated` and `LiveActual`;
- `LiveActual` requires an explicit required Risk Plane;
- `LiveActual` requires an execution capability policy attached during construction;
- static graph validation must run before runtime state creation;
- machine family runtime state must initialize from graph machines;
- initial risk-plane, execution, simulated-execution, queue/log, sequence, and provider-submit state must remain equivalent;
- execution capability policy validation must remain equivalent.

## Explicitly Out Of Scope

This leaf must not move:

- `with_simulated_execution_config`;
- backtest bar/tick replay;
- event ingestion and queue draining;
- machine transition matching and application;
- risk-plane runtime decision evaluation;
- execution capability decision evaluation after runtime creation;
- simulated execution engine internals;
- v4 tests.

## Leaf Split Decision Gate

This child should be terminal after extraction.

Reason:

- The constructor/mode gate has one owner: accepting or rejecting a v4 runtime instance before replay/event processing begins.
- Splitting `new*` from `with_execution_capabilities` would separate `LiveActual` precondition enforcement from the policy that satisfies it.
- `with_simulated_execution_config` is deliberately excluded because it belongs to simulated execution configuration, not constructor admission.

Decision:

`stop_split_after_extraction: true`

## Baseline Decision

`actual_extraction: false`

The helper pocket should remain parent-owned for this recursion pass.

## Rationale

The current helper surface is used by multiple already-closed child modules:

- `weighted_signal_decisions` uses signal-kind indexing, signal scoring, threshold constants, and available-position ratio;
- `portfolio_rebalance` uses signal-kind indexing, signal scoring, threshold constants, and current-position ratio;
- `cross_venue_arbitrage` uses available-position ratio and spread multiplier.

Extracting these helpers into a new child module would either:

- make policy children depend directly on a sibling helper module; or
- require parent wrapper/re-export plumbing that adds indirection without improving ownership clarity.

The current shape keeps child communication parent-mediated through `super::` references. That satisfies the hard parent-child communication rule while avoiding helper micro-module churn.

## Boundaries To Preserve

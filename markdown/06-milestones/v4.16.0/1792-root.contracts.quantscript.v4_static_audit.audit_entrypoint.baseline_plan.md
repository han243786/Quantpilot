## Baseline

Freeze `audit_entrypoint` before Rust movement.

The approved future movement is limited to the implementation body of
`audit_v4_quant_script_static`. The public function must remain in
`quantscript/src/v4_static_audit.rs` as a stable wrapper that delegates to a
private child module.

## Equivalent Behavior To Preserve

| Behavior | Baseline |
| --- | --- |
| Parser failure | Return rejected `V4QsStaticAuditReport` with no graph, request, or capability report |
| Schema version | Use `V4_QS_STATIC_AUDIT_REPORT_VERSION` |
| Static graph validation | Extend diagnostics with `QSV4200` errors from `validate_static_contract` |
| Capability report bundle | Clone bundle, replace same-graph entry, push parsed graph, then build report |
| Capability diagnostics | Map capability report errors into `QSV4300` diagnostics |
| Verdict | Reject if any diagnostic is error or capability report verdict is not accepted |
| Accepted report | Preserve graph id, parsed graph, capability request, capability report, diagnostics |
| Runtime/lowering flags | Keep `runtime_attached` and `lowering_attached` false |

## Selection Rationale

`backtest_artifact_contract` is selected because it is a compact DTO family immediately below the v4 identity constants:

- it owns `V4BacktestArtifact` and nested backtest metric/trajectory/risk/capability-source records;
- it has no impl blocks, validator logic, default helper bodies, or tests of its own;
- extracting it establishes a DTO-family child before larger validator families move;
- dependent taxonomy names stay parent-mediated and remain owned by later families.

## Explicit Non-Owners

The selected child does not own:

- `MachineTemplateKind`, which belongs to machine contract taxonomy;
- `RuntimeTradingMode`, which belongs to runtime mode contract;
- `ExecutionCapabilityKind` and `CapabilitySupportSource`, which belong to venue capability matrix;
- `default_v4_backtest_artifact_version`, which remains in default helper surface unless later family extraction moves it with artifact after a separate judgment;
- runtime execution, projection, persistence, backend, or frontend artifact handling.

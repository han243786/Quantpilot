## Baseline Decision

Freeze `spread_intent_inference` for actual extraction.

The next Rust movement may create a child module under `quantscript/src/lowering/intents/` and move only formal spread matching, spread operand decoding, spread params, and resample/align parsing. Parent-owned condition dispatch, MA ratio intent inference, legacy emit fallback, agent param projection, data-source canonicalization, comparison helpers, and public(crate) facades must remain in `intents.rs`.

## Boundary Contract

| Field | Rule |
| --- | --- |
| Parent input | indicator expression, relation, threshold expression, `BindingEnv`, and optional runtime id hint |
| Child output | optional `IntentConfig` or `anyhow::Error` |
| Child visibility | `pub(super)` implementation entry only |
| Parent calls into child | Through `spread_intent_from_condition` call site in `intents_from_condition` |
| Child calls back to parent | Only for parent-owned canonicalization, comparison helpers, runtime id helpers, and shared expression/binding helpers |

## Equivalence Baseline

Required validation after movement:

- `cargo fmt --check`
- `cargo test -p quantscript`
- `cargo check -p quantpilot`
- `git diff --check`
- UTF-8, full feature tree, and matrix governance checks

Behavior that must stay equivalent:

- only greater-than / greater-equal spread conditions produce a spread intent;
- unsupported or incomplete `spread(...)` expressions return no intent;
- same `data_id` or different-symbol spread pairs are rejected;
- `QuoteObserve` intent id, name, input ids, params, and enabled flag stay equivalent;
- field, resample, align, aggregation, tolerance, and inferred interval numeric encodings stay unchanged;
- no sibling horizontal link is introduced.

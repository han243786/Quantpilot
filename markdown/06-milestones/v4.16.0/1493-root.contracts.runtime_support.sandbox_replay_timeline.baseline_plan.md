## Scope

Freeze the baseline for the runtime sandbox/replay/timeline boundary.

Owned files:

- `qrpc_runtime/src/sandbox/mod.rs`
- `qrpc_runtime/src/sandbox/replay.rs`
- `qrpc_runtime/src/sandbox/timeline.rs`

This parent owns sandbox modes, deterministic test mode, sandbox snapshots, real-time and fast-backtest sandbox implementations, deterministic replay construction, timeline data providers, unified timeline assembly, and local tests.

## Split Decision

`continue_split: true`

Reason:

- the boundary spans three files and roughly two thousand lines;
- `mod.rs` mixes public sandbox surface, real-time sandbox, fast-backtest sandbox, snapshot helpers, and tests;
- `timeline.rs` mixes provider implementations and unified timeline assembly;
- `replay.rs` owns deterministic replay construction and provider assembly;
- keeping all of this as one terminal leaf would hide meaningful runtime ownership boundaries.

## Goal

Freeze the event catalog derivation boundary before Rust movement.

This child owns the pure projection from a parsed `V4MachineGraphContract` to
`MachineEventCatalog`, plus the recursive child-machine traversal needed by
that projection.

## Frozen Boundary

| Field | Value |

| Output | `MachineEventCatalog` |
| Approved functions | `derive_event_catalog`, `machine_family` |

| Parent caller | `parse_v4_static_document` graph assembly |
| Parent facade | Parent may keep a private thin wrapper named `derive_event_catalog` |

## Equivalent Behavior

The extracted child must preserve:

- risk-plane machine ids collected from `graph.risk_plane.machine_ids`;
- emitter collection from transition action emits and graph edges;
- consumer collection from transition selectors and graph edges;
- recursive traversal through state `child_machine`;
- event universe as the sorted union of emitter and consumer keys;
- `RiskPlane` source kind when an event is emitted by a risk-plane machine or
  starts with `risk.`;
- `MarketData` source kind when an event has no emitters and starts with
  `market.`;
- `Machine` source kind for all remaining events;
- `MachineEventScope::Graph`;
- empty `payload_fields`;
- `replayable: true`;
- `V4_MACHINE_EVENT_CATALOG_VERSION` schema version;
- empty catalog `metadata`.

## Goal

Freeze the machine block parser boundary before Rust movement.

This child owns the machine envelope parser and the top-level
`V4MachineContract` assembly for a single `machine` block. It delegates nested
state, memory, transition, template, and child-machine parsing through the
parent-controlled boundary.

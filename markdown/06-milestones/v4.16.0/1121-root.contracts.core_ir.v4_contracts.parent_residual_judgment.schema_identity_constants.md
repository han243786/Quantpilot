## Selection Rationale

`schema_identity_constants` is selected first because it is the lowest-risk v4 child:

- it is contiguous near the top of `v4.rs`;
- it has no serde derives, no validator logic, no helper behavior, and no tests to move;
- downstream references can remain stable through `pub use schema_identity_constants::*`;
- extracting it establishes the v4 child-module facade pattern before larger contract families move.

## Stop-Split Rationale

`market_trigger_flow` has a single owner: market price update driven trigger evaluation. It coordinates expiry, trigger sweep, parent-owned fill handoff, and final portfolio event emission without owning ledger mutation itself.

Rejected finer splits:

| Candidate | Decision | Reason |
| --- | --- | --- |
| `update_market_price` entrypoint | Reject | The entrypoint is the coordination surface for the child and must remain near trigger sweep ordering. |
| `check_order_triggers` | Reject | Trigger sweep depends on trailing-stop adjustment, resting-order conversion, parent-owned fill handoff, and event ordering. |
| `update_trailing_stop` | Reject | Too small alone and directly feeds conditional trigger evaluation. |
| `request_from_order` | Reject | A narrow adapter helper that only supports trigger/fill handoff. |

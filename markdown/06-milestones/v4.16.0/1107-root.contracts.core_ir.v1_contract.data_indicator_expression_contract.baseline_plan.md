## Summary

This baseline freezes the v1 data, indicator, and expression contract before extraction from `qrpc_core_ir/src/v1.rs`.

The next implementation step may move only the frozen surface into `qrpc_core_ir/src/v1/data_indicator_expression_contract.rs`. Public names must remain available through the v1 parent and crate-root facades.

## Frozen Surface

The selected child owns:

- `DataBinding`, `DataBindingKind`;
- `IndicatorNode`, `CoreIndicatorKind`;
- `CustomExprSpec`, `CustomPredicateExpr`, `CustomValueExpr`;
- `ArithmeticOp`, `ArithmeticUnaryOp`;
- `SeriesExpr`, `SeriesField`, `SeriesAggregation`;
- `AlignDirection`, `AlignAsofSpec`, `SpreadValueKind`, `SpreadSpec`;
- `SignalKind`;
- `ScalarExpr`, `ComparisonOp`;
- `close_series_expr`;
- `moving_average_series_expr`;
- `moving_average_compare_expr`;
- `indicator_threshold_compare_expr`;
- `default_custom_confidence`.

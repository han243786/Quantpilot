## Scope

`root.contracts.runtime_support` freezes the current `qrpc-runtime` crate boundary before any runtime-support movement.

Physical scope:

- `qrpc_runtime/Cargo.toml`
- `qrpc_runtime/src/lib.rs`
- `qrpc_runtime/src/*.rs`
- `qrpc_runtime/src/sandbox/*.rs`

Public facade to preserve:

- `qrpc_runtime::RuntimeCoordinator`
- `qrpc_runtime::ConfigGenerationEntry`
- `qrpc_runtime::set_mock_volatility`
- public module surfaces: `backtest_metrics`, `circuit_breaker`, `hotswap`, `live_execution`, `plugin_market`, `plugin_sandbox`, `risk_monitor`, `slippage`, `v4_runtime`
- crate-root re-exports for data, intent, agent, execution, risk, sandbox, plugin runtime, compatibility, merge, reconcile, slippage, and v4 runtime DTOs/functions

External boundaries to preserve:

- `qrpc_core` DTO and contract imports remain the contract source of truth.
- `qrpc_core_ir` remains outside this node.
- Backend route handlers, frontend callers, executor sessions, QuantScript contracts, plugin metadata files, and release-transition optimization remain outside this node.

## White-Box Responsibilities

This parent owns runtime support behavior after contracts are compiled:

- build and run runtime sessions from Core IR or compiled runtime protocol inputs
- collect and normalize market data through provider abstraction
- evaluate intent, agent, risk, and execution modules through provider traits
- evaluate Core IR indicator signals and custom indicator paths
- plan and simulate fills and portfolio state transitions
- enforce risk checks and runtime risk monitor stops
- provide sandbox, replay, timeline, deterministic test mode, and fast backtest boundaries
- expose live execution support and safety gates
- expose plugin runtime registry, market metadata verification, and plugin sandbox support
- expose v4 paper simulated runtime types and event processing
- preserve compatibility, hotswap, merge, reconciliation, slippage, and backtest metric helpers

## First Child Selection Preview

The next parent residual judgment should select `contracts.runtime_support.runtime_facade_coordinator`.

Reason:

- `qrpc_runtime/src/lib.rs` is the public facade and still owns `RuntimeCoordinator`, provider injection, session execution, config generation, state/config/merge coordinator wiring, and crate-root export policy.
- Other runtime children communicate through this facade or the provider traits it exports.
- Freezing this child first gives later runtime leaves a stable parent communication surface.

## Leaf Split Decision Gate

The baseline requires continued splitting:

- `public_surface_owned`: many runtime contracts are re-exported from the crate root.
- `size_or_behavior_pressure`: the crate contains multiple large behavior families.
- `independent_failure_modes`: data, intent, agent, evaluation, execution, fill, risk, sandbox, v4 runtime, live execution, plugin runtime, and ops support fail independently.
- `parent_child_communication_kept`: child communication must continue through crate-root or parent-owned provider traits, not sibling shortcuts.
- `release_transition_guard`: no horizontal child connection is proposed because the developer has not declared release transition.

Stop rules do not apply at this parent baseline.

## Shared Helper Treatment

`collect_machine_family` and `machine_nested_depth` are selected for movement with the graph contract because they traverse graph machine trees. However, they are also used by `ComplexityMetrics::from_machine_graph`.

BE-001UE-02 must therefore expose these helpers only to the v4 parent:

- move them into `qrpc_core_ir/src/v4/machine_graph_contract.rs`;
- mark them `pub(super)`;
- import them in `qrpc_core_ir/src/v4.rs` with `use machine_graph_contract::{collect_machine_family, machine_nested_depth};`;
- do not public-re-export them as external API.

`machine_event_party_allowed` stays private to the graph child.

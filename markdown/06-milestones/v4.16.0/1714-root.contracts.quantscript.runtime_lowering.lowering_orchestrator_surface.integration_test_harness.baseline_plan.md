## Baseline Decision

`integration_test_harness` is frozen as a test-only child for extraction.

The next movement may move the existing `#[cfg(test)] mod tests` block out of the parent `orchestrator.rs` into a child test module. Production lowering code, public entrypoints, runtime config assembly, and the already extracted `profile_detection_surface` child are not approved for movement in this batch.

## Current Test Coverage Surface

The frozen harness covers these scenario groups:

| Group | Existing examples |
| --- | --- |
| Basic lowering | MA cross, RSI threshold, aliased data binding, helper function calls |
| Runtime integration | Runtime protocol compilation and `RuntimeCoordinator` session smoke |
| Semantic rejection | Missing helper and invalid conditional analysis before runtime lowering |
| Manual formula lowering | moving average, momentum, zscore, MACD histogram, momentum ratio, MA gap ratio |
| Manual RSI variants | RS ratio, avg gain/loss aliases, EMA RSI, Cutler RSI |
| Unsupported loop formulas | formal-path rejection for loop-built gain/loss lists |
| Data source decoding | exchange argument and stable data/intent ids |
| Spread lowering | admitted explicit spread helper, non-admitted cross-source/asymmetric/helper-annotated formulas |
| Rebalance lowering | equal weight, fixed weights, rank weight, score weight, weekly schedule |
| Rebalance rejection | unsupported frequency and unsupported rank method |

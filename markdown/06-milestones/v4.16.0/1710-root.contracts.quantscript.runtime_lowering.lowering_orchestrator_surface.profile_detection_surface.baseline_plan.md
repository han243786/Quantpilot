## Baseline Decision

`profile_detection_surface` is frozen as a production child for extraction.

The next movement may create `quantscript/src/lowering/profile_detection_surface.rs` and move only risk/execution profile parsing and nested placement validation from `quantscript/src/lowering/orchestrator.rs`.

## Frozen Input / Output

| Field | Boundary |
| --- | --- |
| Input | `FunctionDecl` strategy body, `Stmt`, `Expr`, and `CallArg` values used by profile declarations |
| Output | `Option<GlobalRiskProfileSpec>` and `Option<PaperExecutionProfileSpec>` |
| Parent caller | `lower_script_to_runtime_config_with_context` |
| Error surface | Existing `anyhow::bail!` messages and top-level-only validation stay outwardly equivalent |

## Parent Mediation Rule

After extraction:

- `orchestrator.rs` imports only `detect_global_risk_profile` and `detect_paper_execution_profile` from the child;
- the child returns simple spec structs with fields visible to the parent;
- the child must not call sibling lowering modules;
- public re-exports in `lowering/mod.rs` remain unchanged.

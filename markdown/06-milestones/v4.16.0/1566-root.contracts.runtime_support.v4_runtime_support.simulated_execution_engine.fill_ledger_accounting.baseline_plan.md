## Decision

Freeze `fill_ledger_accounting` as a same-parent child movement candidate.

The next movement may extract fill execution and ledger mutation helpers while keeping direct-submit orchestration, validation helper families, snapshot projection, microstructure metrics, and tests parent-owned.

## Allowed Movement

The actual extraction may add `qrpc_runtime/src/v4_runtime/simulated_execution_engine/fill_ledger_accounting.rs` and move only these methods from `qrpc_runtime/src/v4_simulated_execution.rs`:

| Method | Visibility after move | Reason |
| --- | --- | --- |
| `fill_existing_order` | `pub(super)` | `market_trigger_flow` calls trigger-fill execution through the simulated execution parent boundary. |
| `apply_fill_to_ledger` | `pub(super)` | Parent direct-submit path and moved trigger-fill path both mutate cash/position ledger through this helper. |

The movement must preserve:

- validation and rejection handoff order before filling;
- fill id construction and fill count sequencing;
- fill quantity, fill price, notional, fee, and fee asset semantics;
- order status update between partially filled and filled;
- cash balance, realized fees, signed position quantity, average price, market price, and market value math;
- OCO sibling cancellation only after a filled existing order;
- order/fill/fee/portfolio event order and payload shapes;
- history trimming and asset point recording side effects.

## Frozen Parent-Owned Surface

The next movement must leave the following outside `fill_ledger_accounting`:

- `submit_order` and the direct-submit fill block;
- `validate_position_action`;
- `pre_execution_rejection_reason`;
- `non_executable_resting_reason`;
- `record_asset_point`, `asset_point`, `snapshot`, and `microstructure_metrics`;
- market trigger flow already closed in `market_trigger_flow`;
- order lifecycle internals already closed in `order_lifecycle_flow`;
- runtime adapter behavior already closed in `runtime_adapter`;
- v4 tests.

`submit_order` may continue to call `apply_fill_to_ledger` through the parent boundary, but it must not move wholesale in this batch.

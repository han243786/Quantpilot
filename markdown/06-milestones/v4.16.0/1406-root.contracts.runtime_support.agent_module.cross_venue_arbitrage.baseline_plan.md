## Boundaries To Preserve

| Boundary | Requirement |
| --- | --- |
| Dispatch | `evaluate_agents` continues to select this path only for `AgentPolicyKind::CrossVenueArbitrage` on `fast` cycle. |
| Explicit spread signal | A signal carrying `spread_ratio`, `buy_mid_price`, and `sell_mid_price` still takes precedence over exchange-pair quote inference. |
| Quote pair inference | Binance and OKX quote observe signals still infer buy/sell legs from lower and higher reference prices. |
| Cost buffer | Total cost buffer remains `(taker_fee_bps * 2 + slippage_bps * 2 + total_cost_buffer_bps) / 10000`. |
| Spread trigger | `agent.spread_trigger_bps.unwrap_or(50.0) / 10000` remains clamped upward by total cost buffer. |
| Symbol fallback | Missing symbol scope still falls back to `Symbol::BtcUsdt`. |
| Quantity clamp | `agent.max_quantity_ratio.clamp(0.01, 1.0)`, `spread * SPREAD_MULTIPLIER`, and sell-side availability clamp remain equivalent. |
| Suppression | Non-finite or <= 0.01 quantity ratio still suppresses decision output. |
| Output shape | Paired buy/sell actions, exchange targets, strategy tags, reason string, net side, net strength, timestamp, and trace id remain equivalent. |

## Why This Child

`state_block_parser` is the next natural extraction because state parsing is the
remaining bridge between machine envelope parsing and nested child-machine
support. It owns the state line/block grammar and the child-machine handoff
rules, while memory, transition, edge, risk-plane, and state-group parsing can
remain parent-controlled candidates.

This keeps nested state-machine behavior explicit without over-splitting
terminal helper fragments.

## Summary

This baseline freezes the qrpc-core artifact specification surface before extraction.

The next implementation step may move only canonical digest helpers, run/backtest spec DTOs, dataset and execution assumption projections, market data snapshot specs, and strategy/compile/core-IR artifact bundle contracts from `qrpc_core/src/lib.rs` into a private child module under the qrpc-core crate root.

## Selected Surface

The selected child owns the current artifact spec surface in `qrpc_core/src/lib.rs`:

- `ArtifactDigestAlgorithm`;
- `ArtifactDigest`;
- `canonical_json_sha256_digest`;
- `RunModeSpec`;
- `BacktestReplaySource`;
- `StrategyArtifactSourceKind`;
- `DatasetSpec` and `DatasetSpec::from`;
- `ExecutionAssumptionSpec`;
- `ExecutionAssumptionValueSource`;
- `ExecutionAssumptionSourceSummary`;
- `ExecutionAssumptionSpec::from`;
- `MarketDataSnapshotSpec` and `MarketDataSnapshotSpec::from_runtime_protocol`;
- `RunSpec`;
- `RunSpecRuntimeProtocolInput`;
- `RunSpec::from_runtime_protocol`;
- `BacktestSpec` and `BacktestSpec::new`;
- `StrategyArtifact`;
- `CoreIrArtifact`;
- `CompileArtifact`;
- `CompileArtifactBundle`.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Canonical digest | `serde_json::to_vec` output is hashed with SHA-256 and returned as lowercase hex with `Sha256CanonicalJson`. |
| Digest schema | `ArtifactDigestAlgorithm` keeps snake_case serde and `ArtifactDigest` keeps `algorithm` and `value`. |
| Run/backtest modes | `RunModeSpec`, `BacktestReplaySource`, and `StrategyArtifactSourceKind` keep all variants and snake_case serde. |
| Dataset projection | `DatasetSpec::from(&DataSourceConfig)` keeps dataset/data id cloning, primitive clones, interval/day mapping, and enabled propagation. |
| Execution assumptions | `ExecutionAssumptionSpec::from(&RuntimeProtocolCoreConfig)` keeps cash/cost values, `TimeInForce::Gtc`, partial fills true, and no latency assumption. |
| Market data snapshot projection | `MarketDataSnapshotSpec::from_runtime_protocol` maps runtime data sources into datasets without changing snapshot id/source/time fields. |
| Run spec projection | `RunSpec::from_runtime_protocol` keeps schema version, input fields, dataset projection, execution assumption projection, no source summary, and core IR digest. |
| Backtest constructor | `BacktestSpec::new` keeps schema version, id/source/time/run spec/snapshot assignment. |
| Artifact DTOs | Strategy, core IR, compile, and bundle structs keep field names, serde defaults, and nested type ownership. |
| Public facade | Existing crate-root public names remain available through `qrpc_core::*`. |

## Planned Extraction

BE-001RS-02 may:

- create `qrpc_core/src/artifact_specs.rs`;
- add `mod artifact_specs;` to `qrpc_core/src/lib.rs`;
- add `pub use artifact_specs::*;` to preserve crate-root public surfaces;
- move only the selected artifact spec region described above;
- keep runtime IO DTOs beginning at `RawKline` in `qrpc_core/src/lib.rs`;
- keep RFC execution contracts and crate-root tests in `qrpc_core/src/lib.rs`.

## Hard Boundaries

- change canonical digest behavior, serde attributes, schema version constants, field names, projection behavior, constructors, public exports, or tests;
- move runtime IO DTOs beginning at `RawKline`, RFC execution contracts, or crate-root tests;
- change closed error/proto/plugin/strategy IR/protocol primitive/runtime config contracts;
- change `qrpc_core_ir`, `qrpc_compiler`, `qrpc_runtime`, `quantscript`, backend, executor, frontend, physical `plugins/*`, or release transition.

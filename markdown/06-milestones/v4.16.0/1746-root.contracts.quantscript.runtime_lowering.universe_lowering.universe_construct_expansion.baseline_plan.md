## Baseline Decision

Freeze `universe_construct_expansion` for actual extraction.

The next Rust movement may create a child module under `quantscript/src/lowering/universe/` and move only the AST expansion / substitution surface from `quantscript/src/lowering/universe.rs`. The parent `universe.rs` must keep the public(crate) facade and remain the mediator for universe expression evaluation.

## Approved Movement Scope

Move only:

- internal implementation behind `expand_universe_constructs`
- `expand_stmts`
- `uniquify_local_bindings`
- `collect_binding_names`
- `rename_stmt_bindings`
- `rename_expr_bindings`
- `renamed_identifier`
- `substitute_universe_stmt`
- `substitute_universe_expr`
- `substitute_symbol_in_stmt`
- `substitute_symbol_in_expr`

The parent facade `expand_universe_constructs` may remain in `universe.rs` and delegate to the child.

## Parent-Owned Exclusions

Do not move in this step:

- `UniverseValue`
- `detect_portfolio_rebalance_directive`
- `extract_instrument_pool_spec`
- `rebalance_directive_detection` child module
- `evaluate_universe_expr`
- `evaluate_universe_arg`
- `decode_symbols_literal`
- `instrument_pool_selection_key`
- universe metadata lookup, metric projection, and sorting helpers
- module-local tests and sample snapshot fixture

## Boundary Contract

| Field | Rule |
| --- | --- |
| Parent input | `ScriptModule` and `LoweringContext` |
| Child output | expanded `ScriptModule` |
| Child visibility | `pub(super)` implementation entry only |
| Parent calls into child | Through thin `expand_universe_constructs` facade in `universe.rs` |
| Child calls back to parent | Only for `evaluate_universe_expr`, `UniverseValue`, and shared `sanitize_id` / script AST types as needed |

## Equivalence Baseline

Required validation after movement:

- `cargo fmt --check`
- `cargo test -p quantscript`
- `cargo check -p quantpilot`
- `git diff --check`
- UTF-8, full feature tree, and matrix governance checks

Behavior that must stay equivalent:

- non-strategy items remain unchanged;
- strategy `for symbol in universe(...)` bodies expand over evaluated symbols;
- local bindings are uniquified by symbol suffix;
- universe bindings substitute through `let`, `return`, `emit`, expression, member, index, slice, unary, binary, range, await, try, if, for, while, and match shapes;
- parent-owned universe expression evaluation remains the only evaluator for `symbols`, `universe`, `filter`, `sort_by`, and `top`.

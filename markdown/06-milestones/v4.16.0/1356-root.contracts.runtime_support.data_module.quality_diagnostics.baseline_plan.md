## Public API Equivalence

The crate-visible helpers must remain callable through the parent `data_module` boundary:

- `attach_data_quality_snapshot`
- `market_data_quality`
- `build_data_quality_summary`
- `market_data_preview`
- `MarketDataPreview`

`apply_snapshot_status` may be moved as `pub(super)` because it is only used by parent collection/cache flow.

Allowed movement:

- add `qrpc_runtime/src/data_module/quality_diagnostics.rs`
- declare `mod quality_diagnostics;` in `qrpc_runtime/src/data_module.rs`
- re-export crate-visible quality helpers through the parent
- import `apply_snapshot_status` for parent-local cache flow

Forbidden movement:

- do not move `FetchDiagnostics`
- do not move `BuiltinDataModule`
- do not move collection orchestration
- do not move exchange endpoint or payload parsing
- do not move normalization
- do not move mock or historical cache logic
- do not move tests in this batch

## Split Decision Gate

The child is expected to stop after actual extraction.

Reasons:

- quality flags, health projection, preview, status refresh, and summary share one `DataQualitySnapshot` contract
- splitting freshness/status from summary would create sibling coupling in the collection event payload
- quote and kline branches are variants of the same normalized market data quality owner

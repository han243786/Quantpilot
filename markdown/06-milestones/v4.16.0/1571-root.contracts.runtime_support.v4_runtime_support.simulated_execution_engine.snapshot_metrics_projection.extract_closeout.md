## Decision

Extract `snapshot_metrics_projection` as a dedicated simulated execution child.

The extraction moved asset curve recording, portfolio snapshot projection, microstructure metric projection, and private rounding out of the parent include while preserving projection values, event payload shapes, access from the `v4_runtime` parent layer, and same-parent child mediation.

## Code Movement

| Path | Change |
| --- | --- |
| `qrpc_runtime/src/v4_runtime/simulated_execution_engine.rs` | Adds `mod snapshot_metrics_projection;` after existing simulated execution child modules. |
| `qrpc_runtime/src/v4_runtime/simulated_execution_engine/snapshot_metrics_projection.rs` | New child module owning asset curve, snapshot, microstructure metrics, and private rounding projection helpers. |
| `qrpc_runtime/src/v4_simulated_execution.rs` | Removes the moved projection helper implementations and keeps direct-submit orchestration, validation, capability, payload parsing, and tests outside this child. |

Moved helpers:

| Method/helper | Final visibility | Reason |
| --- | --- | --- |
| `record_asset_point` | `pub(super)` | Same-parent children record asset points after state mutations through the parent boundary. |
| `asset_point` | private | Local projection helper used only by the moved child. |
| `snapshot` | `pub(in crate::v4_runtime)` | Runtime adapter, tests, and v4 parent read paths retain access. |
| `microstructure_metrics` | `pub(in crate::v4_runtime)` | Event replay orchestration keeps parent-layer metrics access. |
| `round_money` | private | Projection-only rounding helper moved with its only callers. |

## Preserved Parent-Owned Surface

- `submit_order` and direct-submit fill orchestration;
- fill execution and ledger mutation already closed in `fill_ledger_accounting`;
- market trigger flow already closed in `market_trigger_flow`;

- runtime adapter behavior already closed in `runtime_adapter`;

- conditional order helpers and capability derivation helpers;
- payload parsing helpers;
- v4 tests.

## Boundary Notes

The extraction keeps parent-mediated communication:

- order lifecycle, market trigger, and fill/accounting children call `record_asset_point` and `snapshot` through `V4SimulatedExecutionRuntimeState`;
- v4 runtime event replay reads `microstructure_metrics` through the same state surface;
- `snapshot` and `microstructure_metrics` are visible only within `crate::v4_runtime`.

No release-transition optimization, hot-path sibling horizontal connection, route/schema change, persistence owner change, runtime mode change, or test rewrite was introduced.

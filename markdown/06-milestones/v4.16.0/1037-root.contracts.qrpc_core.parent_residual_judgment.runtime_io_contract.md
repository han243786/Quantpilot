## Selection Rationale

`runtime_io_contract` is selected because it is the next contiguous runtime DTO/output region after artifact specs in `qrpc_core/src/lib.rs`:

- it owns raw and normalized market data DTOs: `RawKline`, `RawQuote`, `NormalizedKline`, `KlineSeriesSnapshot`, `QuoteSnapshot`, and `NormalizedMarketData`;
- it owns decision and action DTOs: `IntentSignal`, `ProposedAction`, `TargetWeight`, `PortfolioTarget`, `PortfolioTargetDecision`, `AgentDecision`, and `RiskDecision`;
- it owns execution IO DTOs: `SimOrder`, `ExecutionPlan`, `FillReport`, `OpenOrder`, and `FillResult`;
- it owns portfolio/runtime state projection DTOs: `Position`, `ExchangeExposure`, `PortfolioState`, `PortfolioState::new`, and `PortfolioState::debug_assert_invariants`;
- it owns runtime output DTOs: `RuntimeEvent`, `RuntimeCycleOutput`, `SessionOutput`, and `BacktestOutput`;
- it owns backtest report DTOs: `BacktestEquityPoint`, `BacktestRiskAdjusted`, `BacktestTradeAnalysis`, `BacktestDrawdownAnalysis`, `BacktestBenchmarkComparison`, `BacktestSummary`, and `PeriodReturn`;
- it can move before RFC execution contracts because the RFC block begins at `MarketScope` and owns a separate request/order/handoff protocol family.

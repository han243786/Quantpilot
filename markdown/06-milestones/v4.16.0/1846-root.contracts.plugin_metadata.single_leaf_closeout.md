## Decision

`stop_split: true`

`plugin_metadata` is a non-code metadata leaf. It owns the physical plugin JSON
manifest and placeholder registry directories. Splitting the placeholder
directories from the one builtin manifest would add governance cost without
improving Rust modularity.

## Owned Paths

| Path | Ownership |
| --- | --- |
| `plugins/builtin/data/kline/plugin.json` | builtin data plugin metadata |
| `plugins/cache/.gitkeep` | plugin cache placeholder |
| `plugins/disabled/.gitkeep` | disabled plugin placeholder |
| `plugins/installed/.gitkeep` | installed plugin placeholder |

## Why No Further Split

- This is not Rust source and requires no code movement.
- Rust manifest DTOs, validation, and registry behavior are already closed in
  `contracts.qrpc_core.plugin_contract`.
- Runtime plugin execution behavior remains outside this metadata leaf.
- The physical metadata set is small and cohesive.

## Preserved Boundaries

- Public API unchanged.
- Plugin JSON content unchanged.
- Rust plugin contract code unchanged.
- Executor, backend, frontend, and release-transition behavior unchanged.

No Rust movement in this closeout step.

## Summary

This baseline freezes the qrpc-core artifact canonical digest surface before extraction.

The next implementation step may move only `ArtifactDigestAlgorithm`, `ArtifactDigest`, and `canonical_json_sha256_digest` from `qrpc_core/src/artifact_specs.rs` into a private child module under the artifact specs parent.

## Selected Surface

The selected child owns:

- `ArtifactDigestAlgorithm`;
- `ArtifactDigest`;
- `canonical_json_sha256_digest`.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Algorithm enum | `ArtifactDigestAlgorithm::Sha256CanonicalJson` remains the only variant and keeps snake_case serde. |
| Digest DTO | `ArtifactDigest` keeps `algorithm` and `value` fields with `PartialEq`/`Eq`. |
| Helper signature | `canonical_json_sha256_digest<T: Serialize + ?Sized>(&T) -> serde_json::Result<ArtifactDigest>` remains unchanged. |
| Serialization source | The helper hashes `serde_json::to_vec(value)?` exactly. |
| Hash algorithm | The helper uses SHA-256 through `Sha256`. |
| Output format | The helper returns lowercase hex through `format!("{:x}", hasher.finalize())`. |
| Test coverage | `canonical_digest_is_stable_for_equivalent_payloads` remains the direct regression proof. |
| Public facade | Existing crate-root public names remain available through `qrpc_core::*`. |

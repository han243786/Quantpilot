## Scope

This baseline freezes the already-separated runtime intent module before closeout.

Current owner file:

- `qrpc_runtime/src/intent_module.rs`

Parent export surface:

- `qrpc_runtime/src/lib.rs`
- `pub use intent_module::{BuiltinIntentModule, IntentEvaluationOutput, IntentEvaluationRequest, IntentModuleProvider};`

## Public Surface To Preserve

| Surface | Requirement |
| --- | --- |
| `IntentEvaluationRequest` | Request fields for selected intent kinds, Core IR, normalized market data, timestamp, and trace id remain unchanged. |
| `IntentEvaluationOutput` | Output continues to expose generated intent signals and runtime events. |
| `IntentModuleProvider` | Provider trait remains `Send + Sync`; default key remains `builtin.intent.default`; `evaluate_intents` signature remains unchanged. |
| `BuiltinIntentModule` | Built-in provider continues to implement the trait with no constructor or state requirement. |

## White-Box Responsibilities

`root.contracts.runtime_support.intent_module` owns:

- resolving Core IR indicators into runtime intent configs;
- evaluating each resolved intent through `core_ir_evaluator::evaluate_indicator_signal`;
- constructing `IntentSignal` values with exchange/symbol scopes, side, strength, confidence, reference price, derived metrics, reason, TTL, timestamp, and trace id;
- emitting `IntentEvaluated` and `IntentTriggered` runtime events with the existing payload shape;
- mapping Core IR indicator kinds into runtime `IntentKind` values;
- keeping local tests for quote observe, RSI, MACD, evaluator-preferred path, and custom indicator mapping.

## Boundaries To Preserve

| Boundary | Requirement |
| --- | --- |
| Parent communication | Runtime facade and coordinator continue to reach this module through the crate-root re-export. |
| Core IR evaluator | The module may call `evaluate_indicator_signal`; it must not absorb evaluator implementation. |
| Data ownership | Normalized market data remains caller-provided input; no data collection or cache behavior moves here. |
| Agent/risk/execution | Agent decisions, risk checks, execution planning, fills, sandbox, live execution, plugins, and metrics remain outside this child. |
| Event semantics | Existing event id format, event type selection, provider key payload, trace id, timestamp, and source id remain equivalent. |
| Indicator mapping | Current mappings for MA cross variants, RSI, MACD, Momentum, Spread, ZScore, Custom, QuoteObserve, and advanced indicator aliases remain equivalent. |

Decision:

Reason:

- the module is already physically separated from `qrpc_runtime/src/lib.rs`;
- the line count sits inside the terminal target range;
- the public surface is cohesive and small;
- deeper splits would mostly separate private helpers or tests, increasing governance cost without improving parent-child boundaries;
- the module has trading semantics and public API risk, so unnecessary movement is discouraged.

# v4.16.0 测试资产汰换登记

> 职责: 记录当前测试体系中即将被废弃或替换的资产，建立替代证据和风险窗口。
> 范围: E2E、视觉快照、端到端 mock、历史测试程序、抽离等价性测试。
> 非目标: 本阶段不整理 E2E，不删除旧测试程序，不把测试删除伪装成质量提升。

---

## 总原则

1. E2E 整理延后，不作为 v4.16 抽离控制面落地的阻断项。
2. 测试程序后续可以大规模废弃，但必须登记。
3. 关键行为的旧测试废弃前，必须有替代证据或明确风险窗口。
4. 抽离阶段优先使用靠近模块边界的小型等价性测试。
5. 视觉快照和大端到端流程只作为历史风险源，不作为本轮必须修复项。
6. system 经验回填后，入口抽离必须至少保留编译、旧入口可见性和入口行为测试中的一种直接证据。

## 废弃候选登记

| 候选 | 当前作用 | 废弃前必须具备 | 风险窗口 |
| --- | --- | --- | --- |
| T1 前端 E2E 大套件 | 覆盖用户路径、mock、视觉和 runtime 合约 | 组件测试、projection 测试、API 契约测试、少量稳定 smoke | 可接受短期不作为抽离阻断 |
| T2 视觉快照基线 | 发现 UI 大幅偏移 | 后续新视觉基线或人工 UI 对照清单 | 延后到 E2E 整理方案 |
| T3 testnet 长测脚本 | 外部环境/长链路验证 | 明确手动验收或独立发布前检查 | 不参与抽离批次 closeout |
| T4 destructive 测试脚本 | 高风险破坏性验证 | 明确执行环境、隔离数据和替代安全测试 | 默认不自动运行 |
| T5 历史 API 脚本 | 辅助 API smoke | Rust API tests 或轻量契约测试 | 可逐步替换 |

## 替代证据菜单

| 目标 | 优先证据 |
| --- | --- |
| 后端抽离 | Rust API tests、契约测试、artifact snapshot、event sequence |
| 前端抽离 | Vitest 组件测试、projection 单测、store action 单测、人工截图核查 |
| 启动/入口抽离 | 编译、旧 public 入口检查、入口单测、环境变量/日志人工核查 |
| 状态/锁边界 | 专门单测、并发场景小测试、人工锁顺序审查 |
| 运行证据 | runtime artifact、SSE event、history record 对照 |
| UI 行为 | 组件测试 + 人工对照，E2E 只作补充 |

---

## 进入废弃批次前的检查单

1. 是否列出旧测试路径。
2. 是否说明旧测试覆盖的行为。
3. 是否给出替代证据。
4. 若无替代证据，是否写清风险窗口和不阻断理由。
5. 是否确认废弃不会掩盖抽离导致的行为变化。
6. 是否确认废弃动作不与代码抽离混在同一批次。

---

## 非目标

- 不在 v4.16 删除任何旧测试程序。
- 不在 v4.16 更新视觉快照基线。
- 不在 v4.16 修复所有 E2E mock。
- 不把 E2E 未通过解释为抽离失败。
- 不把测试废弃解释为测试覆盖提升。

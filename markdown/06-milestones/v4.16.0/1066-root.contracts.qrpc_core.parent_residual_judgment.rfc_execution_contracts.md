## Selection Rationale

`rfc_execution_contracts` is selected because it is the final qrpc-core root residual still physically embedded in `qrpc_core/src/lib.rs` after the closed qrpc-core children were extracted:

- RFC-001 data request contracts: `MarketScope`, `PrimaryDataType`, `SourceType`, `Timeframe`, `TimeRange`, `RoundingMode`, `PrecisionPolicy`, `UsageTag`, and `DataRequest`;
- RFC-010 allocation contracts: `AllocationMethod`, `Allocation`, and `Allocation::apply_to_targets`;
- RFC-012 order contracts: `OrderStatus`, `OrderStatus::can_transition_to`, and `Order`;
- RFC-013 execution feedback contracts: `FeedbackKind` and `ExecutionFeedback`;
- phase-3 handoff contract: `HandoffSnapshot` and `HandoffSnapshot::validate_completeness`;
- the selected slice is contiguous in the crate root and remains separate from crate-root tests.

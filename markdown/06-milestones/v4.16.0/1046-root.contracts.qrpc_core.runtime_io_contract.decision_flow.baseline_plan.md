## Summary

This baseline freezes the runtime IO decision flow DTO family before extraction.

The next implementation step may move only intent, proposed action, portfolio target, agent decision, and risk decision DTOs from `qrpc_core/src/runtime_io_contract.rs` into a private child module under the runtime IO parent.

Execution IO beginning at `SimOrder`, portfolio state, runtime output, backtest output, RFC execution contracts, and crate-root tests remain parent-owned for later recursive steps.

## Frozen Surface

The selected child owns the current decision flow surface in `qrpc_core/src/runtime_io_contract.rs`:

- `IntentSignal`;
- `ProposedAction`;
- `TargetWeight`;
- `PortfolioTarget`;
- `PortfolioTargetDecision`;
- `AgentDecision`;
- `RiskDecision`.

## Equivalence Baseline

| Surface | Frozen behavior |
| --- | --- |
| Intent signal | Signal/intent identity, kind, exchange/symbol scope, side/strength/confidence, reference price, metrics, reason, timing, TTL, and trace fields remain unchanged. |
| Proposed action | Exchange, side, quantity ratio, reference price, and strategy tag fields remain unchanged. |
| Target weight | Exchange/symbol, target/current weights, reference price, defaulted optional signal score, and `PartialEq` derive remain unchanged. |
| Portfolio target | Allocation kind and defaulted target weights remain unchanged. |
| Portfolio target decision | Target id, nested target, reason, and `PartialEq` derive remain unchanged. |
| Agent decision | Agent identity, symbol, exchange targets, net side/strength, defaulted optional portfolio target decision, proposed actions, reason, timestamp, and trace fields remain unchanged. |
| Risk decision | Risk/agent identity, symbol, status, defaulted mode, optional adjusted portfolio target decision, adjusted actions, reason codes/text, timestamp, and trace fields remain unchanged. |
| Public facade | Existing `qrpc_core::*` and runtime IO parent public names remain available through parent re-exports. |

## Planned Extraction Shape

BE-001SF-02 may:

- create `qrpc_core/src/runtime_io_contract/decision_flow.rs`;
- add `mod decision_flow;` to `qrpc_core/src/runtime_io_contract.rs`;
- add `pub use decision_flow::*;` to preserve the runtime IO parent facade;
- move only the frozen decision flow surface listed above;
- keep execution IO beginning at `SimOrder`, portfolio state, runtime output, and backtest output DTOs in `qrpc_core/src/runtime_io_contract.rs`;
- keep qrpc-core crate-root exports unchanged.

## Same-Parent Parallel Wave Judgment

This child remains a single-child extraction for BE-001SF-02.

`same_parent_parallel_children` is not activated because execution IO and portfolio output DTOs refer to decision-flow types; serial parent-facade updates keep the dependency direction explicit.

## Hard Boundaries

BE-001SF-02 must not:

- change decision/action/target field names, types, serde derives, optional/default attributes, `PartialEq` derives, public exports, or tests;
- move execution IO, portfolio state, runtime output, backtest output, RFC execution contracts, or crate-root tests;
- change closed market data IO or other qrpc-core children, downstream runtime/backend/compiler behavior, or release transition;
- create direct sibling shortcuts to other runtime IO child candidates.

## Split Rule Pre-Check

| Rule | Baseline result |
| --- | --- |
| Physical owner | Worth extracting. The selected slice is a contiguous decision DTO family after market data IO. |
| Public surface | Continue only at this layer. Public names remain preserved through parent and crate-root facades. |
| Mixed responsibility | Stop after extraction unless target/agent/risk DTOs expand independently. The family is cohesive as a decision flow boundary. |
| State ownership | Stop after extraction. The child owns no mutable runtime state. |

| Future reopen rule | Allowed only for concrete decision schema, target/action semantics, serde shape, or public facade proposals. |

## Summary

This baseline freezes the next Strategy IR root validation child before extraction.

The next implementation step may move only the unknown marker helper implementation and `unknowns[*]` path/reason validation into a private child module under `root_validation.rs`.

The already closed identity, signal/logic, risk, and data/execution validation children remain authoritative. This baseline narrows the next safe movement without changing Rust source code.

## Frozen Surface

The selected child owns the current unknown marker validation surface in `qrpc_core/src/strategy_ir/root_validation.rs`:

- the final loop over `self.unknowns`;
- `unknowns[{index}].path` required-field validation;
- `unknowns[{index}].reason` required-field validation;
- the implementation of `validate_unknownable`;
- the implementation of `validate_unknownable_opt`.

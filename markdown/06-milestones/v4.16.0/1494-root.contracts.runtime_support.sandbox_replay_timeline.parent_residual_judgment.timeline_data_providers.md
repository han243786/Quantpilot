## Decision

## Evidence

`qrpc_runtime/src/sandbox/timeline.rs` currently owns two separable concerns:

- timeline data provider implementations;
- unified timeline assembly and cursor advancement.

The provider concern is a clear first child because it groups the source-specific `asof` data providers used by replay and unified timeline assembly.

- provider-local tests, if they are physically separable without weakening the unified timeline tests.

- sandbox modes and `Sandbox` trait in `mod.rs`;
- realtime and fast-backtest sandbox implementations;
- crate-root exports and sibling runtime-support modules.

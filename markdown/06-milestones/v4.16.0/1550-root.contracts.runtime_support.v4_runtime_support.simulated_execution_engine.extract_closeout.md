## Decision

## Boundary Corrections

During extraction, the old include file was found to contain three non-simulated helpers. They were not moved into the simulated execution child:

- transition source matching now lives beside transition matching in `qrpc_runtime/src/v4_runtime/machine_transition_engine.rs`;
- transition freshness matching now lives beside transition matching in `qrpc_runtime/src/v4_runtime/machine_transition_engine.rs`;
- event payload field type validation now lives in the v4 runtime parent beside `validate_event_payload`.

This keeps the new child from absorbing transition or payload-validation responsibilities.

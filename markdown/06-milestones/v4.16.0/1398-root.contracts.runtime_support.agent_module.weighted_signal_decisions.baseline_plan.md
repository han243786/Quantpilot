## Boundaries To Preserve

| Boundary | Requirement |
| --- | --- |
| Signal filtering | Observe signal rules and `IntentKind::QuoteObserve` remain excluded from weighted decisions. |
| Grouping | Signals still group by first exchange scope and first symbol scope with Binance/BTCUSDT fallbacks. |
| Weighted score | Net score remains confidence-weighted with confidence minimum `0.1`. |
| Thresholds | Decision threshold defaults to `DEFAULT_DECISION_THRESHOLD` and is bounded by `MIN_QUANTITY_RATIO`. |
| Max quantity | `agent.max_quantity_ratio` clamp remains `MIN_QUANTITY_RATIO..=1.0`. |
| Sell clamp | Short-side quantity still clamps to `available_position_ratio`. |
| Output shape | Decision id, symbol, exchange target, net side, proposed action, strategy tag, reason, timestamp, and trace id remain equivalent. |
| Parent facade | `evaluate_agents` continues to select this path only for `AgentPolicyKind::WeightedSignals` on `slow` cycle. |

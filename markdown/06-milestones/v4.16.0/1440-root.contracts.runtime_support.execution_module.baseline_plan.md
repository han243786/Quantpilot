## Decision

`continue_split: true`

Limited split reason:

- moving local tests gives the parent a compact production owner without changing provider or helper visibility;
- splitting production planning helpers now would create wrapper churn around public provider traits and private order helpers;
- `fill_engine`, `risk_support`, `data_module`, and `runtime_facade_coordinator` remain separate sibling boundaries.

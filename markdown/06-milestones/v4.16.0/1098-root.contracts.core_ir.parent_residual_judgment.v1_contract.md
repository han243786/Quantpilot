## Selection Rationale

`v1_contract` is selected first because it is currently embedded in the crate root. Extracting it into `qrpc_core_ir/src/v1.rs` can turn `qrpc_core_ir/src/lib.rs` into a stable facade before the much larger v4 parent is split.

Selected surface:

- v1 version constants;
- `CoreStrategyIr`, `CoreIREdge`, metadata/data/indicator/signal/agent/risk/execution DTOs;
- expression helper builders;
- `CoreStrategyIr::new`;
- `CoreStrategyIr::validate_dag`;
- local v1 round-trip test.

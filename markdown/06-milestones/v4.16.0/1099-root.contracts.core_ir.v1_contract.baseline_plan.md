## Summary

This baseline freezes the v1 Core IR contract before extraction from `qrpc_core_ir/src/lib.rs`.

The next implementation step may move only the v1 Core IR declarations and local v1 test into `qrpc_core_ir/src/v1.rs`. The crate root must preserve existing public names with `pub use v1::*`, and `pub mod v4;` must remain available.

## Frozen Surface

The selected child owns:

- `CORE_IR_V1_VERSION`;
- `CUSTOM_EXPR_V1_VERSION`;
- `CoreStrategyIr`, `CoreIREdge`, `CoreMetadata`, `CoreSourceKind`;
- data, indicator, expression, signal, agent, risk, and execution DTOs/enums;
- `CoreStrategyIr::new`;
- `CoreStrategyIr::validate_dag`;
- helper builders: `close_series_expr`, `moving_average_series_expr`, `moving_average_compare_expr`, `indicator_threshold_compare_expr`;
- private default helpers for v1 fields;
- local `core_ir_round_trips` test.

| Surface | Frozen behavior |

| v4 module | Existing `qrpc_core_ir::v4` module remains unchanged and outside this move. |

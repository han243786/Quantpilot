# v1.0.4 前端排版美化

> 基于 v0.5.0 Adobe 风格设计系统 | CSS 修复 + 视觉层次 + 排版优化 | 0 新增 npm 依赖

---

## 背景

v0.5.0 的 Adobe 风格设计系统 (`design-system.css` + `shared.css`) 已定义完整的 `--ad-*` 令牌体系，但落地不彻底。v1.0.4 聚焦纯 CSS 层面的修复和优化，不改 JSX 组件结构。

### 当前问题

1. 3 个页面 CSS 文件中存在 **25 处空 `background:` 属性**（无效 CSS），另有 6 处空 CSS 自定义属性
2. `styles.css` 中的按钮/组件混用旧变量 (`var(--panel)`, `var(--text)`) 和硬编码颜色值
3. `strategy-card-note` 样式在 strategy-hub.css 和 strategy-workspace.css 中**重复 152 行**
4. 视觉层次扁平 — 面板/卡片缺乏深度感，border 颜色过弱
5. 字体排版不一致 — 行高偏低 (1.45)，中文可读性不佳
6. 未定义的 CSS 变量引用 (`--analysis-surface-glint`)

---

## 目标

- 修复所有 CSS 语法错误（空 background 属性、空自定义属性、未定义变量引用）
- 统一所有组件使用 `--ad-*` 设计令牌
- 提升视觉层次：面板深度感、卡片呼吸感、清晰的信息边界
- 优化排版：统一行高、提升可读性
- 不改 JSX 结构，仅修改 CSS 文件
- 不引入新 npm 依赖

---

## 原则

- 只改 CSS，不碰 JSX
- 不改功能逻辑，只改视觉呈现
- 保持暗色主题，对标 Photoshop/Illustrator 专业面板风格
- `npx vite build` + `npx vitest run` 持续通过

---

## 实施阶段

### Phase 1 — 修复 CSS 语法错误 + 令牌统一

**1A — 修复空 `background:` 属性**

| 文件 | 修复数量 |
|------|:------:|
| `frontend/src/pages/strategy-hub.css` | 10 处 |
| `frontend/src/pages/strategy-workspace.css` | 12 处 |
| `frontend/src/pages/backtest-analysis.css` | 3 处 + 6 处空自定义属性 + 1 处未定义变量 |

**1B — 统一 styles.css 旧变量**

| 旧写法 | 新写法 |
|--------|--------|
| `var(--panel)` | `var(--ad-panel)` |
| `var(--panel-2)` | `var(--ad-panel)` |
| `var(--text)` | `var(--ad-text)` |
| `border-radius: 8px` | `var(--ad-radius-panel)` |

**1C — 消除重复样式**

从 `strategy-workspace.css` 移除 152 行与 `strategy-hub.css` 完全重复的 `.strategy-card-note*` 样式块。

### Phase 2 — 提升视觉层次

- 设计令牌值优化：加深面板/卡片背景以增强与 #0d0d0d 底色的对比
- 边框颜色 #404040→#4a4a4a 提升面板边界可见度
- 卡片增加 `inset 0 1px 0 rgba(255,255,255,0.02)` 顶部高光线
- 卡片 hover: `translateY(-1px)` + shadow 增强
- 侧边栏背景 #141414→#0f0f0f 与内容区形成更强对比
- Tab/侧边栏激活态指示器 2px→3px 加粗
- 表格行 hover 微弱背景反馈

### Phase 3 — 排版优化

- 正文行高 `1.45` → `1.6`（提升中文可读性）
- 标题行高 `1.15` → `1.25`
- 正文增加 `letter-spacing: 0.01em`
- 卡片内边距 `10px 12px` → `12px 14px`
- 新增 `--ad-font-size-hero: 24px` 令牌

### Phase 4 — 微交互润色

- 按钮过渡: `background 0.12s ease, border-color 0.12s ease, color 0.12s ease, transform 0.1s ease`
- 按钮 active: `transform: scale(0.97)`
- 滚动条颜色统一使用 `--ad-border` / `--ad-border-strong` 令牌

## P1 — 必须完成

### P1-1: PaperActual 自动 runner 未实现

**问题**: `src-executor/main.rs` 在 `provider_order_submission_attached()` 模式下启动策略返回 `NOT_IMPLEMENTED`。当前只有手动 submit/query/cancel provider 路由, 用户选择 OKX 模拟盘后无法自动执行策略。

**方案**:
1. RunnerPool 将策略 execution event 转为 provider order router 请求。
2. 只允许 `ExecutionMode::PaperActual` + OKX demo profile + `x-simulated-trading: 1`。
3. 订单提交、查询、撤单和回执全部写入脱敏审计。
4. 真实资金 profile 保持不可达。

**验收**:
- PaperActual 策略自动产生 OKX demo order id。
- 非 demo profile / production endpoint 被拒绝。
- evidence 明确标注 OKX 模拟盘 / 非真实资金。

### P1-2: 插件安全策略未在运行路径强制执行

**问题**: `RuntimePluginRegistry::check_security` 已实现但注释说明尚未在生产执行路径接线; `PluginSandbox` 说明无网络和文件系统隔离。

**方案**:
1. 插件执行前必须验证 Ed25519 manifest 签名或本地 trusted policy。
2. `check_security` 接入所有插件 action: network, credentials, state write。
3. `PluginSandbox::execute` 根据 manifest security 配置 timeout/memory/network/file 策略。
4. Windows 平台补 Job Object 或明确 fail-closed/降级策略。

**验收**:
- 未声明 allow_network 的插件发起网络能力时被拒绝。
- 插件默认不能访问凭证。
- 本地 manifest 未签名时必须来自显式 trusted source。

## P2 — 优先完成

### P2-1: OpenAPI 与 API 版本治理

**问题**: 路由混用 `/api` 和 `/api/v1`; 当前已有迁移注释但缺路线。v4.8.1 修复凭证路径缩进后, v4.9.0 继续做版本治理。

**方案**:
1. 生成实际路由 vs OpenAPI diff。
2. 定义 `/api/v1` 迁移矩阵和兼容窗口。
3. 对旧路径返回 deprecation header。

**验收**: route diff 无未知缺口; OpenAPI lint 通过。

### P2-2: 策略包导入/导出不完整

**问题**: 已有运行配置和 QS 源码导出, 但缺完整策略包导入/导出和回测分享包。

**方案**:
1. 定义 `.quantpilot-strategy.json` 包格式。
2. 包含 graph、formal_source、capability_context、template/version、backtest summary。
3. 导入时验证 schema、版本、能力 hash 和文件大小。

**验收**: 用户可导出策略包并在新环境导入复现。

### P2-3: 无用户设置页

**问题**: 语言、主题、编辑器行为、profile 状态分散在不同入口或不可配置。

**方案**:
1. 新增 Settings 页面。
2. 管理 locale、主题偏好、编辑器草稿策略和 profile 摘要。
3. 设置项写入本地持久化并可重置。

**验收**: 用户能在单一页面完成偏好配置。

### P2-4: AI 沙箱失败缺队列/管理员动作

**问题**: 沙箱验证有 3 次退避重试和日志, 但失败后没有可见队列或管理员覆盖机制。

**方案**:
1. 失败 proposal 进入 sandbox retry queue。
2. 审批页显示失败原因、下一步、重试按钮和管理员 override。
3. 所有 override 进入 audit event。

**验收**: 3 次失败后不静默丢失, 可人工处理。

### P2-5: 执行端 K 线缺周期/缩放控制

**问题**: `KlineChart` 只渲染图表, 缺 timeframe selector、zoom preset、数据源说明。

**方案**:
1. 增加周期选择器和缩放 preset。
2. 标注 public market-data / demo provider / replay source。
3. 与 PaperSimulated/PaperActual 模式文案联动。

**验收**: 执行端用户能切换周期并理解数据来源。

## 不纳入项

- 真实资金 `LiveActual` 自动交易: 延后到 v5 或更高安全等级。
- 远程插件市场 UI: 继续延后。
- 多 provider 扩张: 按 v4 provider 范围收口, 延后到 v5。

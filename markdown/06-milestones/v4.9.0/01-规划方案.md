# v4.9.0 规划方案 — 产品功能完整度与插件执行安全

> 版本类型: MINOR | 基准: v4.8.x 收敛线
> 来源: Claude 产品/UX/功能完整度审计 + Codex 代码侧核查
> 目标: 补齐产品功能闭环和插件执行安全, 不开放真实资金 `LiveActual`

---

## 目标

v4.9.0 处理超出 PATCH 范围的功能完整度问题: PaperActual 自动 runner、插件安全强制、策略包导入/导出、设置页、API 版本治理、AI 沙箱队列和执行端图表控制。

1. **PaperActual 自动 runner**: 在 OKX 模拟盘范围内接入 provider order router, 保持真实资金 fail-closed。
2. **插件执行安全**: 将 manifest 安全策略、Ed25519 签名、runtime registry 和 PluginSandbox 执行路径串成强制门禁。
3. **策略包导入/导出**: 支持完整策略图、QS 源、能力上下文、回测摘要和可复现元数据的包格式。
4. **用户设置页**: 统一管理语言、主题、编辑器偏好、profile 状态和安全提示。
5. **API 版本治理**: 建立 `/api` 与 `/api/v1` 迁移计划和兼容窗口。
6. **AI 沙箱队列**: 3 次失败后进入可见队列, 支持管理员重试/覆盖/关闭。
7. **执行端图表控制**: K 线周期、缩放、数据源标记和模式边界可见。

## 非目标

- 不接入真实资金 provider。
- 不开放 `LiveActual` 自动交易。
- 不开放第三方远程插件安装 UI。
- 不把 OKX 模拟盘宣传为实盘。
- 不新增非 OKX provider。

## 回归保护矩阵

| 受影响能力 | 风险 | 保护证据 | 验证命令 |
|------------|------|----------|----------|
| PaperActual | 自动 runner 误触真实资金 | demo flag + simulated header + mode guard | executor tests + ignored smoke |
| 插件执行 | 未声明网络/凭证访问被放行 | security policy tests | `cargo test -p qrpc-runtime plugin` |
| 策略包 | 导入包越权或能力漂移 | schema + capability hash 校验 | backend + frontend tests |

| API 版本 | 旧客户端断裂 | deprecation matrix | OpenAPI lint + route diff |
| 沙箱队列 | 审批状态不一致 | queue/audit tests | runtime mutation tests |
| 图表控制 | 数据源误读 | executor visual smoke | frontend-executor tests |

## 兼容性与迁移

- PaperActual runner 只允许 OKX demo profile, 真实资金仍不可启动。
- 插件安全强制先覆盖本地运行路径, 远程市场安装 UI 继续延后。
- `/api` 到 `/api/v1` 迁移必须提供兼容期和 deprecation header。
- 策略包导入必须验证 schema、版本、能力 hash 和文件大小。

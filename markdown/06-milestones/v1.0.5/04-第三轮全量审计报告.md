## S0 — 阻断级 (5项)

### S0-1 SSE 重连处理器转移完全失效

**来源**: Agent 7 (状态管理) | **文件**: `graphStoreRuntimeTransport.js:39-41`

```js
if (es._onMessage) next.addEventListener("runtime_event", es._onMessage);
if (es._onComplete) next.addEventListener("run_completed", es._onComplete);
if (es._onError) next.onerror = es._onError;
```

`_onMessage`/`_onComplete`/`_onError` 从未被设置。实际的监听器通过标准 `source.addEventListener()` 注册，不会设置这些属性。**SSE 重连后所有事件静默丢失**，`onRetryExhausted` 回调永不触发。

### S0-2 未保存的策略图刷新后全部丢失

**来源**: Agent 9 (工作流) | **文件**: `graphStore.js:190-196` + `graphStorePersistenceHelpers.js:512-516`

`graphExistsInIndex()` 检查 `graph_id` 是否在后端索引中。但 `openBlankWorkspace()` 生成的是客户端 `graph_${Date.now()}` ID，从未持久化到后端。刷新后 localStorage 中的完整策略图被跳过，用户看到空白图。**任何没有点过"保存"的用户在刷新后丢失全部工作。**

### S0-3 运行时清理 effect 有闭包过期 bug

**来源**: Agent 9 (工作流) | **文件**: `StrategyWorkspacePage.jsx:66-72`

```js
useEffect(() => {
  return () => { if (runtime?.status === "running") stopRuntime(); };
}, []);  // ← 空依赖数组
```

空 `[]` 导致 cleanup 函数永远捕获挂载时的 `runtime` 值（`"idle"`）。`stopRuntime()` **从未被调用**。页面导航离开后，后端模拟进程成为孤儿，持续运行不可控。

### S0-4 跨标签删除策略导致状态静默损坏

**来源**: Agent 9 (工作流) | **文件**: `graphStore.js:160-171`

Storage 监听器盲目接受 localStorage 中的任何 graph 而不验证。Tab B 删除策略后 Tab A 的 graph 被替换为空白图，URL 参数与状态图 graph_id 不同步，无任何用户提示。

### S0-5 无运行互斥锁——可同时启动两个模拟

**来源**: Agent 7 (状态管理) | **文件**: `graphStoreRuntimeSessionActions.js:71-82`

`startRuntime()` 的 POST 请求期间没有互斥锁。快速双击"启动模拟"会发起两个并行 POST、创建两个 SSE 连接，第一个连接泄漏无法关闭。

## P1 — 高优 (8项)

### P1-1 safeSetItem 中 JSON.stringify 无 try-catch

**来源**: Agent 8 (故障注入) | **文件**: `graphStorePersistenceHelpers.js:40`

循环引用对象传入 `JSON.stringify` 会抛出 `TypeError`，无 try-catch 包裹。导致:
- saveGraph 中静默失败：zustand state 已更新但 localStorage 未写入
- initialize 中：store 可能保持在 undefined 状态

### P1-2 编译按钮禁用无画布侧提示

**来源**: Agent 9 (工作流) | **文件**: `workspaceActionBarShared.js`

`is_valid` 为 false 时编译按钮 disabled，但原因只在 tooltip 中可见。节点不自动高亮，问题节点不可见。用户必须手动切到诊断标签页。

### P1-3 focusFinding() 不切换工作区标签页

**来源**: Agent 9 (工作流) | **文件**: `useWorkspaceActionBarActions.js:203-218`

点击工具栏问题芯片只设置 `selectedNodeId`，不切换到 "code" tab。若用户在 dashboard tab，点击后看不到任何变化。

### P1-4 画布编辑器 1180px 以下不可用

**来源**: Agent 9 (工作流) | **文件**: `strategy-workspace.css:1106-1109`

三面板构建器在 1180px 处折叠为垂直堆叠，拖拽操作不可能。无移动端优化方案或桌面端提示。

### P1-5 凭证保存静默失败

**来源**: Agent 9 (工作流) | **文件**: `TopToolbar.jsx:435-437`

`handleSave` 中 `catch (_) {}` 吞没所有错误。POST 失败时无任何用户反馈，表单保持打开状态。

### P1-6 持久化 actions 捕获过期状态 (stale closure)

**来源**: Agent 7 (状态管理) | **文件**: `graphStoreCompileActions.js:133` + `graphStorePersistenceActions.js:83`

`compileCurrentGraph()` 和 `saveGraph()` 在 async 操作前用 `get()` 捕获 graph，async 期间若有并发编辑，完成时用过期 graph 覆盖新编辑。

### P1-7 重连定时器无法取消 + POST 请求无法 abort

**来源**: Agent 7 (状态管理) | **文件**: `graphStoreRuntimeTransport.js:36`

SSE 重连的 `setTimeout` ID 未存储，`stopRuntime()` 无法取消。`startRuntime`/`startBacktest` 的 POST 不接收 AbortSignal。

### P1-8 跨标签同步不验证 graph

**来源**: Agent 7 (状态管理) | **文件**: `graphStore.js:167-168`

Storage 监听器直接 `set({ graph })`，不调用 `resolveLoadedGraphWithRegistry()` 或 `attachValidationWithRegistry()`。不检查 dirty state，不合并/警告。

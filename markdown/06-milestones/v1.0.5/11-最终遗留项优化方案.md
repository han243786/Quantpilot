## 一、分页部署 (C2) — 等后端

- 8 个列表端点全部返回裸数组, 无分页

### 后端实施指南

**Step 1**: `src/frontend_api_types.rs` 新增共享类型:
```rust
#[derive(Debug, Deserialize, Default)]
pub struct PaginationQuery {
    pub limit: Option<u32>,
    pub offset: Option<u32>,
}

#[derive(Debug, Serialize)]
pub struct PaginatedResponse<T: Serialize> {
    pub data: Vec<T>,
    pub total: usize,
    pub limit: u32,
    pub offset: u32,
}

pub fn paginate<T>(mut items: Vec<T>, query: PaginationQuery) -> PaginatedResponse<T> {
    let total = items.len();
    let limit = query.limit.unwrap_or(20).min(100) as usize;
    let offset = query.offset.unwrap_or(0) as usize;
    if offset > 0 { items = items.into_iter().skip(offset).collect(); }
    items.truncate(limit);
    PaginatedResponse { data: items, total, limit: limit as u32, offset: offset as u32 }
}
```

**Step 2**: 8 个 handler 接入——每个 handler 在 `items.sort_by(...)` 后加一行:
```rust
return Json(paginate(items, pagination_query));
```

**Step 3**: 前端消费方逐页接入 `withPagination()`。

## 三、测试质量收尾

### P2-15: StrategyCanvas.focus.test.jsx 50ms setTimeout

当前: `window.setTimeout(resolve, 50)` 硬编码延迟, CI 负载下可能 flaky。
方案: 改为 `vi.useFakeTimers()` + `vi.advanceTimersByTime(50)`:
```js
vi.useFakeTimers();
const promise = waitForFocusUpdate();
vi.advanceTimersByTime(50);
await promise;
vi.useRealTimers();
```
估时: **5min**。

### P2-17: axe-core 可访问性测试

当前: 零自动 A11y 检测。
方案: 无需新依赖——`@testing-library/jest-dom` 已内置 `toHaveAccessibleName()`, `toHaveRole()` 等。为关键页面添加基础断言:
```js
expect(screen.getByRole("main")).toBeInTheDocument();
expect(screen.getByRole("navigation")).toBeInTheDocument();
```
估时: **15min**。

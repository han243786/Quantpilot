## S0 — 阻断级

### S0-1 所有页面缺少 `<main>` 元素 (6 页面)

**来源**: Agent 4 (A11y) | **影响**: 屏幕阅读器用户无法跳过导航直达内容

| 页面 | 当前 | 应改为 |
|------|------|--------|
| AlertsPage | `<div className="qp-page">` | `<main className="qp-page">` |
| ApprovalPanel | `<div className="qp-page">` | `<main className="qp-page">` |
| BacktestDetailPage | `<div className="detail-page">` | `<main className="detail-page">` |
| StrategyHubPage | `<div className="strategy-hub-page">` | `<main className="strategy-hub-page">` |
| StrategyWorkspacePage | `<div className="strategy-workspace-page">` | `<main className="strategy-workspace-page">` |
| SnapshotsPage/ChaosPage/RunbookPage | 同上 | 同上 |

### S0-2 所有页面缺少 `<h1>` (8 页面)

**来源**: Agent 4 (A11y) | **影响**: 屏幕阅读器无页面主题描述

没有一个审计页面包含 `<h1>`。所有页面从 `<h2>` 甚至无标题开始。StrategyHubHeroSection 完全没有标题元素。

### S0-3 主导航使用 `<button>` 而非 `<a>` (LeftSidebar)

**来源**: Agent 4 (A11y) | **文件**: `LeftSidebar.jsx:38-47`

7 个主导航项 (策略/QS/审批/告警/快照/故障手册/混沌) 全部使用 `<button onClick={navigateTo}>` 而非 `<a href>`。导致：右键"在新标签页打开"不可用、书签不可用、屏幕阅读器无法识别为导航链接。

### S0-4 组件文件过大 (2 文件)

**来源**: Agent 5 (代码质量)

| 文件 | 行数 | 导出组件数 |
|------|------|:--:|
| `propertyPanelViews.jsx` | 1478+ | 33 |
| `EventStreamPanel.jsx` | 1557+ | 20+ |

两个文件都严重违反单一职责，应拆分。

**来源**: Agent 6 (安全)

`quantpilot_frontend_graph` 键存储完整策略图 JSON（节点配置/参数/拓扑），属于专有交易逻辑。若存在 XSS 漏洞可被导出。

**来源**: Agent 5

`useStrategyWorkspaceUiState.js` 和 `useStrategyDirectoryModel.js` 中多个返回函数未用 `useCallback` 包裹，导致子组件不必要的重渲染。

### P2-5 无障碍细节 (4 项)

**来源**: Agent 4

- `role="listitem"` 卡片缺少父级 `role="list"`
- 侧边栏导航缺少 `aria-current="page"`
- 无 `sr-only` 仅屏幕阅读器文本
- 动态事件流缺少 `aria-live` 区域

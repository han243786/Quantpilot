## S0 — 阻断级 (致命缺陷)

### S0-1 破坏性操作无确认对话框 (3 处)

**来源**: Agent 3 (交互审计) | **文件**: TopToolbar.jsx

用户点击以下操作时**立即执行，无任何确认**：

| 操作 | 行号 | 后果 |
|------|------|------|
| `resetGraph` 重置策略图 | 138-140 | 整个策略图丢失 |
| `resetRuntime` 重置运行时 | 216-218 | 可能中断进行中的模拟 |
| `deleteCredential` 删除凭证 | 439-443, 484 | 凭证永久删除 |

**修复**: 在三处操作前添加 `window.confirm("此操作不可撤销。是否继续？")`。

### S0-2 数据丢失防护缺失 (无 beforeunload)

**来源**: Agent 3 (交互审计)

应用中**没有任何 `beforeunload` 事件处理**。用户在编辑策略图后关闭标签页或导航离开时，不会收到 "有未保存更改" 的警告。

**修复**: 在 graphStore 中添加脏状态跟踪，注册 `beforeunload` 事件处理。

## P1 — 高优 (合理的数据丢失/竞争场景)

### P1-1 乐观更新无回滚 (saveGraph)

**来源**: Agent 1 (数据处理审计) | **文件**: `graphStorePersistenceActions.js:139-158`

`saveGraph` 在 API 调用成功前就更新了本地状态和 localStorage。如果 `/graphs/save` 请求失败，UI 显示"已保存"但服务端没有数据。刷新页面后数据丢失。

**修复**: API 调用失败后回滚状态到保存前的快照。

### P1-2 颜色对比度不达标

**来源**: Agent 2 (视觉审计) | **文件**: `design-system.css`

`--ad-text-muted` (#909090) 在 `--ad-card` (#242424) 背景上的对比度为 **4.15:1**，低于 WCAG AA 要求的 4.5:1。影响卡片上的标签、时间戳、辅助文本。

**修复**: `--ad-text-muted` 从 #909090 → #9e9e9e (对比度 4.6:1)。

### P1-3 减少动画偏好未全覆盖

**来源**: Agent 2 (视觉审计)

`@media (prefers-reduced-motion: reduce)` 已在 styles.css 中定义，但**缺失以下元素的覆盖**：

| 缺失位置 | 文件 |
|---------|------|
| 侧边栏 hover 展开动画 | design-system.css:288 |
| 骨架屏 loading 动画 (skeleton-pulse) | shared.css:267-275 |
| Popup 弹出动画 (opacity/transform) | strategy-hub.css:403 |
| Tab 切换动画 (border-color/transform) | strategy-workspace.css:88 |

**修复**: 在各对应文件中补充 `prefers-reduced-motion` 媒体查询。

### P1-4 编译和保存操作无防抖/节流

**来源**: Agent 1 (数据处理审计)

`compileCurrentGraph` 没有 `compileStatus: "loading"` 标志。`saveGraph` 没有锁。快速连续点击可导致重叠请求。

**修复**: 为 compileCurrentGraph 添加 loading 状态锁。为 saveGraph 添加防抖或互斥锁。

### P1-5 KPI/操作卡片文本溢出无省略号

**来源**: Agent 2 (视觉审计) | **文件**: `strategy-hub.css`

`.strategy-kpi-card strong` 和 `.strategy-ops-card strong` 设置了 `white-space: nowrap` 但**没有** `overflow: hidden` 和 `text-overflow: ellipsis`。长值会直接溢出卡片。

**修复**: 添加 `overflow: hidden; text-overflow: ellipsis;`。

### P1-6 Workspace 页头名称/ID 无溢出保护

**来源**: Agent 2 (视觉审计) | **文件**: `design-system.css:403-412`

`.ad-workspace-header__name` 和 `__id` 没有 overflow 保护。长策略名和 UUID 会溢出。

**修复**: 添加 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`。

### P1-7 dashboard-grid 无响应式断点

**来源**: Agent 2 (视觉审计) | **文件**: `styles.css:4354-4357`

`grid-template-columns: repeat(4, 1fr)` 在任何宽度下都保持 4 列，窄屏下内容会被挤碎。

**修复**: 添加 `@media (max-width: 768px)` { `grid-template-columns: repeat(2, 1fr)` }。

### P1-8 ErrorBoundary 缺少 onRetry (PropertyPanel)

**来源**: Agent 3 (交互审计) | **文件**: `PropertyPanel.jsx:20,44,58`

PropertyPanel 的 3 个 ErrorBoundary 包装器都**没有传递 `onRetry` 属性**。用户看到静态错误消息后只能手动刷新整页。

**修复**: 传递 `onRetry` 回调，重置错误状态并重新挂载。

## P2 — 中优 (边界情况/体验优化)

### P2-1 formatValue 无 NaN/Infinity 守卫

**来源**: Agent 1 | **文件**: `backtestAnalysisShared.jsx:1-7`

`formatValue` 检查了 null/undefined/空字符串，但**没有** `isFinite()` 守卫。NaN/Infinity 传入会导致显示 "NaN" / "Infinity" 字符串。

**修复**: 添加 `Number.isFinite(value)` 检查。

### P2-2 compileCurrentGraph 无 loading 状态

**来源**: Agent 1 | **文件**: `graphStoreCompileActions.js`

编译过程中没有 `compileStatus: "loading"` 标志。UI 无法区分"未编译"和"编译中"。如果用户快速点击编译按钮，会同时发起多个请求。

**修复**: 添加 `compileStatus` 状态字段。

### P2-3 localStorage 无 SSR 守卫

**来源**: Agent 1 | **文件**: `graphStorePersistenceHelpers.js`

`loadGraphFromStorage` 和 `safeSetItem` 在访问 `window.localStorage` 前没有检查 `typeof window !== "undefined"`。如果在 SSR 环境中被调用会崩溃。

**修复**: 在访问前添加 window 存在性检查。

### P2-4 双滚动条风险 (qs-source-code)

**来源**: Agent 2 | **文件**: `styles.css`

`qs-source-code` 设置了 `max-height: 60vh; overflow: auto`，但其父容器也可能是可滚动的。窄屏下可能出现双滚动条。

**修复**: 父容器使用 `overflow: hidden` 或确保 `max-height` 计算考虑到父容器。

### P2-5 无 @media print 规则

**来源**: Agent 2 | **所有 CSS**

代码库中不存在任何 `@media print` 规则。打印时暗色背景会消耗墨水，fixed 定位元素会遮挡内容。

**修复**: 添加基本的 print 样式（白色背景、隐藏侧边栏/标题栏/叠加层）。

### P2-6 CommandPalette 无焦点捕获

**来源**: Agent 3 | **文件**: `CommandPalette.jsx`

命令面板打开时 Tab 键可将焦点移出面板到后方元素。缺少模态焦点捕获。

**修复**: 实现焦点循环（Tab/Shift+Tab 限制在面板内）。

### P2-7 保存按钮文本不显示 "保存中..."

**来源**: Agent 3 | **文件**: `TopToolbar.jsx:144-160`

保存时按钮只变 disabled，文本不变。与 CredentialInput 的"保存中..."行为不一致。

**修复**: 按钮文本改为 `{saving ? "保存中..." : "保存策略图"}`。

### P2-8 API_BASE 双定义

**来源**: Agent 1 | **文件**: `api.js:1` vs `graphStorePersistenceHelpers.js:20-30`

`VITE_BACKEND_ORIGIN` 在 api.js 中定义但仅在 fetchWithTimeout 使用（不被任何 API 调用使用）。实际生效的是 resolveApiBase() 中的 VITE_API_BASE_URL。

**修复**: 统一为单一环境变量。

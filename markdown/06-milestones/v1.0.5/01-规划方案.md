# v1.0.5 前端样式深度修复

> 基于 v1.0.4 全量前端审计 | 3 个 agent 并行分析 | 无新功能 | 纯 CSS/JSX 质量修复

---

## 背景

v1.0.4 完成了前端排版美化（视觉层次、排版、空 background 修复）。本轮针对 v1.0.4 后启动的**全量前端审计**发现的更深层问题进行修复。审计由 3 个 agent 并行进行，覆盖：

- 79 个 JSX 文件 (31 组件 + 48 页面)
- 6 个 CSS 文件 (~5400 行)
- 49 个 JS 文件 (22 hooks + 27 utils/其他)

---

## 原则

- 只改 CSS + JSX，不碰功能逻辑
- 不改后端代码
- 不引入新 npm 依赖
- `npx vite build` + `npx vitest run` 持续通过

---

## P0 — 阻断级 CSS 语法错误

### P0-1 styles.css 多行选择器缺少逗号 (~50 处)

**严重度**: 🔴 阻断 | **来源**: 全量 CSS 审计

**问题**:

`styles.css` 中大量使用多行选择器但没有逗号分隔，CSS 将其解析为后代选择器而非分组选择器，

导致 `.primary-btn` `.ghost-btn` `.danger-btn` `.status-pill` `.toolbar-issue-chip` 等数十个基础组件的样式可能从未生效。

```css
/* ❌ 当前: 解析为后代选择器, 几乎不会匹配任何元素 */
.primary-btn
.ghost-btn
.danger-btn {
  border: 1px solid var(--ad-border);
  ...
}

/* ✅ 正确: 用逗号分隔的分组选择器 */
.primary-btn,
.ghost-btn,
.danger-btn {
```

**涉及的选择器组 (~50 处)**:

### P0-2 补齐未定义的 CSS 变量兼容别名

**严重度**: 🔴 阻断 | **来源**: 全量 CSS 审计

**问题**:

`styles.css` 中使用 `var(--danger)` `var(--warning)` `var(--success)` 但 `design-system.css` 的 `:root` 兼容别名块中未定义这些变量。

| 变量 | 使用位置 | 应有值 |
|------|---------|--------|
| `--danger` | styles.css:1463-1466, 1698-1700 | `var(--ad-error)` |
| `--warning` | styles.css:1689-1700 | `var(--ad-warning)` |
| `--success` | styles.css:1463 | `var(--ad-success)` |

**方案**:

在 `design-system.css` `:root` 兼容别名块中添加：

```css
--danger: var(--ad-error);
--warning: var(--ad-warning);
--success: var(--ad-success);
```

**验收**:
- `grep -rn "var(--danger)\|var(--warning)\|var(--success)" frontend/src/styles.css` 仍存在
- 但 `grep -rn "\-\-danger:\|\-\-warning:\|\-\-success:" frontend/src/design-system.css` 返回匹配

### P0-3 修复 ~15 处 background 双值无效语法

```css
/* ❌ 无效 — 第二个值被浏览器忽略 */

background: rgba(12, 20, 32, 0.92);
```

**涉及行**: 520, 1030, 2168, 2182, 2195, 2359, 2445, 2570, 2711, 2719, 3098, 3436, 3450, 3928, 4012

**方案**:

逐个检查每处上下文，决定保留哪个 background 值，删除另一个。

**验收**:
- `grep -rn "background: var(.*); r" frontend/src/styles.css` 返回 0

## P2 — 设计令牌扩展与统一

### P2-1 扩展 --ad-space-* 令牌补充常用值

**严重度**: 🟡 中 | **来源**: CSS 审计 | **估时**: 5min

**问题**:

当前令牌只有 `4/8/12/16/20/24`，但代码中大量使用 `10px` `14px` `18px`。

**方案**:

在 `design-system.css` `:root` 中添加:

```css
--ad-space-0-5: 2px;   /* 微间距 */
--ad-space-2-5: 10px;  /* gap: 10px 最常用 */
--ad-space-3-5: 14px;  /* padding: 14px 次常用 */
--ad-space-4-5: 18px;  /* margin-bottom: 18px */
```

**验收**:
- 新增令牌在 `design-system.css` 中定义
- 后续 P2-3 操作中实际使用

---

### P2-2 提取 --ad-border-rgb 全局变量

**严重度**: 🟡 中 | **来源**: CSS 审计 | **估时**: 15min

**问题**:

`rgba(116, 145, 182, 0.*)` 在代码库中出现 **70+ 次**，每次都是硬编码的 rgba 值。

**方案**:

在 `design-system.css` 中添加:

```css
--ad-border-rgb: 116, 145, 182;
```

然后将所有 `rgba(116, 145, 182, X.XX)` 替换为 `rgba(var(--ad-border-rgb), X.XX)`。

**涉及文件**: strategy-hub.css (~40处), strategy-workspace.css (~30处), backtest-analysis.css (~15处)

**验收**:
- `grep -rn "rgba(116, 145, 182" frontend/src/` 返回 0

## P3 — 低优清理

### P3-1 交互元素缺失 transition 补充

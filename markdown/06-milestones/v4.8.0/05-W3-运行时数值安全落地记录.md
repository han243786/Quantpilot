# v4.8.0 W3 运行时数值安全落地记录

> 日期: 2026-05-25
> 范围: W3-1 至 W3-5

## 落地项

| 项 | 落地内容 | 验证 |
| --- | --- | --- |
| W3-1 | `compute_step_returns` 对 `prev`/`curr` 同时执行有限性与正值校验, 避免 NaN/Inf 下游传播 | `cargo test -p qrpc-runtime compute_step_returns_rejects_non_finite_previous_equity` |
| W3-2 | Sharpe/Sortino/Calmar 在使用 `annualized_return` 前归一为有限数, 比率分母同步检查有限性 | `cargo test -p qrpc-runtime compute_metrics_zeroes_non_finite_annualized_return_before_ratios` |
| W3-3 | `fee_bps`/`slippage_bps` 覆盖回测 override、runtime protocol、Strategy IR、v4 simulated execution config 的有限性校验 | `cargo test validate_backtest_execution_assumption_overrides_rejects_non_finite_costs` |
| W3-4 | v4 回测 summary `win_rate` 改为从 equity curve directional steps 计算, flat step 不计入分母 | `cargo test v4_win_rate_counts_up_steps_over_directional_steps` |
| W3-5 | `V4RuntimeInputEvent` 顶层 serde `deny_unknown_fields`; 外部输入 payload 按事件目录拒绝未知字段 | `cargo test -p qrpc-runtime v4_runtime_input_event_denies_unknown_top_level_fields` |

## 边界说明

- v4 模拟盘/实盘同构边界不在 W3 改动执行端适配, 本轮只封运行时数值与输入契约。
- `market.data` 内部 helper 生成的行情 payload 继续兼容 runtime 补充字段; 直接外部输入按 `MachineEventCatalog.payload_fields` fail-closed。
- 非有限成本参数在进入回测与执行模拟前拒绝, 不再依赖后续 `.max(0.0)` 或默认值兜底。

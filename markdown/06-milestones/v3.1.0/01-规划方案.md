# v3.1.0 规划方案

> 版本类型: MINOR | 基准: v3.0.2 | 目标: 审计闭环 + 质量达标

---

## 目标

- 序列化安全全量收敛: deny_unknown_fields 覆盖所有策略传输类型
- 前端质量达标: React.memo + 响应式 + 加载态
- 执行端持久化: 策略注册表落地 + 参数快照持久化
- 测试覆盖达 50%+ (30+ tests)
- 文档同步: GP合规矩阵v3.0.0 + CHANGELOG + README

## 非目标

- 不新增交易功能 (留给v3.2.0)
- 不重构编译链 (留给MAJOR)

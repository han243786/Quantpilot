## S0 阻断项 (9条 — 全部已修复)

### S0-1 嵌套写锁死锁风险 (已修复)
**严重度**: 阻断
**来源**: 维度B 并发扫描
**策略**: GP §5.2
**问题**: `process_expired_approvals` 在持有 `approval_records.write()` 时再获取 `ai_proposals.write()`, 反序调用将死锁
**方案**: 拆分为两阶段 — 阶段1持锁收集过期ID + 后台spawn I/O, 释放锁; 阶段2独立获取 `ai_proposals` 锁更新状态
**验收**: `cargo check --workspace` 通过; 代码审查确认无嵌套写锁

### S0-2 JWT验证失败降级绕过 (已修复)
**严重度**: 阻断
**来源**: 维度E API扫描
**策略**: GP §5.4 (禁止绕过)
**问题**: JWT验证失败后降级到API Key认证, 攻击者可用过期JWT绕过
**方案**: JWT失败直接返回401, 移除API Key降级
**验收**: `cargo test auth_middleware`; curl测试JWT失败不降级

### S0-3 CORS 允许通配符 (已修复)
**严重度**: 阻断
**来源**: 维度E API扫描
**策略**: 安全加固
**问题**: `QUANTPILOT_CORS_ORIGIN=*` 可导致全开放CORS
**方案**: 解析时拒绝 `*` 和非 http(s) scheme
**验收**: 设置 `QUANTPILOT_CORS_ORIGIN=*` 后启动，日志显示拒绝警告

### S0-4 graph_version_dir 缺少纵深防御 (已修复)
**严重度**: 阻断
**来源**: 维度E API扫描
**策略**: GP §7.1 路径遍历防护
**问题**: `graph_version_dir` 仅依赖调用方验证 graph_id, 无自身防护
**方案**: 内部调用 `sanitize_storage_path_segment` 作为纵深防御
**验收**: `grep -A3 "fn graph_version_dir" src/graph_api.rs` 确认 sanitize 调用

### S0-5 未知意图模块键静默丢弃 (已修复)
**严重度**: 阻断
**来源**: 维度G 编译链扫描
**策略**: GP §5.2 (禁止静默忽略)
**问题**: `convert_graph_json_to_script_module` 遇到未知 module_key 仅打日志, 不报错
**方案**: 返回 `anyhow::bail!` 明确错误
**验收**: 发送含 `builtin.intent.unknown` 的编译请求 → 返回400含中文错误

### S0-6 前端未知意图静默降级为 ma_cross (已修复)
**严重度**: 阻断
**来源**: 维度G 编译链扫描

### S0-7 RFC-017/018/019 状态矛盾 (已修复)

## P1 高优先级 (15条)

### P1-1~P1-10 原子写入缺少 fsync (10处统一修复)
**严重度**: 高
**来源**: 维度D 持久化扫描
**策略**: GP §7.4 (写入声明生命周期)
**问题**: 10处 tmp+rename 缺少 fsync, 系统崩溃时可导致数据丢失:
- `backtest_artifacts.rs:write_json`
- `snapshot_service.rs:persist_snapshot`
- `alert_engine.rs:persist_alert_firing`
- `collaboration.rs:persist_graph_audit_entry`
- `chaos_experiment.rs` 报告写入
- `runtime/mutation.rs` 两处写入
- `storage_lifecycle.rs:ensure_storage_quota`
- `data_module.rs` 历史缓存写入
- `backup.rs` 清单写入
- `main.rs` 待办项持久化
**方案**: 抽取 `atomic_write_json_with_fsync()` 公共函数, 10处调用点统一替换
**验收**: `grep -r "fs::rename" src/ --include="*.rs" | grep -v "atomic_write\|fsync\|_bak\|staging"` 应返回0

### P1-11 8个BTreeMap无界增长
**严重度**: 高
**来源**: 维度B 并发扫描
**策略**: GP §7.2 (存储配额)
**问题**: AppState 中 parameter_mutations/ai_proposals/hotswap_records/approval_records/sandbox_reports/alert_firings/snapshots/chaos_experiments 无大小上限
**方案**: 在后台10-tick循环中对这8个BTreeMap追加 MAX_CACHED_RECORDS=500 淘汰 + 24h TTL
**验收**: 长期运行测试, 内存使用不持续增长

### P1-12 radial-gradient 违反 GP §8.3
**严重度**: 高
**来源**: 维度A GP扫描
**策略**: GP §8.3 (背景限制)
**问题**: `styles.css:1224` 使用 `radial-gradient(circle, ...)` 做点阵图案
**方案**: 用 SVG pattern 或纯色 `background-image` + `background-size` 替代
**验收**: `grep "radial-gradient" frontend/src/styles.css` 返回0

### P1-13 圆角12px超过GP限制
**严重度**: 高
**来源**: 维度A GP扫描
**策略**: GP §8.2 (圆角限制 ≤6px)
**问题**: `styles.css` 中 `.qs-editor-report__badge` 使用 `border-radius: 12px`
**方案**: 改为 `var(--ad-radius-lg)` (6px)
**验收**: `grep "border-radius: 12px" frontend/src/` 返回0

### P1-14 编译/回测按钮无加载状态
**严重度**: 高
**来源**: 交互完整性检查
**策略**: 用户体验
**问题**: 点击编译/模拟/回测按钮后仅 disabled, 无 "编译中..." 文字反馈
**方案**: 在 TopToolbar 中为三个按钮增加 loading 状态: `compiling/running/backtesting`, 按钮文字变为 "编译中..." / "回测中..."
**验收**: 点击编译按钮 → 按钮显示 "编译中..." 且不可再次点击

### P1-15 技术术语泄漏到用户界面
**严重度**: 高
**来源**: 交互完整性检查
**策略**: GP §2.5 (前端字符串 t() 包裹)
**问题**: "Strategy IR"、"Core IR 工件"、"lowering" 等术语在诊断面板、错误提示、总览页直接展示
**方案**:
- `actionFailure.js`: "Strategy IR" → "策略编译"

- `ModuleSidebar.jsx`: 锁定模块添加 tooltip 说明原因
- `supportMatrix.js`: 能力描述用自然语言
**验收**: 用户界面搜索 "Strategy IR\|Core IR\|lowering" 返回0 (中文替换后)

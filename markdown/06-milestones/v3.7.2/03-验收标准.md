## 三、专项验收

### 3.1 Safe fallback

| 项 | 标准 |
|----|------|
| 无缓存 capability 503 | 前端进入 safe fallback |
| 风险操作 | 编译、模拟、回测、runtime_config 导出禁用 |
| Workspace tabs | 若采用 strict fallback，tab 可见但禁用且有原因 |
| 测试 | `editor enters safe fallback mode when capability fetch fails without cache` 通过 |
| API 守卫 | 无未声明 API 请求 |

### 3.2 文档真实口径

| 项 | 标准 |
|----|------|
| closeout 项数 | 活跃文档统一为 23 项 |
| E2E 状态 | 只在实测通过后声明 21/21 |
| Vitest 统计 | 与最新实测一致，或明确“以命令输出为准” |
| UTF-8 统计 | 与最新实测一致，或明确“以命令输出为准” |
| v3.7.1 历史记录 | 不作为当前状态真源 |

### 3.3 测试副作用

| 项 | 标准 |
|----|------|
| Session key | 不在 `qrpc_session/storage` 留下未跟踪文件 |
| closeout 后状态 | `git status --short` 干净 |
| 清理方式 | 不使用会误删用户文件的通配清理 |

### 3.4 Clippy 语义

| 决策 | 验收 |
|------|------|
| budget gate | 脚本输出当前预算和上限，新增 warning 阻断 |

## 优化方法

本里程碑采用 **四步优化法**，每条优化项按此流程执行：

### 第一步：溯源定位

```
1. 读取目标文件，理解当前实现
2. 对照 GP 条款和超级规范化要求，确定违规点
3. 定位具体的代码行/块
```

### 第二步：最小修改

```
1. 只改需要改的代码，不碰无关逻辑
2. 优先使用项目已有的机制 (t()、CSS变量、Diagnostic API)
3. 保持向后兼容 — 新字段用 serde(skip_serializing_if)、新函数用 allow(dead_code)
```

### 第三步：即时验证

```
每完成一个文件/模块的修改:
1. cargo check --workspace (Rust) / npx vite build (前端)
2. 验证修改效果 (curl API / 检查输出)
3. 确保不引入新 warning
```

### 第四步：门禁收口

```
全量门禁:
1. cargo check --workspace    — 零 error, 零新增 warning
2. cargo test --workspace     — 全量通过
3. npx vite build             — 零 CSS warning
4. npx vitest run             — 全量通过
5. grep 质量检查              — 残留术语/硬编码归零
```

### 优化技术分类

| 类别 | 方法 | 本里程碑应用 |
|------|------|-------------|
| 文本替换 | sed 批量替换 / replace_all | CSS 令牌化 (~75 处)、QS 术语 (30+ 处) |
| 代码重构 | 提取函数/常量/结构体 | unwrapPage()、actionFailure 结构化、ApiErrorResponse |
| 翻译补齐 | 脚本批量翻译 + 正则匹配 | en-US 283/283 键 |
| CSS 修复 | awk brace balance + grep 语法检查 | 3 处 CSS 语法错误 |
| 文档生成 | 按模板生成 + 自动化验证 | 诱错测试矩阵 74 项 |

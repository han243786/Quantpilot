# v3.2.0 规划方案

> 版本类型: MINOR | 基准: v3.1.0 | 目标: P3全量消化 + 性能达标 + 前端专业级

---

## 目标

- P3项全量消化 (38条→0)
- 性能: BTreeMap→HashMap热点路径, audit_log流式读取, 加密预分配
- 前端专业级: 多标签页流畅切换, 策略图涌动优化, 编译产物缓存
- 文档全中文化: RFC-017/018/019翻译 + 术语表
- 执行端实盘模式对接 (OKX live_execution)

## 非目标

- 不新增策略指标
- 不改变协议定义
- 不做架构级重构

## 方案

### 性能深化 (8项)

| # | 文件 | 修复 |
|---|------|------|
| J-1 | `executor_state.rs` + `kline_buffer.rs` | BTreeMap→HashMap (kline_buffers, pending_params) |
| J-2 | `live_runner.rs` | broadcast_ws_event 建立 symbol→runner 反向索引 O(1) |
| J-3 | `audit_log.rs` | recent() 改用 BufReader+seek 流式倒序读取 |
| J-4 | `credential_vault_v2.rs` | encrypt_vault 预分配 Vec::with_capacity |
| J-5 | `credential_vault_v2.rs` | PBKDF2派生密钥缓存, save()延迟批处理去抖5s |
| J-6 | `KlineChart.jsx` | lightweight-charts `update()` 增量取代 `setData()` 全量 |
| J-7 | `StrategyGraphPanel.jsx` | ticker防抖200ms, useRef直接DOM更新价格overlay |
| J-8 | `ExecutorApp.jsx` | 标签页切换时非活跃策略暂停轮询 (Visibility API) |
